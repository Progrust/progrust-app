# 0022. AI 機能が使えなくても学習を続けられるようにする

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `claude-integration.md`「検出と、使えない場合の動作」、`architecture.md`「見つからない場合」
- 置き換え: なし

## 背景

AI 機能は学習者の環境の Claude Code に依存しており、未導入・未ログイン・利用上限・オフラインなどで使えないことがある。AI 機能が使えないときに学習全体が止まると、アプリの中心であるスライドと演習まで使えなくなる。

## 決定

スライド・演習・レッスンの完了は AI なしで行えるようにする。Claude Code が見つからない間、学習記録・分析のジョブは登録だけ行い、見つかってから実行する（`claude-integration.md`「検出と、使えない場合の動作」）。

## 検討した他の案

- 案: Claude Code が見つからない場合はアプリを使えなくする
  - 採用しなかった理由: AI に関係ない学習まで止まる
- 案: Claude Code が見つからない間の試行は記録しない
  - 採用しなかった理由: 後から Claude Code を導入したときに、それまでの学習が分析に反映されない

## 影響

- 試行ログは常に記録されるため、後から学習記録と分析を作れる。
- Claude Code が見つからない間、`pending` のジョブがたまり続ける。
