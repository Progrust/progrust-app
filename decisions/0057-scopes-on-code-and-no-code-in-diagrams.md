# 0057. 変数が生きている範囲はコードに重ねた枠で示し、図の中にコードを書かない

- 状態: 採用
- 日付: 2026-11-01
- 関連仕様: `content-format.md`「コードブロック」、`content-guidelines.md`「図」
- 置き換え: なし

## 背景

サンプルのスライドで、ライフタイム（変数が生きている範囲）を、コードの文を図（SVG）の中に文字として書き、その横に棒を描いて示していた。コードがコードブロックに書かれていなかった。その後、コードをコードブロックに移し、横に範囲の棒の図を並べたが、棒で範囲を表す図はかなり分かりにくかった。

## 決定

- コード（文や式）は図の中に書かず、コードブロックに書く。図の中に書くのは、変数名・型名・値などの短いラベルだけにする。
- 変数が生きている範囲・スコープは図にせず、コードブロックの行を囲む枠で示す（`data-scopes`）。

## 検討した他の案

- 案: 範囲を棒の図で示し、コードブロックと並べる
  - 採用しなかった理由: かなり分かりにくい。範囲を表すなら、その範囲を囲う表現のほうが見やすい

## 影響

- 範囲の枠と Diff は、同じコードブロックで使わない（`content-format.md`「コードブロック」）。
- 図とコードを 1 枚に並べるときは `two-column` を使う。
