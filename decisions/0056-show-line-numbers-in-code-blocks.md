# 0056. コードブロックに行番号を表示し、文で行番号を指してよいことにする

- 状態: 採用
- 日付: 2026-11-01
- 関連仕様: `content-format.md`「コードの表示」、`content-guidelines.md`「コード」
- 置き換え: なし

## 背景

サンプルのスライドで、説明の文が「6 行目」「7 行目」と行番号でコードを指していたが、コードブロックには行番号がなかった。いったんは「行番号を表示せず、文でも行番号を使わない」というルールを決めた。その後、行番号を表示する試作（見た目 3 案）を作って見比べた。この ADR は、試作を見たうえでの判断を記録する。

## 決定

- `language-text`（ターミナルの出力）以外のコードブロックに、行番号を表示する。見た目は、右寄せの番号と区切り線（試作の案 A）にする。生きている範囲の枠（0057）は、行番号の欄の内側に置く。
- 文で「6 行目」のように行番号でコードを指してよい。
- 行番号はファイルの行番号とする。ファイルの途中から載せるときは `data-start-line` で始まりの番号を指定する。作者が属性に書く行番号も、文で指す行番号も、表示される番号で書く。
- `language-text` はターミナルの出力に限り、行番号を付けない。ターミナルの出力ではないテキストは `language-plaintext` で書く。

## 検討した他の案

- 案: 行番号を表示せず、文でも行番号を使わない（コード片やマーカーで指す）
  - 採用しなかった理由: 試作を見比べて、行番号を表示するほうが自然で見やすかった
- 案: 番号の欄だけ面の色を変える（試作の案 B）、番号だけを淡く置く（試作の案 C）
  - 採用しなかった理由: 案 A が一番自然で見やすかった（試作では、案 B は面の差が小さく Diff の削除行の帯と同じ色になり、案 C は番号の文字のコントラストが 4.5:1 に届かなかった）
- 案: 範囲の枠で、行番号の欄ごと外側から囲む
  - 採用しなかった理由: 欄の内側に置くほうが自然で見やすかった（試作では、外側から囲むと区切り線が枠を横切った）
- 案: ファイルの途中から載せても、行番号を 1 から数える
  - 採用しなかった理由: 途中から載せているので、行番号も途中から始まるほうが自然で、コンパイラの出力の行番号ともそろう

## 影響

- 行番号の欄の分だけ、コードの 1 行に入る文字数が減る。
- コンパイラの出力の行番号と、コードの行番号を照らし合わせられる。
