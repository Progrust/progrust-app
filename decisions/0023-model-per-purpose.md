# 0023. Claude のモデルを用途ごとに選べるようにする

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `claude-integration.md`「モデルの選択」
- 置き換え: なし

## 背景

質疑応答は学習者が回答を待つため応答の速さが大事であり、記録・分析・問題生成はバックグラウンドで実行するため品質が大事である。1 つのモデルで両方を満たすのは難しい。

## 決定

「質疑応答」と「記録・分析・問題生成」で別々にモデルを選べるようにする。既定値は質疑応答が `sonnet`、記録・分析・問題生成が `opus` とする（`claude-integration.md`「モデルの選択」）。

## 検討した他の案

- 案: 全体で 1 つのモデルを選ぶ
  - 採用しなかった理由: 速さと品質のどちらかを犠牲にすることになる
- 案: 記録・分析・問題生成もそれぞれ別に選べるようにする
  - 採用しなかった理由: 設定項目が増えるわりに、別々のモデルにしたい場面が少ない

## 影響

- 設定画面のモデルの選択欄が 2 つになる。
- モデルの名前は Claude Code のエイリアスで指定するため、新しいモデルが出てもアプリの更新は不要である。
