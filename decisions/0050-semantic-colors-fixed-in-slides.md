# 0050. スライドでは、意味と色が結びついた要素を章によらない固定の色にする

- 状態: 採用
- 日付: 2026-11-01
- 関連仕様: `content-format.md`「色の指定」
- 置き換え: なし

## 背景

画面では、正解・完了を章カラーで表し、成功専用の緑を持たない（0041）。スライドのデザインシステムも最初はこれにならい、`c-ok` と `callout.ok` を章カラーにしていた。サンプルを作ると、ダークテーマの第4章で `callout.ok`（章カラーのマゼンタ）と `callout.ng`（赤）の地がほとんど同じ色に見えた。また、`c-ok` と `c-primary` が同じ色になるので、1 枚の中で両方を使えなかった。

## 決定

- スライドでは、意味と色が一般に結びついている要素を、章によらない固定の色にする。
  - `callout` の 5 種類（`info`・`tip`・`warn`・`ng`・`ok`）
  - `c-ok`（正しい・成功。緑）と `c-ng`（誤り・エラー。赤）
- 章カラーは主役と補助（0048）だけに使う。
- 画面の 0041 は変えない。スライドの中だけ成功の緑を持つ。
- 色の値はスライドのデザインシステムに定める。

## 検討した他の案

- 案: 0041 と同じく、正しい・成功を章カラーで表す
  - 採用しなかった理由: 意味と色が一般に結びついている要素は、章に関係なくその色にしたほうが見やすい。スライドは正しい書き方と誤った書き方を並べて比べることが多く、緑＝正しい・赤＝誤りの対応のほうが読み取りやすい
- 案: `callout.ok` だけを緑にする
  - 採用しなかった理由: 意味と色の対応を、callout の 5 種類と文字・図の色クラスで一貫させる

## 影響

- 第2章・第12章（緑の章）では、主役の章カラーと成功の緑が近い色になる。callout は章カラーを使わないので問題にならない。文字・図では ✓ の形と文言で区別する。
- 画面（正解は章カラー）とスライド（正しいは緑）で、成功の色が違う。
