# 0009. 隠しテストを、対象ファイルの末尾に子モジュールとして組み込む

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `exercise-runner.md`「test 方式」
- 置き換え: なし

## 背景

`test` 方式では、学習者のコードに含まれる関数を隠しテストから呼び出す必要がある。`tests/` ディレクトリの結合テストはライブラリクレート（`src/lib.rs`）の公開アイテムしか呼べず、`src/main.rs` だけの演習では使えない。

## 決定

判定時に、`judge.target` のファイルの末尾へ `#[cfg(test)] #[path = ...] mod progrust_judge;` を追加し、隠しテストを子モジュールとして組み込む。テスト実行時は `progrust_judge::` で絞り込む（`exercise-runner.md`「test 方式」）。

## 検討した他の案

- 案: `tests/` の結合テストにする
  - 採用しなかった理由: `src/main.rs` の関数や非公開の関数を呼べない
- 案: 学習者のファイルの先頭や途中に挿入する
  - 採用しなかった理由: コンパイルエラーの行番号が、エディタ上の行番号とずれる

## 影響

- 末尾に追加するため、コンパイルエラーの行番号はエディタ上の行番号と一致する。
- `use super::*;` で非公開の関数も呼べる。
- 学習者自身が書いた `#[test]` は判定に含まれない。
