# 0054. コードの Diff を、行の先頭の記号で書き、章によらない固定の色で示す

- 状態: 採用
- 日付: 2026-11-01
- 関連仕様: `content-format.md`「コードブロック」
- 置き換え: なし

## 背景

スライドで、コードのどこを追加・削除したのかを見せる表示がなかった。

## 決定

- コードブロックに Diff の表示を追加する。`data-diff` を付け、各行の先頭に `+`（追加）・`-`（削除）・半角空白（変わらない行）を書く（`content-format.md`「コードブロック」）。
- 追加・削除の色は、章によらない固定の色にする。値はスライドのデザインシステムに定める。
- 削除行に取り消し線を付けない。
- 行番号は変更後のファイルの行番号だけを表示し、削除行には付けない。

## 検討した他の案

- 案: 追加・削除の行を、行番号の属性（追加の行・削除の行の番号の一覧）で指定する
  - 採用しなかった理由: 属性は削除行を含めた位置で数え、表示と文は変更後の行番号で数えることになり、作者が取り違えやすい。行の先頭に記号を書く形は git の差分と同じで、行を数える必要がない
- 案: 削除行に取り消し線を付ける
  - 採用しなかった理由: 元のコードが読みにくくなる
- 案: 変更前と変更後の 2 列の行番号を表示する
  - 採用しなかった理由: git の差分の表示などでも変更後の番号だけのスタイルが多く、見やすい

## 影響

- 追加の色は、第7章の章カラーと似た色になる。行に帯を引く表示は Diff にしかない（0053）ので、問題にならない。
- Diff のコードは、作者が書く行が先頭の記号の分だけ 1 文字長くなる。
