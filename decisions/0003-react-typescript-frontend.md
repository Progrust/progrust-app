# 0003. フロントエンドに React と TypeScript を使う

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `architecture.md`「技術構成」
- 置き換え: なし

## 背景

Tauri のフロントエンドには任意の Web フレームワークを使える。このアプリは、コードエディタ・スライドの描画・チャット UI など、既存のライブラリを多く使う画面を持つ。また、実装の多くを AI（Claude Code）に任せる想定である。

## 決定

フロントエンドに React + TypeScript（ビルドは Vite）を使う（`architecture.md`「技術構成」）。

## 検討した他の案

- 案: Svelte + TypeScript
  - 採用しなかった理由: 軽量で Tauri と相性が良いが、エディタ・Markdown 描画・チャット UI などのライブラリが React より少ない
- 案: Vue + TypeScript
  - 採用しなかった理由: ライブラリの数は中程度で、React を選ばない理由が特になかった

## 影響

- ライブラリの選択肢が多く、AI による実装の精度も高いことが期待できる。
- バンドルサイズは Svelte より大きくなる。
