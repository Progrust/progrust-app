# 0065. 台本で、もとの文（text）と読ませる文（say）を分ける

- 状態: 採用
- 日付: 2026-11-19
- 関連仕様: `content-format.md`「台本（script.json）」「音声」、`content-guidelines.md`「台本」
- 置き換え: なし

## 背景

試作では、台本を文ごとに書き、VOICEPEAK で読ませた。VOICEPEAK には読み間違えやすい語がある（Rust、値、s1 など）。試作では、台本の各文を、もとの文（`text`）と読ませる文（`say`）に分け、`say` では読み間違えやすい語をかなで書いた（Rust → ラスト、値 → あたい、s1 → エスワン など）。

## 決定

- 台本の各文に、もとの文（`text`）と読ませる文（`say`）を持たせる（`content-format.md`「台本（script.json）」）。
- `say` では、読み間違えやすい語をかなで書く。書き換えの対応表（読みの対応表）は全レッスン共通で 1 か所に持ち、作者は `say` を書くときにこの表に従う（`content-format.md`「音声」、`content-guidelines.md`「台本」）。

## 検討した他の案

- なし（試作の形を採用した）

## 影響

- 音声は `say` から作る。字幕（0067）と質疑応答（`qa-chat.md`「AI への入力」）には `text` を使う。
- 作者は 1 つの文について `text` と `say` の 2 つを書き、内容をそろえる必要がある。
- `say` に読みの対応表の語がそのまま残っていると、教材チェックツールが警告する（`content-guidelines.md`「教材チェックツール」）。
