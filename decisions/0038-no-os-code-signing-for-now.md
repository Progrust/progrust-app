# 0038. OS のコード署名を当面行わない

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `non-functional.md`「配布と更新」
- 置き換え: なし

## 背景

コード署名がないと、初回起動時に macOS（Gatekeeper）と Windows（SmartScreen）が警告を出す。署名には Apple Developer Program や Windows のコード署名証明書の費用がかかる。正式に公開するかどうかはまだ決まっていない。

## 決定

macOS・Windows ともにコード署名を行わず、警告を回避する手順を配布ページに記載する（`non-functional.md`「配布と更新」）。

## 検討した他の案

- 案: macOS だけ署名・公証する
  - 採用しなかった理由: macOS は未署名だと起動に手間がかかるが、正式公開が未定の段階では費用に見合わない
- 案: 両 OS で署名する
  - 採用しなかった理由: 費用がさらにかかる

## 影響

- 学習者は初回起動時に OS の警告を回避する操作が必要になる。
- 署名なしの macOS アプリで自動更新が正しく動くかを検証する必要がある（`non-functional.md`「未決事項」）。
- 正式に公開すると決めたときに、この ADR を置き換える。
