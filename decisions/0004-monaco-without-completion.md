# 0004. コードエディタに Monaco Editor を使い、補完・LSP 連携は行わない

- 状態: 採用
- 日付: 2026-10-31
- 関連仕様: `architecture.md`「技術構成」
- 置き換え: なし

## 背景

演習画面にはコードエディタが必要である。rust-analyzer と連携すれば補完や型の表示ができるが、学習者に自力で考えさせる原則（0001）と相反するうえ、rust-analyzer の導入・管理が必要になる。

## 決定

Monaco Editor を使い、シンタックスハイライトと基本的な編集機能のみとする。補完・LSP 連携は行わない（`architecture.md`「技術構成」）。

## 検討した他の案

- 案: Monaco Editor と rust-analyzer を連携する
  - 採用しなかった理由: 実際の開発に近いが、補完が答えを教えてしまう場面がある。rust-analyzer の同梱または検出・起動・更新の管理が必要になる
- 案: CodeMirror 6 を使う
  - 採用しなかった理由: 軽量でカスタマイズしやすいが、VS Code と同じ操作感を持つ Monaco の方が、学習後に実際の開発へ移りやすい

## 影響

- エラーは実行・提出してコンパイラの出力で確認することになる。
- 後から補完を加える場合は、0001 との関係を含めてこの ADR を置き換える。
