# 質疑応答 仕様書

動画や解説について、チャット形式で AI に質問する機能を定める。
`claude -p` の呼び出し方の共通ルールは `claude-integration.md` に従う。

## 1. 利用できる場面

| 場面 | コンテキスト（試行ログの `context`） |
|---|---|
| 動画の再生中（動画画面を開いている間。一時停止中も含む） | `video:{文の ID}`（質問を送信したときに再生中だった文の ID。再生中の文は `screens.md` §5） |
| 演習の解説表示中（レッスン・生成問題） | `explanation` |

- 演習の解答中（正解前）は質問できない。
- レッスン検索のモーダル（`screens.md` §9）からは質問できない。

## 2. 会話履歴

- 会話履歴は画面を開いている間だけメモリに保持する。動画画面と演習画面は別の画面として扱い、画面を移ると会話は消える。
- 動画画面の中で再生位置を移しても、会話は続く。
- アプリは毎回の呼び出しで、直近 10 往復までの会話履歴を入力に含める。
- 会話履歴そのものはファイルに保存しない。質問文は試行ログの `chat` イベントとして記録する（§6）。

## 3. AI への入力

### 3.1 動画の再生中

1. 指示文（`prompts/chat-video.md`）
2. レッスンのタイトルと主要素の説明（要素マスタの `name`・`description`）
3. レッスンの台本（`content-format.md` §5.2）の内容
   - 全文: シーンごとにシーンの名前を見出しにし、そのシーンの各文の ID と `text` を台本の順に並べたもの
   - `ai_note`
   - 画面に出すコード（`code_blocks`。渡し方は §3.3）
4. 質問を送信したときに再生中だった文の ID と、その文の `text`
5. 既習の要素の一覧（`content-format.md` §2 の定義による）
6. 会話履歴
7. 今回の質問

演習の問題文・模範解答・テストケースは渡さない。

### 3.2 解説表示中

1. 指示文（`prompts/chat-explanation.md`）
2. レッスン（または生成問題）のタイトルと主要素・副要素の説明
3. 問題文、解説、模範解答
4. 学習者が正解したときのコード
5. 会話履歴
6. 今回の質問

### 3.3 画面に出すコードの渡し方

台本の文は、コードの行を行番号で指すことがある（`content-guidelines.md` §4.4）。台本の `code_blocks` は、次のように渡す。

- 言語（`language`）とラベル（`label`）を添えたコードとして渡す。`language` が `text` のものは、ターミナルの出力として渡す。
- 行番号を表示するもの（`content-format.md` §5.6）は、各行の先頭に、`code_blocks` の行番号を付けて渡す。
- Diff として表示するものは、Diff であることを示し、各行の先頭の `+` / `-` を残して渡す。行番号は変更後のファイルの行番号を付け、削除行には付けない。

## 4. 回答の方針

指示文で以下を指示する。

**共通**

- 日本語で、学習者の質問に簡潔に答える。
- 未学習の要素に触れる必要がある場合は、そのことを明示し、深入りしない。
- Rust のバージョンは edition 2024 を前提とする。

**動画の再生中**

- 動画の内容と既習の範囲で説明する。
- 演習の答えになる完成コードは書かない。学習者が課題を示して解答を求めた場合は、考え方の説明にとどめ、自分で書くよう促す。
- コード例は、説明に必要な短いものに限る。

**解説表示中**

- 学習者のコードと模範解答の違い、より Rust らしい書き方、関連する発展的な話題について自由に答えてよい。

## 5. 画面

- 動画画面では、画面の右側に開閉できるチャットパネルとして表示する。演習の解説表示中は、正解のモーダルの中に表示する（`screens.md` §6）。
- 質問を送信しても、動画の再生と一時停止は変えない（学習者の操作のままとする）。
- 回答はストリーミングで少しずつ表示する。Markdown を描画し、Rust のコードブロックはシンタックスハイライトする。
- 回答中は「停止」ボタン（`cancel_chat`）を表示する。停止した場合、それまでの回答を残して「（停止しました）」と表示する。
- 入力欄は最大 2,000 文字。Enter で改行し、Ctrl+Enter（macOS は Cmd+Enter）で送信する。
- 回答中は次の質問を送信できない。
- エラー時は、回答の場所にエラーの内容（`claude-integration.md` §7）と「再試行」ボタンを表示する。
- 画面を離れるとき、回答中であれば呼び出しを中断する。

## 6. 試行ログへの記録

- 質問を送信したとき、試行ログに `chat` イベントを追記する（スキーマは `learning-record-and-analysis.md` §3.2）。
- 試行セッションが存在する場面（レッスンの動画画面、レッスン・生成問題の演習画面）でのみ記録する。

## 7. 受け入れ条件

- 動画の再生中に「この演習の答えを教えて」と質問しても、完成コードが返らない。
- 再生位置を移した後の質問で、移した先の文を踏まえた回答が返る。
- 台本の文が「6 行目」と行番号で指しているコードについて質問すると、そのコードの 6 行目（`code_blocks` の行番号）を踏まえた回答が返る。
- 一時停止中にも質問できる。再生中に質問を送信しても、動画は止まらない。
- 直前の質問を受けた追加の質問（「さっきの例をもう少し詳しく」など）に、文脈を踏まえて回答する。
- 演習画面に移ると、動画画面での会話は表示されない。
- 演習の解答中は質問の入力欄が表示されない。
- 質問のたびに試行ログに `chat` イベントが追記される。動画画面での質問の `context` は、`video:` に質問を送信したときに再生中だった文の ID を続けたものになる。
