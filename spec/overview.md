# Progrust（Rust プログラミング学習アプリ）

仕様の大枠を記載する。各機能の詳細は、記載した仕様書に定める。用語の定義は `glossary.md` を参照。

## 1. 目的

- Rust の各要素ごとに、動画で知識をインプットし、コーディングエディタで演習問題を解く、という流れを細かく繰り返して Rust を学ぶ。
- AI（Claude Code）が演習ごとに学習者の特徴を分析・記録し、その内容をもとに学習者に適した演習問題を生成する。
- AI は動画や演習問題の内容について質疑応答も行う。

## 2. 想定する学習者

- 他のプログラミング言語の経験がある人（詳細は `content-guidelines.md` §1）。

## 3. 技術構成の概要

- Tauri を利用したネイティブアプリケーションとし、macOS と Windows を対象とする。
- 演習のコードは学習者の環境の Rust ツールチェーンでビルド・実行する。
- Claude Code とは `claude -p` で連携する。
- 詳細は `architecture.md`、対応環境・配布などは `non-functional.md`。

## 4. 機能

| 機能 | 概要 | 仕様書 |
|---|---|---|
| レッスン | 「動画 1 本 + 演習問題 1 問」を 1 レッスンとし、章ごとに分類する。各章の最後に演習のみの章末復習レッスンを置く。演習に正解するとレッスン完了 | `lesson-flow.md` |
| 動画 | ナレーションつきの 16:9 の動画。全レッスンで統一したデザイン。コードと図を動かして分かりやすさを重視する | `content-format.md` |
| 演習 | 問題文・エディタ・コンソールを 1 画面に表示する。複数ファイルに対応し、実行（動作確認）と提出（正誤判定）ができる。正解後に解説を表示する | `exercise-runner.md`、`screens.md` |
| 質疑応答 | 動画の再生中と、演習の正解後の解説表示中に、AI にチャットで質問できる | `qa-chat.md` |
| 学習記録 | レッスン終了時に、演習の解き方・躓いた箇所・スムーズに解けた箇所を AI が Markdown で記録する | `learning-record-and-analysis.md` |
| 分析 | 学習記録をもとに、得意・苦手分野をレベル分けし、時間軸（最近扱っていない分野など）も含めて AI が分析ファイルを更新し続ける。記録とは別の AI セッションで行う | `learning-record-and-analysis.md` |
| 演習問題生成 | 苦手分野を中心にするか、扱う要素、難易度、AI へのメッセージを設定して、AI が演習問題を生成する | `exercise-generation.md` |
| レッスン検索 | ヘッダーの検索窓から、検索ワードとタイトルでレッスンを検索し、動画をモーダルで表示する | `screens.md` |
