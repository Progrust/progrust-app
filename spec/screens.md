# 画面仕様書

各画面の表示内容・操作・画面遷移と、全画面に共通する UI（ヘッダー、レッスン検索、見た目とテーマ、通知）を定める。
画面で使うデータの意味や計算方法は、それぞれの担当仕様書に定める。

## 1. 共通レイアウト

```
┌──────────────────────────────────────────────────────────────────┐
│ Progrust  ホーム  レッスン  問題生成  設定 [🔍 レッスン検索] ⟳ 1 │ ← ヘッダー
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                         各画面の内容                             │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

- ヘッダーは全画面に表示する。右端の ⟳ は実行中・待機中のジョブ数で、押すとジョブの一覧をポップオーバーで表示する（ジョブがなければ非表示）。
- ウィンドウの最小サイズは 1024×700、初期サイズは 1280×800 とする。
- UI の文言は日本語のみとする。

## 2. 画面一覧と遷移

| 画面 | 内容 |
|---|---|
| 初回起動画面 | 初回起動時のみ表示する説明と環境チェック（§12） |
| トップページ | 起動時に表示する。次にやるべきレッスンと分析の要約をダッシュボードとして表示する（§3） |
| レッスン一覧 | 章ごとのレッスンの一覧（§4） |
| 動画画面 | レッスンの動画を再生する（§5） |
| 演習画面 | レッスンまたは生成問題の演習を表示する（§6） |
| 生成問題一覧 | 過去に生成した演習問題の一覧（§7.1） |
| 生成設定画面 | 生成する問題の設定（§7.2） |
| 設定画面 | アプリの設定と学習データの管理（§8） |

## 3. トップページ

| 表示項目 | 内容・データ |
|---|---|
| 環境の警告 | `cargo` / `claude` が見つからない、初回準備中・失敗、の場合にバナーを表示する（`architecture.md` §3） |
| 次にやるべきレッスン | `lesson-flow.md` §2 で決まるレッスンのタイトル・章・概要と「続きから」（未着手なら「始める」）ボタン。すべて完了済みなら問題生成への案内 |
| 学習の進み具合 | 完了レッスン数 / 全レッスン数、章ごとの完了率 |
| 苦手分野 | `level` 1〜2 かつ `provisional: false` の要素の上位 3 件。level が低い順、同じ level 内では `last_stumbled` が新しい順 |
| 復習推奨 | `review_due: true` の要素 |
| 定着度が低下した要素 | `regressed: true` の要素 |
| 学習ペース | `activity.last_4_weeks` の週ごとの記録数 |
| 総評 | 分析ファイル本文の「総評」セクション（アプリが本文から取り出すのはこのセクションのみ） |

- 苦手分野・復習推奨・定着度が低下した要素の各要素から、その要素を選択した状態の生成設定画面を開ける。
- 分析ファイルのデータは `analysis.md` の frontmatter から取る（`learning-record-and-analysis.md` §5）。
- 学習記録がまだない場合、分析に関する項目の代わりに「レッスンを完了すると、ここに分析が表示されます」と表示する。
- `analysis.md` を解析できない場合は、分析に関する項目の代わりに「分析ファイルを読み込めません」と、設定画面の「分析を再構築」への案内を表示する。

## 4. レッスン一覧

- 章ごとに区切って表示する。章の見出しには章のタイトル・説明・完了数（例: 3 / 5）を表示する。
- 各レッスンに、番号、タイトル、概要、目安の所要時間、状態（未着手 / 進行中 / 完了）を表示する。章末復習レッスンは「復習」と表示する。
- 推奨レッスン（`lesson-flow.md` §2）に「次はここ」の印を付け、初期表示ではその章までスクロールする。
- レッスンを選ぶと動画画面（章末復習レッスンは演習画面）を開く。

## 5. 動画画面

```
┌──────────────────────────────────────────────────┬──────────────┐
│ ← レッスン一覧   第4章 / 所有権のムーブ          │              │
│ ┌──────────────────────────────────────────────┐ │  チャット    │
│ │                                              │ │  パネル      │
│ │                 動画（16:9）                 │ │  （開閉可）  │
│ │                                              │ │              │
│ └──────────────────────────────────────────────┘ │              │
│                字幕（オンのとき）                │              │
│ ──────┼────●─────────┼──────────────┼─────────── │              │
│ [▶] 0:42 / 1:44  [-5秒] [+5秒] [前の文] [次の文] │              │
│ [1倍] [音量] [字幕]                   [演習へ ▶] │              │
└──────────────────────────────────────────────────┴──────────────┘
```

- 動画は表示領域に収まる最大のサイズで、16:9 を保って表示する。動画の描画方法は `content-format.md` §5 に従う。
- 動画は、そのレッスンが属する章を指定して再生する（`content-format.md` §5.1）。
- 動画の下にプレーヤーの操作を置く。
- チャットパネルの動作は `qa-chat.md` §5 に従う。

**プレーヤーの操作**

| 操作 | 動作 |
|---|---|
| 再生／一時停止 | 再生と一時停止を切り替える |
| シークバー | 再生位置を表示する。押した位置・ドラッグした位置に再生位置を移す。シーンの区切り（各シーンの開始位置。`content-format.md` §5.4）に印を表示する |
| 時間 | 現在の再生位置と、動画全体の長さを表示する |
| 5 秒戻る／5 秒進む | 再生位置を 5 秒前・5 秒後に移す。動画の先頭・末尾を越えるときは、先頭・末尾に移す |
| 前の文へ／次の文へ | 再生中の文の 1 つ前・1 つ後の文の頭に移る。最初の文で「前の文へ」を押すと、最初の文の頭に移る。最後の文では「次の文へ」を使えない |
| 再生速度 | 0.75・1・1.25・1.5・2 倍から選ぶ |
| 音量とミュート | 音量を変える。ミュートを切り替える |
| 字幕 | 字幕の表示と非表示を切り替える |
| 演習へ | 演習画面に移る。表示する条件は `lesson-flow.md` §1 に従う |

- 再生中の文は、開始位置が再生位置と同じかそれより前の文のうち、最後の文とする。最初の文が始まる前は、最初の文とする。文の頭は、その文の開始位置（`content-format.md` §5.4）とする。
- 再生位置を移しても、再生中か一時停止中かは変わらない。
- 画面を開いても自動では再生しない。開いたときの再生位置は `lesson-flow.md` §3 に従う。
- 最後まで再生したら、末尾で止まる。
- 字幕は、既定では表示しない。表示するときは、再生中の文の `text`（`content-format.md` §5.2）を、動画の枠の外（下）に表示する。動画の枠の中には表示しない。
- 字幕の表示・非表示を切り替えても、動画の大きさは変わらない。
- 音量・ミュート・再生速度・字幕の表示は、変えると設定（§8.2 の `video`）に保存し、次に再生するときも使う。

**キーボードショートカット**

| 操作 | キー |
|---|---|
| 再生／一時停止 | Space |
| 5 秒戻る／5 秒進む | ← / → |
| 前の文へ／次の文へ | Shift+← / Shift+→ |

- macOS と Windows で同じキーとする。
- 文字の入力欄（チャットの入力欄、ヘッダーの検索窓）にフォーカスがあるときは効かない。

## 6. 演習画面

```
┌─────────────────────────────────────────────────────────────────────────┐
│ ← 戻る   第4章 / 所有権のムーブ        [動画を見直す]                   │
├────────────────────┬────────────────────────────────────────────────────┤
│ 判定結果（提出後） │ [src/main.rs] [src/geo.rs] [+]  [初期コードに戻す] │
│ ✕ 不正解 2/3 [詳細]│                                                    │
├────────────────────┤ エディタ                                           │
│ 問題文             │                                                    │
│                    ├────────────────────────────────────────────────────┤
│                    │ コンソール              [▶ 実行] [提出] [■ 停止]   │
│                    │ 出力 …                                             │
│                    │ > 入力欄                           [入力終了]      │
└────────────────────┴────────────────────────────────────────────────────┘
```

- 左に問題文、右上にエディタ、右下にコンソールを配置する。左右と上下の境界はドラッグで幅・高さを変えられる。
- `multi` レイアウトでは、エディタ上部のタブでファイルを切り替え、`+` でファイルを追加する。ファイル操作の制約は `lesson-flow.md` §5.1 に従う。
- コンソールには、実行の出力（`exercise-runner.md` §4）と提出の経過（`exercise-runner.md` §5）を表示する。提出してもそれまでの出力は消さず、続けて表示する。
- コンパイラの出力は ANSI の色を反映して表示する。
- 実行中は「停止」ボタンと入力欄を有効にする（`exercise-runner.md` §4.2）。
- 「初期コードに戻す」「前回の正解コードを見る」の動作は `lesson-flow.md` §5 に従う。
- 動画がない演習（章末復習レッスン・生成問題）では「動画を見直す」を表示しない。

**判定結果**

- 提出の結果は、左の列の問題文の上にカードで表示する。表示する内容は `exercise-runner.md` §5.3 に従う。
- 不正解のときは、結果・通過数・提出した時刻だけを表示し、失敗したテストケースの名前と詳細は畳んでおく。「詳細を見る」で開閉する。
- ビルドに失敗したときは、テストを実行していないことと、エラーをコンソールに表示していることを示す。
- 次に提出すると、最新の結果に置き換え、詳細を畳んだ状態に戻す。

**正解したとき**

```
┌────────────────────────────────────────────────────────────────┐
│ ✓ 正解  3 件のテストがすべて通りました                    [×]  │
├──────────────────────────────────────┬─────────────────────────┤
│ [解説] [問題文] [提出したコード]     │ 解説について質問する    │
│                                      │                         │
│ 解説                                 │ チャット                │
│                                      │                         │
├──────────────────────────────────────┴─────────────────────────┤
│ [閉じてコードを見る]       [レッスン一覧へ] [次のレッスンへ]   │
└────────────────────────────────────────────────────────────────┘
```

- 正解すると、演習画面の上にモーダルを開く。
  - 左に解説を表示する。タブで「問題文」「提出したコード」に切り替えられる。
  - 右に解説への質疑応答を表示する（`qa-chat.md` §5）。
  - 下に「レッスン一覧へ」「次のレッスンへ」（生成問題は「生成問題一覧へ」）を表示する。
- 「閉じてコードを見る」または × でモーダルを閉じると、読み取り専用のエディタ（`lesson-flow.md` §1）でコードを見られる。画面下部に帯を表示し、「解説を開く」でモーダルを開き直せる。帯にも「レッスン一覧へ」「次のレッスンへ」（生成問題は「生成問題一覧へ」）を表示する。

**キーボードショートカット**

| 操作 | macOS | Windows |
|---|---|---|
| 実行 | Cmd+Enter | Ctrl+Enter |
| 提出 | Cmd+Shift+Enter | Ctrl+Shift+Enter |
| 停止 | Cmd+. | Ctrl+. |

エディタの文字サイズは設定画面で変更できる（既定 14px）。

## 7. 問題生成

### 7.1 生成問題一覧

- 表示内容と操作は `exercise-generation.md` §6 に従う。
- 画面上部に「新しい問題を生成」ボタンを置き、生成設定画面を開く。
- 生成問題がない場合は「まだ生成した問題はありません」と生成ボタンを表示する。

### 7.2 生成設定画面

- 設定項目と初期値は `exercise-generation.md` §2 に従う。
- 要素の選択欄は章ごとに折りたためるリストとし、各要素に習熟レベルのバッジ（未学習 / よく間違える / たまに間違える / 安定 / 得意、`provisional` の場合は「データ不足」を併記）を表示する。要素名にマウスを重ねると `description` を表示する。
- 難易度は 1〜5 の選択とし、選択中の難易度の目安を下に表示する。
- 「生成」ボタンで生成を依頼し、生成問題一覧に戻る。`claude` が見つからない場合はボタンを無効にする。

### 8.1 設定項目

| 動画 | 字幕 | 表示する / 表示しない（§5） |

| AI | 接続テスト | `claude-integration.md` §2 |
| 環境 | Rust ツールチェーン | 検出したパスとバージョン、パスの手動指定、再検出 |
| 環境 | Claude Code | 検出したパスとバージョン、パスの手動指定、再検出 |
| 環境 | クレートの準備 | 初回準備の状態と、失敗時の再試行（`exercise-runner.md` §2.3） |
| 学習データ | 学習記録をエディタで開く | `records/` ディレクトリを OS の既定アプリで開く |
| 学習データ | 分析ファイルをエディタで開く | `analysis/analysis.md` を OS の既定アプリで開く |

| 学習データ | 失敗したジョブ | `failed` のジョブの一覧（種類・対象・エラー内容）と再実行ボタン |

- リセット操作は確認ダイアログを表示してから実行する。「学習履歴をすべてリセット」は、確認ダイアログでテキスト「リセット」の入力を求める。

### 8.2 settings.json

```json
{
  "schema_version": 1,
  "theme": "system",
  "editor_font_size": 14,
  "video": { "volume": 1.0, "muted": false, "playback_rate": 1.0, "captions": false },
  "models": { "chat": "sonnet", "background": "opus" },
  "tool_paths": { "cargo": null, "claude": null },
  "first_launch_completed": true

```

- `video.volume` は 0.0〜1.0、`video.playback_rate` は §5 の再生速度のどれかとする。

## 9. レッスン検索

- ヘッダーの検索窓（「レッスン検索」と表示する）に入力すると、入力が止まってから 200ms 後に検索し、検索窓の下にドロップダウンで結果を表示する。
- 検索対象は、動画のある全レッスン（進捗に関係なく）の検索ワード（`lesson.json` の `tags`。`content-format.md` §4）とタイトルとする。
- 照合は部分一致とし、大文字・小文字と全角・半角の違いを無視する（NFKC 正規化と小文字化）。空白で区切った複数の語は、すべての語を含むレッスンに一致する。語ごとに、検索ワードとタイトルのどれかに含まれればよい。
- 結果はレッスン単位で、最大 20 件。すべての語がタイトルに含まれるものを先に、その中では学習順に並べる。各結果にレッスン名・章・一致した検索ワードを表示し、一致した部分を強調する。
- 結果を選ぶと、現在の画面の上にモーダルを開き、そのレッスンの動画を最初から再生できる状態で表示する。
  - 動画は、そのレッスンが属する章を指定して再生する（`content-format.md` §5.1）。動画の章カラーは、その章の色になる。
  - 自動では再生しない。プレーヤーの操作（キーボードショートカットを含む）と、音量などの設定の保存は §5 と同じとする。「演習へ」は表示しない。
  - 「このレッスンを開く」で、そのレッスンの動画画面に移る。開き方はレッスン一覧から開いたときと同じとする。
  - Esc またはモーダルの外側をクリックで閉じる。
- 検索用の索引はアプリ起動時にバックエンドで作る。

## 10. 見た目とテーマ

### 10.1 デザインシステム

- 画面の見た目（配色・書体・余白・角丸・アイコン・部品）は、デザインシステム「Progrust」（https://claude.ai/artifact/3Pn15TZ4nZ1H2u8cAfLosA ）に従う。
- 色・書体などの値はデザインシステムを唯一の定義とし、仕様書には書かない。使い方のルールはデザインシステムの README、部品ごとの使い方は各部品の README に従う。
- 開いている章の色（章カラー）を、その画面のアクセントにする。章カラーを使う範囲、章に属さない画面の色、章の数が章カラーの数を超えたときの割り当ては、デザインシステムの README「章カラー」「章外の画面」に従う。
- 動画の中身（動画の枠の中に描画するもの。`content-format.md` §5）の見た目は、このデザインシステムの対象外とし、動画のデザインシステム「Progrust Video」（https://claude.ai/artifact/QGt9Cb1cFYaA8TU7kY9bPq ）に従う。動画画面のプレーヤーの操作と字幕（§5）は、画面の一部として「Progrust」に従う。
  - 値は動画のデザインシステムを唯一の定義とし、仕様書には書かない。使い方のルールはその README（「動画の原則」など）、部品ごとの使い方は各部品の README に従う。
  - 書体・基本の色・章カラーなど、画面と共通の値は「Progrust」を正とし、動画のデザインシステムはその写しを持つ。値を変えるときは「Progrust」を変えてから写しを合わせる。
  - 動画で章カラーを使う範囲と、章に属さずに表示するときの色は、動画のデザインシステムの README「章カラーとの連動」に従う。

### 10.2 テーマ

- ライト・ダークの 2 つのテーマを持ち、設定に従って切り替える（「システムに合わせる」では OS の設定の変化に追従する）。
- 色はすべて CSS 変数で定義する。動画の色クラス（`content-format.md` §5.7）、Monaco Editor のテーマ、コンソールの ANSI カラーもテーマに合わせて切り替える。
- テーマを切り替えると、再生中の動画の色も、再生を止めずに切り替わる。

## 11. 通知

- 画面右下にトーストで通知する。通知するのは、問題生成の完了・失敗、ジョブの失敗（3 回失敗して `failed` になったとき）、アプリの更新があるとき。
- 学習記録・分析のジョブの成功は通知しない（ヘッダーのジョブ数の表示のみ）。

## 13. 受け入れ条件

- ウィンドウを最小サイズにしても、動画が 16:9 を保ったまま全体が表示され、プレーヤーの操作もすべて表示される。
- ダークモードに切り替えると、エディタ・コンソール・再生中の動画を含む全画面の色が切り替わる。動画の再生は止まらない。
- 第4章のレッスンの動画画面・演習画面では、主ボタン・章の番号・進み具合・正解の表示が第4章の章カラーで表示される。生成問題の演習画面では、これらが墨色で表示される。
- 動画画面を開いても、動画は自動では再生されない。
- 再生中に → を押すと 5 秒後に、Shift+→ を押すと次の文の頭に移り、再生が続く。チャットの入力欄に入力中に Space を押しても、再生と一時停止は切り替わらない。
- 字幕を表示すると、再生中の文の `text` が動画の枠の外に表示され、文が変わると切り替わる。字幕の表示と非表示を切り替えても、動画の大きさは変わらない。
- 音量・再生速度・字幕の表示を変えてアプリを再起動しても、同じ設定で再生される。
- 「ｏｗｎｅｒｓｈｉｐ」（全角）で検索しても、検索ワードに「ownership」を持つレッスンが見つかる。
- 検索ワードにない語でも、レッスンのタイトルに含まれていれば見つかる。
- 演習画面でレッスン検索の結果を開いて動画を再生し、閉じても、エディタのコードが失われない。
- 実行した後に提出して不正解になっても、実行の出力をコンソールでそのまま読める。
- 正解のモーダルを閉じた後も、「解説を開く」で解説とそれまでの質疑応答の会話を再び表示できる。
- 「学習履歴をすべてリセット」の後、トップページは学習記録がない状態の表示になり、全レッスンが未着手になる。
- 学習記録がない状態でトップページを開いてもエラーにならない。
