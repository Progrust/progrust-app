# レッスン進行・進捗管理 仕様書

レッスンの進め方（動画 → 演習 → 解説）、完了の判定、進捗と下書きの保存を定める。
各画面のレイアウトは `screens.md` に、試行セッションの開始・終了は `learning-record-and-analysis.md` §3.1 に定める。

## 1. レッスンの流れ

```
  ┌────── 「動画を見直す」 ──────┐
  ▼                              │
[動画] ──「演習へ」──▶ [演習（解答中）] ──提出で正解──▶ [演習（解説表示）]
                            │  ▲                              │
                            │  └─ 不正解なら解答を続ける      ├─「レッスン一覧へ」
                            └─ 実行・提出を繰り返す           └─「次のレッスンへ」
```

| 状態 | 説明 |
|---|---|
| 動画 | 動画画面で動画を再生する（プレーヤーの操作は `screens.md` §5）。「演習へ」で演習に進む |
| 演習（解答中） | 問題文・エディタ・コンソールを表示する。「動画を見直す」で動画画面に戻れる（下書きは保持される） |
| 演習（解説表示） | 正解すると解説を表示し（表示のしかたは `screens.md` §6）、質疑応答を使えるようにする。「レッスン一覧へ」「次のレッスンへ」を表示する |

- 「演習へ」は、動画を最後まで再生したときに表示し、以後そのレッスンでは表示し続ける（§3 の `video_watched`）。再生位置を移して動画の末尾に着いた場合も、最後まで再生したものとする。ただし、完了済みのレッスンでは動画画面を開いた時点から表示する。
- 「動画を見直す」で動画画面に戻ったときは、前回の再生位置（§3）から表示する。
- 章末復習レッスンは演習から始まる。
- 生成問題も演習から始まり、解説表示の後は「生成問題一覧へ」を表示する（`exercise-generation.md` §6）。
- 解説表示の状態で再度提出することはできない（エディタは読み取り専用にする）。

## 2. 受講順

- レッスンの受講順は制限しない。どのレッスンもレッスン一覧から開ける。
- 「次にやるべきレッスン」（推奨レッスン）を以下の順で決める。
  1. 完了していないレッスンのうち、最後に開いたレッスン（`last_opened_at` が最新）
  2. 1 がなければ、学習順（`content-format.md` §2）で最初の未完了レッスン
  3. すべて完了していれば、なし（トップページでは問題生成を案内する）
- 「次のレッスンへ」は学習順で次のレッスンを開く。最後のレッスンでは表示しない。

## 3. 進捗（progress.json）

```json
{
  "schema_version": 1,
  "lessons": {
    "ch04-03": {
      "status": "completed",
      "first_completed_at": "2026-10-31T13:25:00+09:00",
      "last_completed_at": "2026-10-31T13:25:00+09:00",
      "completion_count": 1,
      "last_opened_at": "2026-10-31T13:02:00+09:00",
      "last_sentence_id": "m5",
      "video_watched": true,
      "last_passed_session_id": "20261031T130200_ch04-03"
    }
  }
}
```

| フィールド | 説明 |
|---|---|
| `status` | `in_progress`（開いたことがあり未完了）/ `completed`。一度も開いていないレッスンはキーごと存在しない（未着手） |
| `first_completed_at` / `last_completed_at` | 最初・最後に正解した日時 |
| `completion_count` | 正解した回数（やり直しを含む） |
| `last_opened_at` | 最後に開いた日時 |
| `last_sentence_id` | 最後に再生していた文（`screens.md` §5 の再生中の文）の ID。まだ動画を再生していないときは `null` |
| `video_watched` | 動画を最後まで再生したことがあるか。「演習へ」の表示に使う（§1） |
| `last_passed_session_id` | 最後に正解した試行セッションの ID。正解コードの参照に使う |

- 動画画面を開いたとき、`last_sentence_id` の文の頭で一時停止した状態で表示する。`last_sentence_id` が `null` のときと、その ID の文が台本（`content-format.md` §5.2）にないときは、動画の先頭から表示する。
- `last_sentence_id` と `video_watched` は、`save_video_position` で保存する。保存するのは、再生中の文が変わったとき・一時停止したとき・最後まで再生したとき・動画画面を離れるときとする。
- レッスン検索のモーダル（`screens.md` §9）での再生は、`last_sentence_id` と `video_watched` に記録しない。
- 章末復習レッスンでは、`last_sentence_id` は `null`、`video_watched` は `false` のままとする。
- 生成問題の進捗は `progress.json` ではなく、生成問題のメタデータに記録する（`exercise-generation.md` §5）。
- 完了済みのレッスンをやり直して途中でやめても、`status` は `completed` のままとする。

## 4. 完了

- 提出で正解したとき、そのレッスンを完了とし、`progress.json` を更新する。
- 試行ログへの `passed_at` の記録と、試行セッションの終了・記録ジョブの登録は `learning-record-and-analysis.md` §3.1 に従う。

## 5. 下書き（drafts/{lesson_id}.json）

```json
{
  "lesson_id": "ch04-03",
  "updated_at": "2026-10-31T13:10:00+09:00",
  "files": { "src/main.rs": "fn main() { ... }" }
}
```

- エディタで編集したら、最後の編集から 1 秒後に保存する。実行・提出の直前と、画面を離れるときにも保存する。
- 演習を開いたとき、下書きがあれば復元し、なければ初期コードを表示する。
- 「初期コードに戻す」ボタンで、確認ダイアログの後、全ファイルを初期コードに戻す（下書きも上書きする）。
- 正解して試行セッションが終了したら、下書きを削除する。次に開いたときは初期コードから始まる。
- 完了済みのレッスンを開いたとき、「前回の正解コードを見る」ボタンを表示する。押すと、`last_passed_session_id` の試行ログのうち正解した `submit` イベントのファイルを、読み取り専用のモーダルで表示する。
- `multi` レイアウトで学習者がファイルを追加・削除・名前変更した場合も、下書きにはその時点の全ファイルを保存する。

### 5.1 multi レイアウトのファイル操作

- `src/` 以下に `.rs` ファイルを追加・削除・名前変更できる。
- `readonly_files` のファイルは編集・削除・名前変更できない。
- `src/main.rs` は削除・名前変更できない。
- `single` レイアウトではファイル操作はできない。

## 6. 受け入れ条件

- 未着手のレッスンを含め、レッスン一覧のどのレッスンも開ける。
- 動画の途中でアプリを終了して開き直すと、最後に再生していた文の頭で止まった状態で表示される。
- 動画を最後まで再生するまでは「演習へ」が表示されない。最後まで再生すると（シークで末尾に移した場合を含む）表示され、レッスンを開き直しても表示されたままになる。
- 完了済みのレッスンでは、動画画面を開いた時点で「演習へ」が表示される。
- 演習画面から「動画を見直す」で戻ると、前回の再生位置から表示される。
- レッスン検索のモーダルで動画を再生しても、そのレッスンの再生位置と「演習へ」の表示は変わらない。
- 台本が変わって `last_sentence_id` の文がなくなっていても、エラーにならず動画の先頭から表示される。
- 演習の途中でアプリを強制終了しても、開き直すと直前（1 秒前まで）のコードが復元される。
- 正解した後に同じレッスンを開くと初期コードから始まり、「前回の正解コードを見る」で正解時のコードを確認できる。
- 推奨レッスンが §2 の規則どおりに決まる。

## 7. 未決事項

- 動画を最後まで再生した後に開き直したとき、最後の文の頭から表示するか、動画の先頭から表示するか。いまは §3 のとおり、最後の文の頭から表示する。
