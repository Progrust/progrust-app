# ドキュメント

* [仕様](spec/index.md) - Progrust の現時点の仕様（概要、用語集、機能ごとの仕様、受け入れ条件、未決事項）があり、実装・修正するときと実装を確かめるときに読む。
* [設計判断記録（ADR）](decisions/index.md) - 仕様の「なぜ」（その仕様にした理由・変更した理由）を記録した ADR があり、仕様を変更・提案する前と実装・修正する前に、関連する判断を確かめるために読む。
* [技術検証の結果](verification/index.md) - 実装を始める前に行った技術検証（GitHub の Issue でラベル `技術検証` のもの）の結果があり、実装するときと、仕様を変える前に、検証で分かった事実を確かめるために読む。
* [運用ルール](conventions/index.md) - `documents/` の中の文書の置き場所、frontmatter、分割、リンク、`index.md`、仕様と ADR の書き方、検査についての決まりと、AI エージェントが見つけた問題を GitHub の Issue に起票するときの決まりと、実装計画・タスクの実装・レビュー・実装のループの決まりがあり、文書を追加・変更する前と、Issue を起票するときと、実装計画を作るとき・実装するときに読む。
