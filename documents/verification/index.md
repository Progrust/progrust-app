# 技術検証の結果

* [動画の描画チェックを CI で実行できるかの技術検証](issue-7-render-check-in-ci.md) - 教材チェックツールの動画の描画チェックと禁止事項の lint が CI で実行できるかを Issue #7 で検証した結果（画面なしの描画とエラー検出、ネットワークなしでの実行、Studio・チェックツール・Vite の 3 か所で同じコードが動くこと、ESLint と stylelint による禁止事項の検出と限界）を記す。
* [claude -p の隔離起動の技術検証](issue-8-claude-isolated-invocation.md) - claude -p を、ユーザー設定を読み込まず、ツールを使わせず、学習者のログイン状態のまま起動できるかを Issue #8 で検証した結果（フラグの組み合わせごとの効き方、--bare が OAuth を読まないこと、ツール無効の確認、設定ディレクトリに残るもの、推奨のフラグと再実行の 1 行のコマンド）を記す。
* [claude -p の出力の形とエラーの見分け方の技術検証](issue-9-claude-output-and-errors.md) - claude -p の json 出力から回答の本文を取り出せるか、stream-json で回答を少しずつ表示できるか、未ログインとモデル指定の誤りで終了コードと出力がどうなるかを Issue #9 で検証した結果（subtype が success のままになること、分類コードは stream-json にだけ出ること、エラーの文が標準出力に出ること、利用上限は未再現）を記す。
* [claude -p の子プロセスとしての扱いの技術検証](issue-10-claude-child-process.md) - claude -p を子プロセスとして扱えるかを Issue #10 で検証した結果（50 KB の日本語の標準入力、質疑応答とジョブの同時呼び出し、プロセスグループへの kill での子・孫プロセスの停止、Finder から起動したアプリでの claude の検出と認証、npm・Homebrew の探索先が決まっていないこと）を記す。
* [許可クレートのビルド結果の共有の技術検証](issue-12-reuse-prepared-crates.md) - 初回準備でビルドした許可クレートを、各演習が作り直さずに使えるかを Issue #12 で検証した結果（rand だけの今の一覧では作り直しなし、10 クレートの想定の一覧では feature の違いによる作り直し、Cargo.lock の不一致がエラーにならないこと、空のライブラリへの path 依存で作り直しがなくなること、空の main.rs で warmup が失敗すること）を記す。
* [検証と学習者の実行の並行ビルドの技術検証](issue-13-parallel-build-lock.md) - 問題生成の検証と学習者の実行が互いを待たせずに並行できるかを Issue #13 で検証した結果（同じビルド先でのロックの待ち、同じパッケージ名で相手の実行ファイルを使ってしまう誤り、初回準備中のパッケージキャッシュのロック、APFS のクローンなどでビルド先を分ける方法の比較）を記す。
* [隠しテストを読み込む #[path] の解決の技術検証](issue-14-hidden-test-path-resolution.md) - 隠しテストを読み込む `#[path]` が `judge.target` の場所によらず解決されるかを Issue #14 で検証した結果（`../` の数の決め方、絶対パス案、テスト名へのモジュール経路の付加、`use super::*;` の基準）を記す。
* [test 方式のテスト結果の読み取りの技術検証](issue-15-test-result-parsing.md) - test 方式の libtest の出力からテストごとの結果と panic メッセージを確実に読み取れるかを Issue #15 で検証した結果（出力形式、学習者の出力との混合、process::exit・abort・無限ループ、10 秒の制限での打ち切り、1 回起動する方式とテストごとに別プロセスで実行する方式の比較）を記す。
* [署名なしの macOS アプリの自動更新の技術検証](issue-19-updater-unsigned-macos.md) - 署名なしの macOS アプリで Tauri の自動更新が動くかと、GitHub Actions でのビルドと Releases への公開、Windows インストーラーの WebView2 導入処理を Issue #19 で検証した結果（App Translocation されると更新が失敗すること、quarantine 属性の値ごとの結果、private リポジトリの Releases を認証なしで取れないこと、ad-hoc 署名の有無による違い）を記す。
* [配布物と更新のサイズの技術検証](issue-20-distribution-size.md) - 音声・フォント・フロントエンド JS・Tauri の実行ファイルを含む配布物と更新のサイズを Issue #20 で検証した結果（音声の形式ごとのサイズ、142 レッスン分の見積もり、HE-AAC の扱い、Murecho のサイズ、Monaco と Remotion の JS、Tauri の updater が差分更新をしないこと、選択肢ごとのインストーラーのサイズ）を記す。
