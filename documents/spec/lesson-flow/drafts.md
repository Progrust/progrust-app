```json
{
  "schema_version": 1,
  "lesson_id": "ch04-04",
  "updated_at": "2026-10-31T13:10:00+09:00",
  "files": { "src/main.rs": "fn main() { ... }" }
}
```

- `schema_version` は下書きの形式の版で、いまは `1` とする（[データの互換性](../non-functional/data-compatibility.md)）。
- 読み込めない下書き（[データの保存場所](../architecture/data-locations.md)「書き込みの規則」と同じ条件）は、`.broken-{日時}` を付けて退避し、下書きが無いものとして扱う（初期コードを表示する）。
- エディタで編集したら、最後の編集から 1 秒後に保存する。実行・提出の直前と、画面を離れるときにも保存する。
- 演習を開いたとき、下書きがあれば復元し、なければ初期コードを表示する。
- 「初期コードに戻す」ボタンで、確認ダイアログの後、全ファイルを初期コードに戻す（下書きも上書きする）。
- 正解して試行セッションが終了したら、下書きを削除する。次に開いたときは初期コードから始まる。
- 完了済みのレッスン（動画のみのレッスンを除く）を開いたとき、「前回の正解コードを見る」ボタンを表示する。押すと、`last_passed_session_id` の試行ログのうち正解した `submit` イベントのファイルを、読み取り専用のモーダルで表示する。
- `multi` レイアウトで学習者がファイルを追加・削除・名前変更した場合も、下書きにはその時点の全ファイルを保存する。

## multi レイアウトのファイル操作

- `src/` 以下と `tests/` 以下に `.rs` ファイルを追加・削除・名前変更できる。
- `readonly_files` のファイルは編集・削除・名前変更できない。
- `src/main.rs` は削除・名前変更できない。
- `single` レイアウトではファイル操作はできない。
