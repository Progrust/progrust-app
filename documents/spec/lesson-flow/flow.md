---
type: Specification
title: "レッスンの流れ"
description: "動画、演習（解答中）、演習（解説表示）の 3 つの状態と遷移、「演習へ」の表示条件、章末復習レッスンと生成問題の始まり方、動画のみのレッスンの終わり方を定める。"
---

```
  ┌────── 「動画を見直す」 ──────┐
  ▼                              │
[動画] ──「演習へ」──▶ [演習（解答中）] ──提出で正解──▶ [演習（解説表示）]
                            │  ▲                              │
                            │  └─ 不正解なら解答を続ける      ├─「レッスン一覧へ」
                            └─ 実行・提出を繰り返す           └─「次のレッスンへ」
```

| 状態 | 説明 |
|---|---|
| 動画 | 動画画面で動画を再生する（プレーヤーの操作は [動画画面](../screens/video-screen.md)）。「演習へ」で演習に進む |
| 演習（解答中） | 問題文・エディタ・コンソールを表示する。「動画を見直す」で動画画面に戻れる（下書きは保持される） |
| 演習（解説表示） | 正解すると解説を表示し（表示のしかたは [演習画面](../screens/exercise-screen.md)）、質疑応答を使えるようにする。「レッスン一覧へ」「次のレッスンへ」を表示する（「次のレッスンへ」を表示しない場合と、開くレッスンは [レッスンの受講順](order.md)） |

- 「演習へ」は、動画を最後まで再生したときに表示し、以後そのレッスンでは表示し続ける（[進捗（progress.json）](progress.md) の `video_watched`）。再生位置を移して動画の末尾に着いた場合も、最後まで再生したものとする。ただし、完了済みのレッスンでは動画画面を開いた時点から表示する。動画のみのレッスンでは、どの場合も表示しない。
- 「動画を見直す」で動画画面に戻ったときは、前回の再生位置（[進捗（progress.json）](progress.md)）から表示する。
- 章末復習レッスンは演習から始まる。
- 動画のみのレッスンは動画だけで終わる。動画を最後まで再生したとき（「演習へ」と同じ決め方）に、動画画面に「次のレッスンへ」を表示し、以後そのレッスンでは表示し続ける（表示しない場合と、開くレッスンは [レッスンの受講順](order.md)）。レッスン一覧へは、動画画面の左上の「レッスン一覧」で移る（[動画画面](../screens/video-screen.md)）。完了の扱いは [レッスンの完了](completion.md) に従う。
- 生成問題も演習から始まり、解説表示の後は「生成問題一覧へ」を表示する（[生成問題一覧と生成問題の演習](../exercise-generation/list-and-exercise.md)）。
- 解説表示の状態で再度提出することはできない（エディタは読み取り専用にする）。
