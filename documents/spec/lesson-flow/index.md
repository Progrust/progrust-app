# レッスン進行・進捗管理

* [レッスン進行・進捗管理の目的とスコープ](scope.md) - レッスン進行・進捗管理の仕様が扱う範囲と、画面のレイアウトおよび試行セッションの開始・終了の参照先を定める。
* [レッスンの流れ](flow.md) - 動画、演習（解答中）、演習（解説表示）の 3 つの状態と遷移、「演習へ」の表示条件、章末復習レッスンと生成問題の始まり方、動画のみのレッスンの終わり方を定める。
* [レッスンの受講順](order.md) - レッスンの受講順を制限しないことと、準備中のレッスンを開けないこと、推奨レッスン（次にやるべきレッスン）の決め方、「次のレッスンへ」の動作を定める。
* [進捗（progress.json）](progress.md) - `progress.json` の形式と各フィールドの意味、動画の再生位置（`last_sentence_id`、`video_watched`）の保存と復元のしかた、動画のみのレッスンを完了にするときの値を定める。
* [レッスンの完了](completion.md) - 提出で正解したときにレッスンを完了とすること、動画のみのレッスンを動画の再生で完了とすること、`progress.json` の更新、試行ログと試行セッションの扱いの参照先を定める。
* [演習コードの下書き](drafts.md) - `drafts/{lesson_id}.json` の形式、下書きの保存と復元と削除の条件、「初期コードに戻す」と「前回の正解コードを見る」の動作、`multi` レイアウトで行えるファイル操作を定める。
* [レッスン進行・進捗管理の受け入れ条件](acceptance.md) - レッスン進行・進捗管理の仕様を満たしたと判断する条件を定める。
