---
type: Glossary
title: "画面に関する用語"
description: "デザインシステム、動画のデザインシステム、表示用のアーティファクト、画面デザイン、字幕、レッスン検索、章カラー、墨色の定義を定める。"
---

| 用語 | 英語表記（コード上の名前） | 定義 |
|---|---|---|
| デザインシステム | design system | 画面の見た目（配色・書体・余白・角丸・アイコン・部品）の定義と使い方をまとめたもの（[画面の見た目とテーマ](../screens/appearance.md)「デザインシステム」） |
| 動画のデザインシステム | video design system | 動画の中身（[レッスンの動画の形式（video/）](../content-format/video/index.md)）の見た目の定義と使い方をまとめたもの「Progrust Video」。画面のデザインシステムとは別に持つ（[画面の見た目とテーマ](../screens/appearance.md)「デザインシステム」） |
| 表示用のアーティファクト | display artifact | リポジトリのデザインシステムのファイルを送った、claude.ai のアーティファクト。部品の見本を表示するのに使い、ページでは編集しない（[デザインシステムのファイルと変更の手順](../screens/design-system-files.md)「表示用のアーティファクト」） |
| 画面デザイン | screen design | 各画面のレイアウト（部品の配置）を描いたもの「Progrust UIデザイン」（[画面の見た目とテーマ](../screens/appearance.md)「画面デザイン」） |
| 字幕 | captions | 再生中の文を、動画の枠の外に文字で表示する機能（[動画画面](../screens/video-screen.md)） |
| レッスン検索 | lesson search | 検索ワードとレッスンのタイトルから、レッスンを探す機能（[レッスン検索](../screens/lesson-search.md)） |
| 章カラー | chapter color | 章ごとに割り当てた色。開いている章の画面のアクセントになる。動画では、再生するときに指定された章の章カラーが主役の色になる（[画面の見た目とテーマ](../screens/appearance.md)「デザインシステム」、[動画の色の指定](../content-format/video/colors.md)） |
| 墨色 | ink | 本文の文字色。章に属さない画面ではアクセントにもなる（[画面の見た目とテーマ](../screens/appearance.md)「デザインシステム」） |
