# 用語集

* [用語集の目的と使い方](scope.md) - 用語集の目的と、新しい用語を導入する場合は用語集に追加するという運用を定める。
* [教材に関する用語](content.md) - 言語、章、レッスン、動画、台本、演習、要素、判定方式、メモリの検査など、教材に関する用語の英語表記と定義を定める。
* [学習の進行に関する用語](learning-progress.md) - 実行、提出、正解、完了、進捗、下書き、試行セッション、試行ログの定義と、「セッション」の書き分けを定める。
* [AI 連携に関する用語](ai-integration.md) - AI セッション、記録セッション、分析セッション、学習記録、分析ファイル、習熟レベル、ジョブ、質疑応答の定義を定める。
* [画面に関する用語](screens.md) - デザインシステム、動画のデザインシステム、画面デザイン、アプリのアイコン、字幕、レッスン検索、章カラー、墨色の定義を定める。
