---
type: Acceptance Criteria
title: "学習記録・分析の受け入れ条件"
description: "学習記録・分析の仕様を満たしたと判断する条件を定める。"
---

- Rust のレッスンに正解して「次のレッスンへ」を押すと、記録ジョブが登録され、完了後に `records/` に学習記録が保存され、続けて分析ジョブが実行される。
- 学習記録のアプリ管理フィールドは、AI が異なる値を出力しても試行ログから計算した値になっている。
- Rust のレッスンの正解後にアプリを強制終了して再起動すると、その試行セッションの記録ジョブが登録される。
- C のレッスンに正解して「次のレッスンへ」を押すと、試行ログの `ended_at` が記録されるが、記録ジョブは登録されず、`records/` に学習記録が作られず、`analysis.md` も変わらない。正解後にアプリを強制終了して再起動しても、記録ジョブは登録されない。
- C のレッスンの試行ログには、`chat`・`run`・`submit` のイベントが記録され、`files` のキーは `main.c` になる。
- 「分析を再構築」を実行しても、C のレッスンの試行ログは分析に入らない。
- 分析ファイルの `level` が `base_level ± 1` の範囲を超えることがない。
- `analysis.md` を手で壊した後に「分析を再構築」を実行すると、全記録から分析ファイルが作り直される。
- AI の出力が検証に失敗した場合、`records/`・`analysis/` のファイルは変更されない。
- 動画のみのレッスンを開いて完了しても、試行ログと学習記録が作られない。
