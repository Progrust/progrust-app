Claude Code 連携機能のうち「学習記録」「分析」に関する仕様を定める。
`claude -p` の呼び出し方とジョブキューは [Claude Code 連携](../claude-integration/index.md) に、本仕様のデータを画面や問題生成でどう使うかは [画面仕様](../screens/index.md)・[演習問題生成](../exercise-generation/index.md) に定める。
