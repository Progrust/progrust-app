---
type: Specification
title: "性能の目安"
description: "起動、再生開始、シーク、レッスン検索、実行・提出の処理時間の目安と、ジョブが画面操作を妨げないことを定める。"
---

| 項目 | 目安 |
|---|---|
| 起動してトップページを表示するまで | 3 秒以内 |
| 再生ボタンを押してから再生が始まるまで | 300ms 以内 |
| シークしてから絵が表示されるまで | 200ms 以内 |
| レッスン検索の結果表示 | 入力が止まってから 300ms 以内 |
| 実行・提出のアプリ側の処理時間（cargo・clang のビルドと、プログラムの実行時間を除く。C の演習のメモリリークの検査の起動も、プログラムの実行時間に含める） | 500ms 以内 |
| 学習記録・分析のジョブ | 画面の操作を妨げない（バックグラウンドで実行する） |
