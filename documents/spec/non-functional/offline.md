---
type: Specification
title: "オフライン時の動作"
description: "動画・実行・提出・初回準備・質疑応答・ジョブ・更新の確認など、機能ごとのオフライン時の動作を定める。"
---

| 機能 | オフライン時 |
|---|---|
| 動画・レッスン検索 | 利用できる（音声も同梱する） |
| 実行・提出 | 利用できる（初回準備が完了していれば、許可クレートを使う演習も利用できる） |
| 初回準備 | 失敗し、次回起動時に再実行する（[許可クレートと作業領域](../exercise-runner/crates-and-workspace.md)「初回準備」） |
| 質疑応答・問題生成 | エラーを表示する |
| 学習記録・分析のジョブ | 失敗してリトライする。3 回失敗したら `failed` になり、設定画面から再実行できる |
| 更新の確認 | 何も表示しない |
