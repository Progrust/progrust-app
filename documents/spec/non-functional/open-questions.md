「一般公開をする場合に決めること」「一般公開した後に決めること」は、アプリの完成までは、どれも決めない（[公開範囲と配布](distribution.md)、[対応環境](environments.md)）。

## 実装のときに決めること

- ログ（[アプリのログ](logging.md)）のファイル名、1 行の形式、日付の変わり目の決め方。
- `schema_version` を持つファイルの範囲。[データの互換性](data-compatibility.md) は「アプリが管理するファイルはすべて `schema_version` を持つ」とするが、下書き、試行ログ、生成問題の `meta.json`、`prepared.json` の形式には `schema_version` が無い。

## 一般公開をする場合に決めること

- 一般公開するかどうか。アプリの完成後に、作者が使ってみてから決める。
- 配布と更新の方法（配布物の形式と置き場所、自動更新を持つかどうか）と、そのために必要な検証。
- OS のコード署名（macOS の公証を含む）。
- Remotion のライセンス。公開するときの配布形態で必要なライセンスを確認する。2026-11-21 に調べた範囲では次のとおり。
  - 個人（商用を含む）・非営利・3 人以下の営利組織は無料で、それ以外は Company License が必要。Player での表示はレンダリングに数えない。
  - 今の規約（Remotion 4.0）には、デスクトップアプリに組み込んで配布することについての定めがない。
  - Remotion 5.0 の規約（5.0 のリリースで発効。まだリリースされていない）では、利用者が Remotion のコードを直接編集・アップロードできないようにすれば、Electron や Tauri のデスクトップアプリに組み込んで配布できる。人数には請負業者も数える。
- VOICEPEAK（夏色花梨）の音声をアプリに同梱して配布できるか。AHS に確認する。2026-11-21 に調べた範囲では次のとおり。
  - 非商用なら、音声を使った作品を無償で配布できる（使用許諾契約書の第10条、個人利用許諾範囲）。一方で、音声ファイルを素材として配布することは禁止されている（第14条）。「素材」の定義はなく、アプリに入れた音声ファイルがこれに当たるかは書かれていない。
  - 商用・業務用途には商用ライセンス（個人向けは製品ごとに 55,000 円（税込））が必要で、別のソフトウェアに組み込んで商用利用するときは問い合わせる（第13条）。有償で配布する作品の扱いは、個人利用許諾範囲の中で書き方が食い違っている。
  - 作品に声優名を書くことは禁止されている。ナレーターは `content/voice.json` で差し替えられる（[動画の音声](../content-format/video/voice.md)）。
- 書体（Murecho、Red Hat Mono）のファイルをアプリに同梱して配布できるか（ライセンス）。同梱するファイルは [画面の見た目とテーマ](../screens/appearance.md)「書体のファイル」。2026-11-21 に調べた範囲では、どちらも SIL Open Font License 1.1 で、著作権表示とライセンスの本文を含めればソフトウェアと一緒に配布できる。Red Hat Mono は、配布元の `OFL.txt` には予約フォント名が無いが、配布元の README には予約フォント名「Red Hat」と書かれている。
- 学習者の Claude Code をアプリから `claude -p` で呼び出すことが、Anthropic の利用規約に照らして問題ないか。文書だけでは決められないので、Anthropic に確認する。2026-11-21 に調べた範囲では次のとおり。
  - Claude Code の Legal and compliance のページは、他の開発者が自分の製品で claude.ai のログインを提供することと、利用者に代わってサブスクリプションの認証情報でリクエストを送ることを認めていない。一方で、利用者が改変していない Claude Code に自分のサブスクリプションでサインインすることは妨げないと書いている。
  - Consumer Terms は、API キーを使う場合と明示的に認めた場合を除き、スクリプトなどの自動の手段でサービスを使うことを禁じている。
  - 他の製品から `claude -p` を子プロセスとして起動することを、明示的に認める文も禁じる文も見つからなかった。
- 学習者が claude.ai のログイン以外の方法（`settings.json` の `apiKeyHelper`・`env` やシェルの環境変数による API キー、Bedrock、Vertex、プロキシなど）で Claude Code を使っている場合と、管理者の設定・管理プラグインが効く PC（会社の管理下の PC など）で使う場合に対応するか。アプリはユーザー設定を読み込まず、決めた環境変数だけを渡して `claude -p` を呼び、claude.ai のログインだけを使う（[claude -p の呼び出しの共通ルール](../claude-integration/invocation.md)「環境変数」「認証」）。

## 一般公開した後に決めること

- macOS の他のバージョン、Intel の Mac、Windows などの他の OS への対応。
