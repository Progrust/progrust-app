# 非機能要件

* [非機能要件の目的とスコープ](scope.md) - 非機能要件の仕様が扱う範囲（対応環境、オフライン時の動作、セキュリティ、公開範囲と配布、ログ、性能）を定める。
* [対応環境](environments.md) - 対応環境を作者の Mac（macOS、Apple Silicon）だけとすること、macOS の他のバージョンと他の OS を開発で考慮しないこと、学習者の環境に必要なものを定める。
* [対応言語](language.md) - UI・教材・AI の回答を日本語のみとすることを定める。
* [オフライン時の動作](offline.md) - 動画・実行・提出・初回準備・質疑応答・ジョブについて、機能ごとのオフライン時の動作を定める。
* [セキュリティとプライバシー](security-privacy.md) - 学習者のコードの実行、アプリ自体の制限、データの送信（Anthropic への送信の説明を含む）に関する方針を定める。
* [公開範囲と配布](distribution.md) - アプリを一般公開せずに作者が自分で使うこと、作者の Mac でビルドして使うこと、配布物・更新の仕組み・配布のためのコード署名を持たないこと、教材をアプリに同梱することを定める。
* [アプリのログ](logging.md) - ログの出力先、保持期間、記録する内容、本文を記録しないこと、設定画面からのフォルダの開き方を定める。
* [性能の目安](performance.md) - 起動、再生開始、シーク、レッスン検索、実行・提出の処理時間の目安と、ジョブが画面操作を妨げないことを定める。
* [データの互換性](data-compatibility.md) - `schema_version` による形式の変換、変換前ファイルの退避、教材の更新時に過去の記録を残す扱いを定める。
* [非機能要件の受け入れ条件](acceptance.md) - 非機能要件の仕様を満たしたと判断する条件を定める。
* [非機能要件の未決事項](open-questions.md) - 非機能要件の仕様でまだ決まっていない事項（一般公開をする場合に決めること: 公開するかどうか、配布と更新の方法、コード署名、Remotion・VOICEPEAK の音声・書体のライセンス、Anthropic の利用規約、claude.ai のログイン以外の認証と管理者の設定への対応。一般公開した後に決めること: macOS の他のバージョンと他の OS への対応）を記す。
