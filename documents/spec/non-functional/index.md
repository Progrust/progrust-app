# 非機能要件

* [非機能要件の目的とスコープ](scope.md) - 非機能要件の仕様が扱う範囲（対応環境、オフライン時の動作、セキュリティ、配布と更新、ログ、性能）を定める。
* [対応環境](environments.md) - 対応する OS（macOS、Windows）のバージョンとアーキテクチャ、学習者の環境に必要なものを定める。
* [対応言語](language.md) - UI・教材・AI の回答を日本語のみとすることを定める。
* [オフライン時の動作](offline.md) - 動画・実行・提出・初回準備・質疑応答・ジョブ・更新の確認など、機能ごとのオフライン時の動作を定める。
* [セキュリティとプライバシー](security-privacy.md) - 学習者のコードの実行、アプリ自体の制限、データの送信（Anthropic への送信の説明を含む）に関する方針を定める。
* [配布と更新](distribution.md) - GitHub Releases での配布、ビルド、インストーラーの形式、コード署名、Tauri の自動更新、更新の通知方法を定める。
* [アプリのログ](logging.md) - ログの出力先、保持期間、記録する内容、本文を記録しないこと、設定画面からのフォルダの開き方を定める。
* [性能の目安](performance.md) - 起動、再生開始、シーク、レッスン検索、実行・提出の処理時間の目安と、ジョブが画面操作を妨げないことを定める。
* [データの互換性](data-compatibility.md) - `schema_version` による形式の変換、変換前ファイルの退避、教材の更新時に過去の記録を残す扱いを定める。
* [非機能要件の受け入れ条件](acceptance.md) - 非機能要件の仕様を満たしたと判断する条件を定める。
* [非機能要件の未決事項](open-questions.md) - 非機能要件の仕様でまだ決まっていない事項（公開の可否とコード署名、署名なしの macOS での自動更新、Remotion のライセンス、VOICEPEAK の音声の配布可否）を記す。
