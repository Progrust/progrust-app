演習のコードをビルド・実行し、正誤を判定する仕組みを定める。
判定方式とテストケースの形式は [演習のファイル形式](../content-format/exercise.md)「判定方式」 に従う。C の演習（C のレッスンの演習）のファイルと判定方式は、同じく「C の演習」に従う。

Rust の演習（レッスンの演習のうち Rust のレッスンのものと、生成問題）と C の演習は、ビルドと判定の手順が違う。それぞれの手順の参照先は [コード実行・判定の概要](overview.md) にある。
