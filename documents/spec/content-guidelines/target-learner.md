---

- 他のプログラミング言語の経験がある人を対象とする。C と Rust の経験は前提にしない。
- 変数・条件分岐・ループ・関数といった一般的な概念は知っている前提とする。C の章では C の文法とメモリの扱いの説明に、Rust の章では Rust の文法と Rust 固有の概念（所有権・借用・ライフタイム・トレイトなど）の説明に集中する。
- ガベージコレクションのある言語（Python・JavaScript など）では意識しなくてよいが、Rust では意識する必要がある周辺知識（メモリの仕組み、参照の実体、コンパイル時と実行時の区別、スレッドとデータ競合など）は、既知としない。メモリの仕組みは、C の章で、演習を通して学ぶ。そのほかは、Rust のレッスンの中で説明する（扱うレッスンは [章とレッスンの一覧](../curriculum/chapters/index.md)）。
- 他言語との違いが躓きの原因になりやすい箇所は、違いを明示して説明する。Rust の章では、学習者が C の章を学んでいる前提で、C との違いも明示する（[動画の作成ルール](video.md)「C との対比」）。
