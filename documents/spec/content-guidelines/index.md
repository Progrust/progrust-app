# 教材作成ガイドライン

* [教材作成ガイドラインの目的とスコープ](scope.md) - 教材作成ガイドラインが扱う範囲と、ファイル形式の参照先、AI で教材を作る場合にもこのガイドラインを指示として与えることを定める。
* [想定する学習者](target-learner.md) - 教材が対象とする学習者（他のプログラミング言語の経験がある人）と、前提とする知識、他言語との違いの説明のしかたを定める。
* [教材作成におけるカリキュラムの決まり](curriculum.md) - 1 レッスンで扱う主要素の数と、各章の最後に章末復習レッスンを置くことを定め、章立ての参照先を示す。
* [未登場の要素を使わない](no-unseen-elements.md) - レッスンに登場させてよい要素の範囲と、どうしても未学習の構文が必要な場合の書き方を定める。
* [動画の作成ルール](video.md) - 動画の構成と長さ、台本（`text` と `say`）、画面の文章、コード、エラー、図、動きと画面の量について、教材作成時の内容面のルールを定める。
* [演習の作成ルール](exercise.md) - 演習の問題、テストケース、章末復習レッスン、解説について、教材作成時の内容面のルールを定める。
* [教材チェックツール](check-tool.md) - `tools/` の教材チェックツールで検証するチェック項目（エラーとして扱うもの）と、警告として扱う項目（動画の長さ、文の長さ、読み）を定める。
* [教材レビューのチェックリスト](review-checklist.md) - 機械的に検証できない項目について、教材のレビュー時に確認するチェックリストを定める。
* [教材作成ガイドラインの未決事項](open-questions.md) - 教材作成ガイドラインでまだ決まっていない事項（要素マスタ（`elements.json`）の用意、検索ワード（`tags`）の選び方）を記す。
