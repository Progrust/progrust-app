# 教材作成ガイドライン

* [教材作成ガイドラインの目的とスコープ](scope.md) - 教材作成ガイドラインが扱う範囲と、ファイル形式の参照先、AI で教材を作る場合にもこのガイドラインを指示として与えることを定める。
* [想定する学習者](target-learner.md) - 教材が対象とする学習者（他のプログラミング言語の経験がある人。C と Rust の経験は前提にしない）と、前提とする知識、既知としない周辺知識とそれを学ぶ場所、他言語との違いと C との違いの説明のしかたを定める。
* [教材作成におけるカリキュラムの決まり](curriculum.md) - Rust の 1 レッスンで扱う主要素の数と、C のレッスンが主要素・副要素を持たないこと、各レッスンの主要素を章とレッスンの一覧の定めに合わせること、動画のみのレッスンが扱う内容、各章の最後に章末復習レッスンを置くことを定め、章立ての参照先を示す。
* [要素の分け方と要素 ID の付け方](elements.md) - 要素マスタ（`content/elements.json`）の要素をレッスンを作る前にすべて定めておくこと、1 レッスン 1 要素を基本とする分け方と 2 つに分ける条件、要素にしないもの、要素 ID の形式と分類の一覧、`name`・`description`・`related_errors` の決め方、要素を足すときと分け方を変えるときの決まりを定める。
* [未登場の要素を使わない](no-unseen-elements.md) - Rust のレッスンに登場させてよい要素の範囲と、どうしても未学習の構文が必要な場合の書き方（「おまじない」と書かず、どんな処理かを説明して、どのレッスンで学ぶかを書くこと）、C のレッスンに Rust の要素を登場させないことと、Rust のレッスンに C の内容を登場させてよい場合を定める。
* [動画の作成ルール](video.md) - 動画の構成と長さ、台本（`text` と `say`）、ナレーションと画面（音声だけで分かること、画面の要素にはすべてナレーションで触れ、話す順に出すこと、読み上げるだけにしないことと読み上げてよい場面、コードは何のコードかから話すこと、指示語だけで指さないこと）、画面の文章、コード、エラー、C との対比、図、動きと画面の量について、教材作成時の内容面のルールを定める。
* [ナレーションでのコードの読み方](readings.md) - 動画のナレーション（`say`）でコードの記号・キーワード・型名・関数名をどう読むかを全レッスンでそろえるために、決まった語の読みを読みの対応表（`content/readings.json`）に持つことと、記号や型の組み合わせの読み方の決まり、読みに「、」を入れないこと、記号の読みと意味の言い方の使い分けを定める。
* [教材で使う訳語](terms.md) - 教材の言葉のゆれをそろえるために、教材で使う語と使わない語を訳語の表（`content/terms.json`）に持つことと、表に従う範囲、`&T` を「共有参照」・`&mut T` を「可変参照」と呼び「不変」を変数にだけ使うこと、カタカナ語の末尾の長音の扱い、表に語を足すときの決まりを定める。
* [実務での書き方を伝える](practice.md) - Rust のレッスン（動画・演習・解説）と生成問題で、実務での使われ方と近年のコミュニティの考え（避ける書き方、よく使われる書き方）を伝えることと、その根拠にする資料、意見が分かれる書き方と古い書き方の扱い、教材のコードの書式、未学習の要素を使う書き方への触れ方を定め、演習の題材の決まりの参照先を示す。C の章には当てはめない。
* [演習の作成ルール](exercise.md) - 演習の問題（Rust の演習を実務で出会う題材にすることを含む）、テストケース、章末復習レッスン、解説について、教材作成時の内容面のルールを定め、C の演習だけの決まりの参照先を示す。
* [C の章の教材の作成ルール](c-lessons.md) - C の章の教材について、目的と説明の深さ、前提とする C の規格とコンパイラ、既習の内容だけを使うこと、Rust に触れるときの決まり、動画に載せる出力とメモリの誤りの見せ方、演習の形・出力・模範解答・テストケース・章末復習レッスン・解説の決まりを定める。
* [教材チェックツール](check-tool.md) - `tools/` の教材チェックツールで検証するチェック項目（エラーとして扱うもの。C の章・C のレッスンの検査と、訳語の表の形式の検査を含む）と、「模範解答」「初期コード」をアプリと同じ判定処理（バックエンドの判定のコマンドラインのプログラム。C のレッスンは C の判定処理）で判定する方法、macOS でないときに C のレッスンを判定しないこと、準備中のレッスンの扱い、警告として扱う項目（動画の長さ、文の長さ、読み、判定しなかった C のレッスン）を定める。
* [教材レビューのチェックリスト](review-checklist.md) - 機械的に検証できない項目について、教材のレビュー時に確認するチェックリストを定める。
* [教材作成ガイドラインの未決事項](open-questions.md) - 教材作成ガイドラインでまだ決まっていない事項（検索ワード（`tags`）の選び方）を記す。
