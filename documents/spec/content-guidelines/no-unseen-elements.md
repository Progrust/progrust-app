---
type: Specification
title: "未登場の要素を使わない"
description: "Rust のレッスンに登場させてよい要素の範囲と、どうしても未学習の構文が必要な場合の書き方（「おまじない」と書かず、どんな処理かを説明して、どのレッスンで学ぶかを書くこと）、C のレッスンに Rust の要素を登場させないことと、Rust のレッスンに C の内容を登場させてよい場合を定める。"
---

- Rust のレッスン（動画・演習・解説）には、そのレッスンの主要素と既習の要素以外の Rust の要素を登場させない。動画のみのレッスンには主要素がないので、既習の要素だけを登場させる。
- 既習の要素と導入レッスンの定義は [章とレッスンの並びの形式（chapters.json）](../content-format/chapters-json.md) に従う。
- `secondary_elements` には既習の要素だけを書く（教材チェックツールで検証する）。
- コード中の構文が未登場でないことは、レビュー時にチェックリスト（[教材レビューのチェックリスト](review-checklist.md)）で確認する（教材チェックツールでは検証しない）。
- どうしても未学習の構文が必要な場合（例: 標準入力の読み込み）は、`starter/` の中に完成した形で用意する。そのうえで、コードのコメントか問題文で、その部分がどんな処理かを簡単に説明し、どのレッスンで詳しく学ぶかを、レッスンの番号とタイトルで書く（例: 「標準入力から名前を 1 行読み込み、前後の空白と改行を取り除く（読み込み方は 9-5「標準入力を読む」で詳しく学ぶ）」）。
  - 「おまじない」と書かない。学習者を、仕組みを理解できない人のように扱う言い方だからである。何をするものかを言わずに「とりあえず書く」とだけ書くことも、同じ理由でしない。
- C のレッスンには、Rust の要素を登場させない（c01-01 の動画の例外と、C のレッスンに登場させてよい C の内容は [C の章の教材の作成ルール](c-lessons.md)「Rust に触れるとき」「既習の内容だけを使う」）。
- Rust のレッスンの動画と解説には、C との対比のために、C の章で扱った内容（[章とレッスンの一覧](../curriculum/chapters/index.md) の C の章の「主に扱う内容」）の C のコードを登場させてよい（[動画の作成ルール](video.md)「C との対比」）。Rust の演習では、学習者に C のコードを書かせない。
