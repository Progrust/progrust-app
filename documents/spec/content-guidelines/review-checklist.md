---

機械的に検証できない項目は、教材のレビュー時に確認する。

- [ ] 未登場の構文・関数・型を使っていない（[未登場の要素を使わない](no-unseen-elements.md)）
- [ ] 画面の見出しが、そのとき伝えていることを言い切る文になっている（[動画の作成ルール](video.md)「画面の文章」）
- [ ] ライト・ダークのどちらのテーマでも、動画の文字と図が読める
- [ ] 音声を聞いて、`say` の読み間違いと不自然な間がない（[動画の作成ルール](video.md)「台本」）
- [ ] コードの読み方が [ナレーションでのコードの読み方](readings.md) に従っている
- [ ] 教材の文の語が [教材で使う訳語](terms.md) に従っている（`&T` を「不変参照」と呼んでいないなど）
- [ ] `say` を順に聞くだけで、画面を見なくても話の筋が分かる（[動画の作成ルール](video.md)「ナレーションと画面」）
- [ ] 画面に出すもの（見出し・本文・callout・図のラベル・コード）に、どれもナレーションで触れ、触れるときに出している（[動画の作成ルール](video.md)「ナレーションと画面」）
- [ ] ナレーションが画面の文を読み上げるだけになっていない。画面の文と同じ内容を話した文の前後で、意味や理由を説明している（まとめの項目を除く）。同じ内容を話すときも「です・ます」調のままで、画面の常体・体言止めをそのまま読んでいない（[動画の作成ルール](video.md)「ナレーションと画面」）
- [ ] コードが初めて出たところで、行を指す前に、何をするコードかを言っている（[動画の作成ルール](video.md)「ナレーションと画面」）
- [ ] 画面の上のものを、指示語だけで指していない（[動画の作成ルール](video.md)「ナレーションと画面」）
- [ ] 合図が言葉に合っている（[動画の作成ルール](video.md)「動きと画面の量」）
- [ ] 寄せ方、文字の大きさ、動き、1 画面に載せる量が、動画のデザインシステムの「動画の原則」に従っている（[動画の作成ルール](video.md)「動きと画面の量」）
- [ ] 再生位置を途中に移しても、その位置の絵が正しく表示される（[動画のシーンの書き方](../content-format/video/scenes.md)）
- [ ] 画面に出すコードを TSX に書き写していない（[動画でのコードの表示](../content-format/video/code-display.md)）
- [ ] エラーをエラーコードだけで説明していない（[動画の作成ルール](video.md)「エラー」）
- [ ] 文で指した行番号が、表示される行番号と合っている（[動画の作成ルール](video.md)「コード」）
- [ ] 図の中にコード（文や式）を書いていない（[動画の作成ルール](video.md)「図」）
- [ ] Rust のレッスンで、実務での使われ方を伝えていて、「実務では」「コミュニティでは」と言う内容に根拠がある（[実務での書き方を伝える](practice.md)）
- [ ] 模範解答と動画のコードが rustfmt の既定の書式で、Clippy の既定の警告が出ない（誤りや避ける書き方を見せるコードを除く。[実務での書き方を伝える](practice.md)「教材のコード」）
- [ ] 未学習の構文を「おまじない」と書かず、どんな処理かと、詳しく学ぶレッスンを書いている（[未登場の要素を使わない](no-unseen-elements.md)）
- [ ] Rust の演習が、実務で出会う題材になっている（[演習の作成ルール](exercise.md)「問題」）
- [ ] 問題文にヒントやコード例が含まれていない
- [ ] 問題文だけで入出力の形式が一意に決まる
- [ ] 主要素（C の演習では、そのレッスンの「主に扱う内容」）を理解していないと解けない問題になっている
- [ ] 解説の「よくある間違い」が実際のエラーメッセージと一致している
- [ ] C のレッスンで、既習でない C の構文・関数・型を使っていない（[C の章の教材の作成ルール](c-lessons.md)「既習の内容だけを使う」）
- [ ] C のレッスンの動画に載せたコンパイラの出力・実行結果・メモリの検査の報告が、実際に得た出力である（[C の章の教材の作成ルール](c-lessons.md)「動画」）
- [ ] C の演習の出力が、アドレスの値や未定義動作の結果に左右されない（[C の章の教材の作成ルール](c-lessons.md)「演習」）
- [ ] Rust のレッスンで、章とレッスンの一覧が C のレッスンの ID を添えている内容を、C と対比して説明している（[動画の作成ルール](video.md)「C との対比」）
