コードの読み方は、全レッスンで同じにする。レッスンによって読み方が変わると、学習者が同じものだと気づけないからである。

## 読みを書く場所

- 決まった語（キーワード、型名、関数名、マクロ名、ツールの名前）の読みは、読みの対応表（`content/readings.json`。[動画の音声](../content-format/video/voice.md)）に書く（例: `mut` → ミュート、`Vec` → ベクタ、`char` → キャラ）。
- 記号と、型や変数の組み合わせの読み方は、下の「組み合わせの読み方」に従う。変数名（s1 → エスワン）の読み方は [動画の作成ルール](video.md)「台本」に従う。
- 対応表にも下の表にもない語や形がコードに出たときは、読みを決め、決まった語は対応表に、形の決まりはこの文書に足す。すでにあるものと違う読みを、レッスンの中だけで使わない。
- 読みには「、」を入れない。音声を作るツールが、句読点の数と音声の中の間の数を合わせるからである（[動画の音声](../content-format/video/voice.md)「音声を作るツール」）。間が要るときは、`say` の文の中で「、」を入れる。

## 記号の読みと意味の言い方

- 画面のコードの字句をそのまま指すときは、記号の読み（下の表の「読み」）を使う。働きを説明するときは、意味の言い方（下の表の「意味の言い方」）を使う。
- 記号がレッスンで初めて出たところでは、記号の読みと意味の言い方の両方を言う（例: 「アンドエス、つまり、エスの共有参照を渡します」）。

## 組み合わせの読み方

| 書き方 | 読み | 意味の言い方・補足 |
|---|---|---|
| `&s` | アンドエス | エスの共有参照 |
| `&mut s` | アンドミュートエス | エスの可変参照 |
| `*r` | アスタリスクアール | アールの参照外し |
| `::`（`String::from`） | コロンコロン（ストリングコロンコロンフロム） | ストリングのフロム関数 |
| `->`（`-> i32`） | アロー（アローアイサンニ） | 戻り値の型を示す |
| `=>` | ファットアロー | match の腕の矢印 |
| `s.len()` | エスドットレン | 呼び出しの `()` は読まない |
| `?` | はてな演算子 | |
| `'a` | ライフタイムエー | |
| `Vec<T>`・`Vec<i32>`・`Result<T, E>` | ティーのベクタ・アイサンニのベクタ・ティーとイーのリザルト | 型引数は、中の型を先に言う |
| `0..10`・`0..=10` | ドットドット・ドットドットイコール | ゼロから十未満・ゼロから十まで |
| `\|x\|` | 引数エックスのクロージャ | |
| `==`・`!=`・`&&`・`\|\|` | 等しい・等しくない・かつ・または | 比較と論理の演算子は、意味の言い方で読む |
| `#[derive(Debug)]` | デライブデバッグの属性 | |
| `println!`・`vec!`・`format!` | プリントライン・ベクタマクロ・フォーマットマクロ | `println!` は「マクロ」を付けずに読む。マクロであることを説明するときは「プリントラインマクロ」と言う |
| 行番号（6 行目） | 漢数字（六行目） | |
