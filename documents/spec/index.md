# 仕様

* [Progrust の概要](overview.md) - Progrust の目的、想定する学習者、技術構成の概要、機能の一覧、画面、教材の大枠と、詳細を定める仕様書の対応を定める。
* [用語集](glossary/index.md) - 仕様書・実装・UI で使う用語を、教材、学習の進行、AI 連携、画面に分けて定める。
* [アーキテクチャ](architecture/index.md) - アプリ全体の技術構成、フロントエンドとバックエンドの役割分担、外部ツールへの依存、データの保存場所を定める。
* [教材データ形式](content-format/index.md) - アプリに同梱する教材（章・レッスン・動画・演習・要素マスタ）のファイル形式を定める。
* [カリキュラム](curriculum/index.md) - 章立てと学習順、各レッスンで主に扱う内容と主要素を定める。
* [教材作成ガイドライン](content-guidelines/index.md) - 教材（動画・演習）を作るときの内容面のルールと、要素の分け方、教材チェックツール、レビューのチェックリストを定める。
* [コード実行・判定](exercise-runner/index.md) - 演習のコードをビルド・実行し、正誤を判定する仕組みを定める。
* [レッスン進行・進捗管理](lesson-flow/index.md) - レッスンの進め方（動画、演習、解説）、完了の判定、進捗と下書きの保存を定める。
* [Claude Code 連携](claude-integration/index.md) - `claude -p` の呼び出し方、モデルの選択、ジョブキューなど、AI を使うすべての機能に共通するルールを定める。
* [質疑応答](qa-chat/index.md) - 動画や解説について、チャット形式で AI に質問する機能を定める。
* [学習記録・分析](learning-record-and-analysis/index.md) - 試行ログ、学習記録ファイル、分析ファイルの形式と、記録・分析の AI ジョブを定める。
* [演習問題生成](exercise-generation/index.md) - 学習者の設定と分析ファイルをもとに、AI が演習問題を生成する機能を定める。
* [画面仕様](screens/index.md) - 各画面の表示内容・操作・画面遷移と、全画面に共通する UI（ヘッダー、レッスン検索、見た目とテーマ、通知）、デザインシステムのファイルの置き場所と変更の手順を定める。
* [非機能要件](non-functional/index.md) - 対応環境、オフライン時の動作、セキュリティ、公開範囲と配布、ログ、性能などを定める。
