## 目的

- Rust の各要素ごとに、動画で知識をインプットし、コーディングエディタで演習問題を解く、という流れを細かく繰り返して Rust を学ぶ。
- Rust の前に C 言語を学ぶ。C の章で、メモリを手で管理する難しさを演習で体験し、その後の Rust の章で、Rust がそれをどう扱うかを C と対比して学ぶ（[カリキュラムの方針](curriculum/policy.md)）。
- AI（Claude Code）が演習ごとに学習者の特徴を分析・記録し、その内容をもとに学習者に適した演習問題を生成する。
- AI は動画や演習問題の内容について質疑応答も行う。

## 想定する学習者

- 他のプログラミング言語の経験がある人。C と Rust の経験は前提にしない（詳細は [想定する学習者](content-guidelines/target-learner.md)）。

## 技術構成の概要

- Tauri を利用したネイティブアプリケーションとし、macOS を対象とする。
- Rust の演習のコードは、学習者の環境の Rust ツールチェーンでビルド・実行する。C の演習のコードは、学習者の環境の `clang` でビルド・実行する。
- Claude Code とは `claude -p` で連携する。
- 詳細は [アーキテクチャ](architecture/index.md)、対応環境・公開範囲などは [非機能要件](non-functional/index.md)。

## 機能

| 機能 | 概要 | 仕様書 |
|---|---|---|
| レッスン | 「動画 1 本 + 演習問題 1 問」を 1 レッスンとし、章ごとに分類する。各章の最後に演習のみの章末復習レッスンを置く。演習に正解するとレッスン完了。周辺知識だけを扱うレッスンは動画のみとし、動画を最後まで再生すると完了 | [レッスン進行・進捗管理](lesson-flow/index.md) |
| 動画 | ナレーションつきの 16:9 の動画。全レッスンで統一したデザイン。コードと図を動かして分かりやすさを重視する | [教材データ形式](content-format/index.md) |
| 演習 | 問題文・エディタ・コンソールを 1 画面に表示する。複数ファイルに対応し、実行（動作確認）と提出（正誤判定）ができる。C の演習は 1 ファイルで、提出ではメモリの検査も行う。正解後に解説を表示する | [コード実行・判定](exercise-runner/index.md)、[画面仕様](screens/index.md) |
| 質疑応答 | 動画の再生中と、演習の正解後の解説表示中に、AI にチャットで質問できる | [質疑応答](qa-chat/index.md) |
| 学習記録 | Rust のレッスンと生成問題の終了時に、演習の解き方・躓いた箇所・スムーズに解けた箇所を AI が Markdown で記録する | [学習記録・分析](learning-record-and-analysis/index.md) |
| 分析 | 学習記録をもとに、得意・苦手分野をレベル分けし、時間軸（最近扱っていない分野など）も含めて AI が分析ファイルを更新し続ける。記録とは別の AI セッションで行う | [学習記録・分析](learning-record-and-analysis/index.md) |
| 演習問題生成 | 苦手分野を中心にするか、扱う要素、難易度、AI へのメッセージを設定して、AI が演習問題を生成する | [演習問題生成](exercise-generation/index.md) |
| レッスン検索 | ヘッダーの検索窓から、検索ワードとタイトルでレッスンを検索し、動画をモーダルで表示する | [画面仕様](screens/index.md) |
