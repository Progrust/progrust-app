title: "動画でのコードの表示"
description: "`code_blocks` の `language` ごとの表示、行番号と Diff の表示、共通部品 `CodeBlock` の指定（`scopes`・`marks`・`errors`・`lines`）とその制約を定める。"
---

画面に出すコードとコンパイラの出力は、台本の `code_blocks` に書き、共通部品 `CodeBlock` で表示する。同じコードを TSX に書き写さない。

**言語（`language`）**

| 値 | 用途 | 表示 |
|---|---|---|
| `rust` | Rust のコード | シンタックスハイライトする |
| `c` | C のコード | シンタックスハイライトする |
| そのほかの言語名（例: `python`、`toml`） | Rust・C 以外の言語のコード | シンタックスハイライトしない |
| `plaintext` | ターミナルの出力ではないテキスト（入力ファイルの中身など） | シンタックスハイライトしない |
| `text` | ターミナルの出力（コンパイラ・cargo の出力、プログラムの実行結果、標準入力とのやりとり） | 行番号を表示しない。rustc の出力、clang の診断（`error:`・`warning:`・`note:`）、メモリの検査の報告は色付けする |

**行番号と Diff**

- `language` が `text` 以外のコードブロックには、左に行番号を表示する。行番号はファイルの行番号である。
- ファイルの途中から載せるときは、`start_line` に、載せた 1 行目のファイルでの行番号を書く。
- `diff` が `true` のコードブロックは、Diff として表示する。`code` の各行の先頭の 1 文字に `+`（追加）・`-`（削除）・半角空白（変わらない行）を書き、その後ろにコードを書く。空の行は変わらない行として扱う。削除行には行番号を表示せず、行番号は変更後のファイルの行番号になる。`start_line` と併用するときは、変更後のファイルで最初の行の番号を書く。
- 表示する最後の行番号は 999 以下とする。
- この決まりに違反する `code_blocks`（`start_line` が 1 以上の整数でない、Diff の行の先頭が `+`・`-`・半角空白のどれでもない、999 を超える行番号）は、教材チェックツール（[教材チェックツール](../../content-guidelines/check-tool.md)）でエラーとする。

**`CodeBlock` の指定**

| 指定 | 内容 |
|---|---|
| `block` | 表示する `code_blocks` の `id` |
| `scopes` | 変数が生きている範囲を枠で示す。範囲ごとに、ラベルと開始行・終了行を書く（例: `{ label: "r", from: 2, to: 7 }`） |
| `marks` | 字句を強調する（マーカー）。字句ごとに、行番号と、その行の中の文字列を書く（例: `{ line: 3, text: "s1" }`） |
| `errors` | エラーの箇所に波線を引く。書き方は `marks` と同じとする |
| `lines` | 行ごとの動き。行番号ごとに、行の差し込み（`open`）・入力の進み具合（`typed`）・淡くする度合い（`dim`）を 0〜1 で書く |

- 指定に書く行番号は、`code_blocks` の行番号（`code` の 1 行目を `start_line` として数えた番号。Diff では変更後のファイルの行番号）とする。行を差し込む動きの途中でも、この番号で書く。`language` が `text` のコードブロックの `lines` では、1 から数えた行の位置で書く。
- `scopes` の範囲は 1 つのコードブロックに 3 つまで、入れ子は 2 段までとする。範囲の一部だけが重なる指定はできない。範囲は `code_blocks` の行番号の中に収める。`diff` が `true` のコードブロックでは使わない。
- `marks` と `errors` は、字句単位で指定する。同じ文字列がその行に複数あるときは、何個目かを `nth`（1 始まり。省略時は 1）で指す。`language` が `text` のコードブロックでは使わない。
- `scopes`・`marks`・`errors` の 1 件ごとに、進み具合（`progress`。0〜1。省略時は 1）を書いて、現れ方を動かせる。
- 行を差し込む動きでは、まだ差し込んでいない行を数えずに行番号を表示する。差し込みが終わると、表示される行番号は `code_blocks` の行番号と同じになる。
- この節の制約に違反する指定（範囲の重なり・入れ子・個数の違反、`code_blocks` の行番号の外の範囲と行、その行にない字句、`text` の中の `marks`・`errors`、`code_blocks` にない `id`）は、描画時にエラーになる。教材チェックツールは、これを描画のチェック（[教材チェックツール](../../content-guidelines/check-tool.md)）で検出する。
- `CodeBlock` にない動きが要るときは、レッスン専用の部品を作ってよい。その場合も、この節の表示の決まりと [動画の色の指定](colors.md) に従う。
