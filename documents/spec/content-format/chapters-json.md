[章とレッスンの一覧](../curriculum/chapters/index.md) に定めた章立てと学習順を、アプリが読む形式で表したものとする。内容は [章とレッスンの一覧](../curriculum/chapters/index.md) と一致させる（教材チェックツールで検証する: [教材チェックツール](../content-guidelines/check-tool.md)）。

```json
[
  {
    "id": "ch04",
    "title": "所有権",
    "description": "Rust のメモリ管理の中心となる所有権の仕組みを学ぶ",
    "lessons": ["ch04-01", "ch04-02", "ch04-03", "ch04-review"]
  }
]
```

C の章は、`language` を持つ。

```json
[
  {
    "id": "c02",
    "title": "ポインタとメモリ",
    "description": "変数がメモリのどこに置かれるかを知り、ポインタでアドレスを扱う方法と、スタックとヒープの使い方を学ぶ",
    "language": "c",
    "lessons": ["c02-01", "c02-02", "c02-review"]
  }
]
```

- `language` は、章が教えるプログラミング言語で、`"c"`（C の章）か `"rust"`（Rust の章）とする。省略したときは `rust` とする。レッスンの言語は、属する章の言語とする。
- 章 ID は、Rust の章は `ch{NN}`、C の章は `c{NN}`（`NN` は 2 桁の数字）とする。
- C の章は、配列の中で、すべての Rust の章より前に並べる。
- 配列の順序が章の学習順、`lessons` の順序が章内の学習順である。
- 全レッスンをこの順に一列に並べたものを「学習順」と呼ぶ。「過去のレッスン」は学習順で前にあるレッスンを指す。
- 要素の「導入レッスン」は、学習順で最初にその要素を主要素とするレッスンとする。各レッスンの主要素は [章とレッスンの一覧](../curriculum/chapters/index.md) の「主要素」で決まり、準備中のレッスンにも決まっている。`kind` が `lesson` のレッスンの `lesson.json` の `primary_elements` は、これと同じである（[レッスン定義の形式（lesson.json）](lesson-json.md)）。章末復習レッスンの主要素は、同じ章の前のレッスンの主要素から選ぶので、要素を導入しない。C の章のレッスンは要素を持たないので、要素の導入レッスンにも既習の要素にも関わらない（[レッスン定義の形式（lesson.json）](lesson-json.md)「C のレッスン」）。
- あるレッスンにとっての「既習の要素」は、導入レッスンが学習順でそのレッスンより前にある要素とする。
- 各章の最後のレッスンは章末復習レッスン（`{章 ID}-review`。例: `ch04-review`、`c03-review`）とする。

## 章とレッスンの番号

- 章の番号は、同じ言語の章の中での位置（その言語の最初の章を 1 とする）とする。Rust の章は、`chapters.json` の Rust の章の中での位置、C の章は、C の章の中での位置である（例: `ch04` は Rust の第4章、`c02` は C の第2章）。
- レッスンの番号は、「{章の番号}-{そのレッスンの `lessons` での位置（最初のレッスンを 1 とする）}」とする（例: 第4章の 4 番目のレッスンは `4-4`）。章末復習レッスンと準備中のレッスンにも、同じ決め方で番号を付ける（例: 6 レッスンの後に置いた第4章の章末復習レッスンは `4-7`）。
- 画面と動画に出す章とレッスンの番号は、この番号とする。表示の形は、言語で変わる。

| 言語 | 章の表示 | レッスンの表示 |
|---|---|---|
| Rust | 第4章 | `4-4` |
| C | C 第1章 | `C1-4` |

- 章カラーは、章の番号で決まる（[画面の見た目とテーマ](../screens/appearance.md)「デザインシステム」）。C の第1章は、Rust の第1章と同じ色になる。

## 準備中のレッスン

- `chapters.json` にあるレッスンのうち、レッスンのディレクトリ（`content/lessons/{lesson_id}/`。[教材のディレクトリ構成](directory-structure.md)）が無いものを「準備中のレッスン」とする。
- ディレクトリがあり、必要なファイルが欠けているレッスンは、準備中のレッスンではない。教材チェックツールの「構成」のエラーになる（[教材チェックツール](../content-guidelines/check-tool.md)）。
- 学習順には、準備中のレッスンも含む。
