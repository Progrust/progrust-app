description: "教材データ形式の仕様でまだ決まっていない事項（アプリの画面の CSS が動画の中にも効くことの扱い、レッスン専用の CSS で動画のデザインシステムの部品を上書きしてよいか、音声を作るツールが「、」にあたる無音を見つける方法、アプリがテーマと章を動画に渡す方法、プレーヤーの部品の設定）を記す。"
---

- アプリの画面の CSS が、動画の中にも効くこと（レッスン専用の CSS の閉じ込めは、ほかへの向きだけである。[動画を構成するファイル](video/structure.md)）の扱い。
- レッスン専用の CSS で、動画のデザインシステムの部品（`callout` など）の見た目を上書きしてよいか。
- 音声を作るツール（[動画の音声](video/voice.md)）が、できた音声の中の「、」にあたる無音を見つける方法（無音とみなす音量と長さ、文の途中の「。」にあたる無音との見分け方）。
- アプリが、再生するときにテーマと章（[動画を構成するファイル](video/structure.md)）を動画に渡す方法（祖先の要素の属性と CSS 変数の継承で渡すか、プレーヤーの入力の値として渡すか）。
- プレーヤーの部品（Remotion の Player）の設定のうち、アプリの操作（[動画画面](../screens/video-screen.md)）と重ならないようにするためのもの（部品の既定の操作とキー操作を使わない設定）。
