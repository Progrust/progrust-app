```
┌─────────────────────────────────────────────────────────────────────────┐
│ ← レッスン一覧   第4章 / 所有権のムーブ        [動画を見直す]           │
├────────────────────┬────────────────────────────────────────────────────┤
│ 判定結果（提出後） │ [src/main.rs] [src/geo.rs] [+]  [初期コードに戻す] │
│ ✕ 不正解 2/3 [詳細]│                                                    │
├────────────────────┤ エディタ                                           │
│ 問題文             │                                                    │
│                    ├────────────────────────────────────────────────────┤
│                    │ コンソール     [▶ 実行] [テスト] [提出] [■ 停止]   │
│                    │ 出力 …                                             │
│                    │ > 入力欄                           [入力終了]      │
└────────────────────┴────────────────────────────────────────────────────┘
```

- 左に問題文、右上にエディタ、右下にコンソールを配置する。左右と上下の境界はドラッグで幅・高さを変えられる。
- `multi` レイアウトでは、エディタ上部のタブでファイルを切り替え、`+` でファイルを追加する。ファイル操作の制約は [演習コードの下書き](../lesson-flow/drafts.md)「multi レイアウトのファイル操作」 に従う。
- コンソールには、実行の出力（[コードの実行（run）](../exercise-runner/run.md)）と提出の経過（[コードの提出（submit）](../exercise-runner/submit.md)）を表示する。提出してもそれまでの出力は消さず、続けて表示する。
- コンソールに残す出力は、末尾の 64K 文字までとする。超えたら古いほうから消し、先頭に「古い出力を省略しました」と表示する。
- コンパイラの出力は ANSI の色を反映して表示する。
- 「テスト」ボタンは、学習者が書いたテストを実行する（[コードの実行（run）](../exercise-runner/run.md)「テスト実行」）。どの演習でも表示する。
- 実行・テスト実行のビルド中と実行中は「停止」ボタンを有効にする（[コードの実行（run）](../exercise-runner/run.md)「停止」）。提出中は「停止」ボタンを無効にする（[コードの提出（submit）](../exercise-runner/submit.md)）。実行中は入力欄も有効にする（[コードの実行（run）](../exercise-runner/run.md)「対話的な標準入力」）。テスト実行では入力欄を表示しない。
- 「初期コードに戻す」「前回の正解コードを見る」の動作は [演習コードの下書き](../lesson-flow/drafts.md) に従う。
- 動画がない演習（章末復習レッスン・生成問題）では「動画を見直す」を表示しない。
- 左上のリンクは、レッスン（章末復習レッスンを含む）の演習では「レッスン一覧」でレッスン一覧に、生成問題の演習では「生成問題一覧」で生成問題一覧に移る。動画画面へは「動画を見直す」で移る。
- 実行・テスト実行・提出の途中で演習画面を離れたとき（左上のリンク、「動画を見直す」、ヘッダーのメニューなど）は、それを止める（[コードの実行（run）](../exercise-runner/run.md)「停止」、[コードの提出（submit）](../exercise-runner/submit.md)「途中で止めた提出」）。提出の途中でも、確認せずに画面を移る。

**判定結果**

- 提出の結果は、左の列の問題文の上にカードで表示する。表示する内容は [コードの提出（submit）](../exercise-runner/submit.md)「判定結果」 に従う。
- 不正解のときは、結果・通過数・提出した時刻だけを表示し、失敗したテストケースの名前と詳細は畳んでおく。「詳細を見る」で開閉する。
- ビルドに失敗したときは、テストを実行していないことと、エラーをコンソールに表示していることを示す。
- 提出が `crates_unavailable` で終わったとき（[コードの提出（submit）](../exercise-runner/submit.md)「判定をしなかった提出」）は、カードを新しく表示せず、前の提出のカードがあればそのまま残す。
- 次に提出すると、最新の結果に置き換え、詳細を畳んだ状態に戻す。

**正解したとき**

```
┌────────────────────────────────────────────────────────────────┐
│ ✓ 正解  3 件のテストがすべて通りました                    [×]  │
├──────────────────────────────────────┬─────────────────────────┤
│ [解説] [問題文] [提出したコード]     │ 解説について質問する    │
│                                      │                         │
│ 解説                                 │ チャット                │
│                                      │                         │
├──────────────────────────────────────┴─────────────────────────┤
│ [閉じてコードを見る]       [レッスン一覧へ] [次のレッスンへ]   │
└────────────────────────────────────────────────────────────────┘
```

- 正解すると、演習画面の上にモーダルを開く。
  - 左に解説を表示する。タブで「問題文」「提出したコード」に切り替えられる。
  - 右に解説への質疑応答を表示する（[質疑応答の画面](../qa-chat/screen.md)）。
  - 下に「レッスン一覧へ」「次のレッスンへ」（生成問題は「生成問題一覧へ」）を表示する。「次のレッスンへ」が開くレッスンと、表示しない場合は [レッスンの受講順](../lesson-flow/order.md) に従う。
- 「閉じてコードを見る」または × でモーダルを閉じると、読み取り専用のエディタ（[レッスンの流れ](../lesson-flow/flow.md)）でコードを見られる。画面下部に帯を表示し、「解説を開く」でモーダルを開き直せる。帯にも「レッスン一覧へ」「次のレッスンへ」（生成問題は「生成問題一覧へ」）を表示する。

**キーボードショートカット**

| 操作 | キー |
|---|---|
| 実行 | Cmd+Enter |
| テスト実行 | Cmd+Shift+T |
| 提出 | Cmd+Shift+Enter |
| 停止 | Cmd+. |

- ショートカットは、エディタにフォーカスがあるときも、エディタの外にあるときも効く。エディタの中では、Monaco Editor の既定の割り当て（Cmd+Enter での行の挿入など）より優先する。
- ただし、質疑応答の入力欄にフォーカスがあるときは効かない。入力欄の Cmd+Enter は送信である（[質疑応答の画面](../qa-chat/screen.md)）。
- 日本語の変換中は、ショートカットとして扱わない。

エディタの文字サイズは設定画面で変更できる（既定 14px）。
