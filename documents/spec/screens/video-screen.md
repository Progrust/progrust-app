```
┌──────────────────────────────────────────────────┬──────────────┐
│ ← レッスン一覧   第4章 / 所有権のムーブ          │              │
│ ┌──────────────────────────────────────────────┐ │  チャット    │
│ │                                              │ │  パネル      │
│ │                 動画（16:9）                 │ │  （開閉可）  │
│ │                                              │ │              │
│ └──────────────────────────────────────────────┘ │              │
│                字幕（オンのとき）                │              │
│ ──────┼────●─────────┼──────────────┼─────────── │              │
│ [▶] 0:42 / 1:44  [-5秒] [+5秒]                   │              │
│ [1倍] [音量] [字幕]                   [演習へ ▶] │              │
└──────────────────────────────────────────────────┴──────────────┘
```

- 動画は表示領域に収まる最大のサイズで、16:9 を保って表示する。動画の描画方法は [レッスンの動画の形式（video/）](../content-format/video/index.md) に従う。
- 動画は、そのレッスンが属する章を指定して再生する（[動画を構成するファイル](../content-format/video/structure.md)）。
- 動画の下にプレーヤーの操作を置く。
- チャットパネルの動作は [質疑応答の画面](../qa-chat/screen.md) に従う。

**プレーヤーの操作**

| 操作 | 動作 |
|---|---|
| 再生／一時停止 | 再生と一時停止を切り替える |
| シークバー | 再生位置を表示する。押した位置・ドラッグした位置に再生位置を移す。シーンの区切り（各シーンの開始位置。[動画のタイムラインと合図](../content-format/video/timeline-and-cues.md)）に印を表示する |
| 時間 | 現在の再生位置と、動画全体の長さを表示する |
| 5 秒戻る／5 秒進む | 再生位置を 5 秒前・5 秒後に移す。動画の先頭・末尾を越えるときは、先頭・末尾に移す |
| 再生速度 | 0.75・1・1.25・1.5・2 倍から選ぶ |
| 音量とミュート | 音量を変える。ミュートを切り替える |
| 字幕 | 字幕の表示と非表示を切り替える |
| 演習へ | 演習画面に移る。表示する条件は [レッスンの流れ](../lesson-flow/flow.md) に従う。動画のみのレッスンでは表示しない |
| 次のレッスンへ | 動画のみのレッスンだけで、「演習へ」の位置に表示する。開くレッスンは [レッスンの受講順](../lesson-flow/order.md) に従う。表示する条件は [レッスンの流れ](../lesson-flow/flow.md) に従う |

- 再生中の文は、開始位置が再生位置と同じかそれより前の文のうち、最後の文とする。最初の文が始まる前は、最初の文とする。文の頭は、その文の開始位置（[動画のタイムラインと合図](../content-format/video/timeline-and-cues.md)）とする。
- 再生位置を移しても、再生中か一時停止中かは変わらない。
- 画面を開いても自動では再生しない。開いたときの再生位置は [進捗（progress.json）](../lesson-flow/progress.md) に従う。
- 最後まで再生したら、末尾で止まる。
- 字幕は、既定では表示しない。表示するときは、再生中の文の `text`（[動画の台本（script.json）](../content-format/video/script-json.md)）を、動画の枠の外（下）に表示する。動画の枠の中には表示しない。
- 字幕を表示しないときも、動画の下に字幕の場所を空けておく。字幕の表示・非表示を切り替えても、動画の大きさと、プレーヤーの操作の位置は変わらない。
- 音量・ミュート・再生速度・字幕の表示は、変えると設定（[設定画面と settings.json](settings-screen.md)「settings.json」 の `video`）に保存し、次に再生するときも使う。

**読み込み中と、読み込みに失敗したとき**

- 動画（動画のコード、台本、音声の長さ）を読み込んでいる間は、動画の枠の中に、読み込み中であることを示す回る印を表示する。
- 読み込みに失敗したときは、動画の枠の中に「動画を読み込めませんでした」と「もう一度読み込む」ボタンを表示する。「もう一度読み込む」で、もう一度読み込む。
- 読み込みが済むまでと、失敗したときは、再生できない。「演習へ」と「次のレッスンへ」を表示する条件（[レッスンの流れ](../lesson-flow/flow.md)）は、読み込みの状態によらない。

**キーボードショートカット**

| 操作 | キー |
|---|---|
| 再生／一時停止 | Space |
| 5 秒戻る／5 秒進む | ← / → |

- 文字の入力欄（チャットの入力欄、ヘッダーの検索窓）にフォーカスがあるときは効かない。
