---
type: Acceptance Criteria
title: "画面仕様の受け入れ条件"
description: "画面仕様を満たしたと判断する条件を定める。"
---

- ウィンドウを最小サイズにしても、動画が 16:9 を保ったまま全体が表示され、プレーヤーの操作もすべて表示される。
- ダークモードに切り替えると、エディタ・コンソール・再生中の動画を含む全画面の色が切り替わる。動画の再生は止まらない。
- 第4章のレッスンの動画画面・演習画面では、主ボタン・章の番号・進み具合・正解の表示が第4章の章カラーで表示される。生成問題の演習画面では、これらが墨色で表示される。
- 動画画面を開いても、動画は自動では再生されない。
- 再生中に → を押すと 5 秒後に移り、再生が続く。チャットの入力欄に入力中に Space を押しても、再生と一時停止は切り替わらない。
- 字幕を表示すると、再生中の文の `text` が動画の枠の外に表示され、文が変わると切り替わる。字幕の表示と非表示を切り替えても、動画の大きさは変わらない。
- 音量・再生速度・字幕の表示を変えてアプリを再起動しても、同じ設定で再生される。
- 「ｏｗｎｅｒｓｈｉｐ」（全角）で検索しても、検索ワードに「ownership」を持つレッスンが見つかる。
- 検索ワードにない語でも、レッスンのタイトルに含まれていれば見つかる。
- 演習画面でレッスン検索の結果を開いて動画を再生し、閉じても、エディタのコードが失われない。
- 実行した後に提出して不正解になっても、実行の出力をコンソールでそのまま読める。
- 1 MB を出力するプログラムを実行しても、コンソールの表示が固まらず、末尾の出力と「古い出力を省略しました」が表示される。
- 正解のモーダルを閉じた後も、「解説を開く」で解説とそれまでの質疑応答の会話を再び表示できる。
- 「学習履歴をすべてリセット」の後、トップページは学習記録がない状態の表示になり、全レッスンが未着手になる。
- 学習記録がない状態でトップページを開いてもエラーにならない。
- 次にやるべきレッスンが第4章にあるとき、トップページの章ごとの完了率に第2〜10章の 9 章だけが表示される。
- レッスン一覧で、準備中のレッスンには番号と「準備中」だけが表示される。
- 7 レッスンのうち 2 レッスンが準備中の章で 3 レッスンを完了すると、レッスン一覧の章の完了数は 3 / 5 になる。トップページの完了レッスン数と全レッスン数にも、準備中のレッスンは数えられない。
- すべてのレッスンが準備中の章は、レッスン一覧の章の完了数とトップページの章ごとの完了率の代わりに「準備中」と表示される。
- 準備中のレッスンがあっても、レッスン検索はエラーにならず、準備中のレッスンは結果に出ない。
- 本番ビルドの `.app` は、Finder で、白い地に 4 つの色で塗り分けた「P」のアイコンで表示される。
- レッスン一覧で、「C 言語編」の見出しの下に C の章が、その後の「Rust 編」の見出しの下に Rust の章が表示される。C のレッスンの番号は `C1-2` の形で、Rust のレッスンの番号は `4-4` の形で表示される。
- C 第1章のレッスンの動画画面・演習画面では、左上に「C 第1章」と表示され、Rust の第1章と同じ章カラーで表示される。
- 次にやるべきレッスンが C 第1章にあるとき、トップページの章ごとの完了率に C 第1〜3章と Rust の第1〜6章の 9 章が表示される。
- C のレッスンを完了すると、トップページの完了レッスン数と、レッスン一覧のその章の完了数が増える。
- C の演習に正解しても、学習記録がない状態のトップページには「Rust の演習に正解すると、ここに分析が表示されます」と表示されたままになる。
- C の演習の演習画面では、エディタのタブが `main.c` だけで、`+` と「テスト」ボタンが表示されない。Cmd+Shift+T を押しても、何も起きない。エディタでは C のコードが色分けされる。
- C の演習で、解放した領域を読むコードを提出すると、判定結果のカードの詳細に、誤りの種類の名前（解放後の使用）と `main.c` の行が見出しとして表示され、その下に検査の報告が表示される。
- `clang` が見つからないとき、C の演習では「実行」「提出」ボタンが無効になり、`xcode-select --install` のコマンドが案内される。Rust の演習は実行・提出でき、動画も再生できる。トップページには環境の警告のバナーが表示される。
- 初回起動画面と設定画面に、`clang` の検出結果が `cargo`・`claude` と並んで表示される。`clang` が見つからないときは、URL を開かずに `xcode-select --install` のコマンドが表示される。
- 設定画面で `clang` のパスを指定して保存すると、`settings.json` の `tool_paths.clang` に保存され、検出し直される。
- `tool_paths` に `clang` の無い版 `1` の `settings.json` があるときにアプリを起動すると、ほかの設定を保ったまま版 `2` に変換され、`tool_paths.clang` が `null` になる。変換前の `first_launch_completed` が `true` なら、初回起動画面は表示されない。
- 生成設定画面の要素の選択欄に、C の章が表示されない。
- レッスン検索で、C のレッスンの検索ワードやタイトルに含まれる語（例: 「malloc」）で検索すると、C のレッスンが見つかる。
