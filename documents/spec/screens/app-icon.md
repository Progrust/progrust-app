## 絵柄

- アプリのアイコンは、白い地に、4 つの色で塗り分けた「P」を置いた絵である。
- 「P」は、端と角の丸い太い線で描く。書体（Murecho）の字形は使わない。
- 「P」の線は、下から順に 4 つに区切り、次の色で塗る。

  | 区切り | 色 |
  |---|---|
  | 縦の線の下半分 | 第1章の章カラー（ライトテーマの値） |
  | 縦の線の上半分と、左上の角 | 第2章の章カラー（ライトテーマの値） |
  | 丸い部分の上半分 | 第3章の章カラー（ダークテーマの値） |
  | 丸い部分の下半分 | 第4章の章カラー（ライトテーマの値） |

- 地は白で、下へ向かってわずかに暗くする。地の縁に、墨色の淡い細い線を引く。
- 色の値は、元の絵のファイル（下の「ファイル」）を正とする。上の表の章カラー（デザインシステム「Progrust」のトークン `chapter-1`〜`chapter-4`）は、絵を決めたときに値を取った元である。アイコンの色は、トークンの値に連動しない。トークンの値を変えても、アイコンの色は変わらない。
- アプリのアイコンは、画面の中で使うアイコン（[画面の見た目とテーマ](appearance.md)「デザインシステムの CSS とアイコン」）とは別のものである。

## 形と余白

- 元の絵は、1024 × 1024 の大きさで描く。中央の 824 × 824 の角丸四角（角の半径 185）に地を描き、まわりの 100 は透明にする。
- macOS は、`.app` のアイコンを、システムの角丸の形に切り抜いて表示する。元の絵に、影は描かない。

## ファイル

| ファイル | 内容 |
|---|---|
| `src-tauri/app-icon.svg` | 元の絵。手で書く |
| `src-tauri/icons/icon.icns` | macOS のアイコンのファイル。本番ビルドの `.app` に入る |
| `src-tauri/icons/32x32.png`、`128x128.png`、`128x128@2x.png` | 32・128・256 の大きさの PNG |
| `src-tauri/icons/icon.png` | 512 の大きさの PNG。Tauri の設定には書いていない |

- `src-tauri/icons/` のファイルは、元の絵から作るファイルで、手で書かない（下の「変える手順」）。
- Tauri の設定（`src-tauri/tauri.conf.json` の `bundle.icon`）には、`icon.icns` と 3 つの PNG（`32x32.png`、`128x128.png`、`128x128@2x.png`）を書く。

## 変える手順

1. `src-tauri/app-icon.svg` を直す。
2. `npm run icon` を実行する（[開発環境と依存の版](../architecture/development-environment.md)「開発で使うコマンド」）。
   - このコマンドは、Tauri CLI（`tauri icon`）で、元の絵からアイコンのファイルを `src-tauri/target/app-icon/` に作り、上の表の `src-tauri/icons/` の 5 つのファイルだけを `src-tauri/icons/` に写す。
   - Tauri CLI は、このアプリで使わないファイル（Windows・iOS・Android のためのもの）も作る。これらは `src-tauri/icons/` に写さない。
   - `icon.icns` は、元の絵が同じでも、作り直すたびに中の画像の並びが変わり、ファイルの中身が変わる。PNG は変わらない。
3. 本番ビルド（`npm run build`）を行い、できた `.app` のアイコンを Finder で確かめる。
4. 絵柄か色を変えたときは、この文書の「絵柄」も直す。
