## デザインシステム

- 画面の見た目（配色・書体・余白・角丸・アイコン・部品）は、デザインシステム「Progrust」（https://claude.ai/artifact/3Pn15TZ4nZ1H2u8cAfLosA ）に従う。
- 色・書体などの値はデザインシステムを唯一の定義とし、仕様書には書かない。使い方のルールはデザインシステムの README、部品ごとの使い方は各部品の README に従う。
- 開いている章の色（章カラー）を、その画面のアクセントにする。章カラーを使う範囲、章に属さない画面の色、章の数が章カラーの数を超えたときの割り当ては、デザインシステムの README「章カラー」「章外の画面」に従う。
- 動画の中身（動画の枠の中に描画するもの。[レッスンの動画の形式（video/）](../content-format/video/index.md)）の見た目は、このデザインシステムの対象外とし、動画のデザインシステム「Progrust Video」（https://claude.ai/artifact/QGt9Cb1cFYaA8TU7kY9bPq ）に従う。動画画面のプレーヤーの操作と字幕（[動画画面](video-screen.md)）は、画面の一部として「Progrust」に従う。
  - 値は動画のデザインシステムを唯一の定義とし、仕様書には書かない。使い方のルールはその README（「動画の原則」など）、部品ごとの使い方は各部品の README に従う。
  - 書体・基本の色・章カラーなど、画面と共通の値は「Progrust」を正とし、動画のデザインシステムはその写しを持つ。値を変えるときは「Progrust」を変えてから写しを合わせる。
  - 動画で章カラーを使う範囲と、章に属さずに表示するときの色は、動画のデザインシステムの README「章カラーとの連動」に従う。

## デザインシステムの写し

- デザインシステムの CSS（トークンの `tokens.css` と、部品のクラスの `components/bundle.css`）とアイコン（`assets/Icons/`）は、リポジトリに写しを置いて使う。置き場所は [リポジトリ構成](../architecture/repository.md)。
- 写しは編集しない。値や部品を変えるときは、デザインシステムを変えてから、写しを取り直す。
  - 例外として、写しの中の、書体を外部から読み込む `@import` の行は取り除く。書体は、同梱したファイルから読む（下の「書体のファイル」）。
- 写しを取ったときのデザインシステムの版と日付を、写しと同じディレクトリに記録する。
- アプリの画面のための CSS と、動画の共通部品のための CSS は、写しとは別のファイルに書く。
- デザインシステムの README（使い方のルール、部品ごとの使い方）は写さない。デザインシステムを読む。

## 画面デザイン

- 各画面のレイアウト（部品の配置）は、画面デザイン「Progrust UIデザイン」（https://claude.ai/artifact/SL7VXW5D7weHs8tLG9zHNx ）に従う。
- 画面を実装した後は、その画面については、実装を正とする。

## 書体のファイル

- 書体（Murecho、Red Hat Mono）のファイルはアプリに同梱し、画面と動画の両方で使う。
- 同梱するのは、それぞれの配布元が配っている可変フォントのファイルで、形式の変換やサブセット化をせず、そのまま使う。

  | 書体 | 配布元 | ファイル |
  |---|---|---|
  | Murecho | https://github.com/positype/Murecho-Project | `fonts/variable/Murecho[wght].ttf` |
  | Red Hat Mono | https://github.com/RedHatOfficial/RedHatFont | `fonts/Mono/RedHatMono/variable/RedHatMono-VF.ttf` |

- それぞれの書体のライセンスの本文（配布元の `OFL.txt`。著作権表示を含む）も同梱する。

## テーマ

- ライト・ダークの 2 つのテーマを持ち、設定に従って切り替える（「システムに合わせる」では OS の設定の変化に追従する）。
- 色はすべて CSS 変数で定義する。動画の色クラス（[動画の色の指定](../content-format/video/colors.md)）、Monaco Editor のテーマ、コンソールの ANSI カラーもテーマに合わせて切り替える。
- テーマを切り替えると、再生中の動画の色も、再生を止めずに切り替わる。
