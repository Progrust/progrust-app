---
type: Specification
title: "トップページ（ダッシュボード）"
description: "トップページに表示する項目（環境の警告、次にやるべきレッスン、学習の進み具合、苦手分野、復習推奨、総評など）と、章ごとの完了率に表示する 9 章の選び方（C の章を含む学習順）、学習記録がないときや `analysis.md` を解析できないときの表示を定める。"
---

| 表示項目 | 内容・データ |
|---|---|
| 環境の警告 | `cargo` / `claude` が見つからない、初回準備中・失敗、の場合にバナーを表示する（[外部ツール（cargo・claude）への依存](../architecture/external-tools.md)）。`clang` が見つからない場合も、バナーを表示する（[C のツール（clang）への依存](../architecture/c-toolchain.md)「見つからない場合」） |
| 次にやるべきレッスン | [レッスンの受講順](../lesson-flow/order.md) で決まるレッスンのタイトル・章・概要と「続きから」（未着手なら「始める」）ボタン。次にやるべきレッスンがなければ問題生成への案内 |
| 学習の進み具合 | 完了レッスン数 / 全レッスン数（どちらも C のレッスンを含み、準備中のレッスン（[章とレッスンの並びの形式（chapters.json）](../content-format/chapters-json.md)「準備中のレッスン」）を数えない）、9 章ぶんの章ごとの完了率（下記）とレッスン一覧への入口 |
| 苦手分野 | `level` 1〜2 かつ `provisional: false` の要素の上位 3 件。level が低い順、同じ level 内では `last_stumbled` が新しい順 |
| 復習推奨 | `review_due: true` の要素 |
| 定着度が低下した要素 | `regressed: true` の要素 |
| 学習ペース | `activity.last_4_weeks` の週ごとの記録数 |
| 総評 | 分析ファイル本文の「総評」セクション（アプリが本文から取り出すのはこのセクションのみ） |

- 章ごとの完了率は、9 章ぶんだけを表示する。章は、C の章と Rust の章をあわせて、学習順（[章とレッスンの並びの形式（chapters.json）](../content-format/chapters-json.md)。C の章が先）に並べたものとする。表示するのは、この並びで、次にやるべきレッスンの章の 2 つ前の章から続く 9 章とする。最初の章より前や最後の章より後にはみ出す分は、反対側にずらす（例: 次にやるべきレッスンが C 第1章なら C 第1〜3章と Rust の第1〜6章、Rust の第1章なら C 第2・3章と Rust の第1〜7章、Rust の第4章なら Rust の第2〜10章）。次にやるべきレッスンがなければ、最後の 9 章を表示する。章が 9 章以下なら、すべての章を表示する。すべての章の完了数は、[レッスン一覧画面](lesson-list.md) で見る。
- 章ごとの完了率の数え方と、準備中でないレッスンが 1 つも無い章の表示（完了率の代わりに「準備中」）は、[レッスン一覧画面](lesson-list.md) の章の完了数と同じとする。
- 苦手分野・復習推奨・定着度が低下した要素の各要素から、その要素を選択した状態の生成設定画面を開ける。
- 分析ファイルのデータは `analysis.md` の frontmatter から取る（[分析ファイル（analysis/analysis.md）](../learning-record-and-analysis/analysis-file.md)）。
- 学習記録がまだない場合、分析に関する項目の代わりに「Rust の演習に正解すると、ここに分析が表示されます」と表示する。
- `analysis.md` を解析できない場合は、分析に関する項目の代わりに「分析ファイルを読み込めません」と、設定画面の「分析を再構築」への案内を表示する。
