# 画面仕様

* [画面仕様の目的とスコープ](scope.md) - 画面仕様が扱う範囲（各画面と全画面に共通する UI、デザインシステムと画面デザインのファイルの置き場所と変更の手順、アプリのアイコン）と、画面で使うデータの意味や計算方法を担当仕様書に任せることを定める。
* [全画面に共通するレイアウト](common-layout.md) - 全画面に表示するヘッダーとジョブ数の表示、ウィンドウの最小サイズと初期サイズ、UI の文言を日本語のみとすることを定める。
* [画面一覧と画面遷移](screen-transitions.md) - アプリの全画面（トップページ、レッスン一覧、動画画面、演習画面、生成問題一覧、設定画面など）の一覧と、画面どうしの遷移を定める。
* [トップページ（ダッシュボード）](top-page.md) - トップページに表示する項目（次にやるべきレッスン、苦手分野、復習推奨、総評など）と、学習記録がないときや `analysis.md` を解析できないときの表示を定める。
* [レッスン一覧画面](lesson-list.md) - レッスン一覧の章ごとの表示、章の完了数の数え方、各レッスンに表示する項目と状態、準備中のレッスンの表示、推奨レッスンの「次はここ」の印、レッスンを選んだときに開く画面を定める。
* [動画画面](video-screen.md) - 動画画面の配置、プレーヤーの操作（シークバー、5 秒戻る・5 秒進む、再生速度、字幕、演習へなど）、再生中の文の決め方、字幕の表示と字幕の場所、読み込み中と読み込みに失敗したときの表示、キーボードショートカットを定める。
* [演習画面](exercise-screen.md) - 演習画面の配置（問題文、エディタ、コンソール）、テスト実行のボタン、判定結果のカード、正解したときのモーダルと閉じた後の帯、キーボードショートカットを定める。
* [問題生成の画面（生成問題一覧、生成設定画面）](generation-screens.md) - 生成問題一覧の「新しい問題を生成」ボタンと問題がないときの表示、生成設定画面の要素の選択欄と習熟レベルのバッジ、難易度の選択、「生成」ボタンを定める。
* [設定画面と settings.json](settings-screen.md) - 設定画面の設定項目（表示、動画、AI、環境、学習データ、アプリ）とリセット操作の確認ダイアログ、`settings.json` の形式と初期値を定める。
* [レッスン検索](lesson-search.md) - ヘッダーの検索窓から行うレッスン検索の対象と照合の方法、結果の並び順と表示、結果を選んだときに開く動画のモーダルを定める。
* [画面の見た目とテーマ](appearance.md) - 画面の見た目と動画の中身の見た目が従うデザインシステム（「Progrust」「Progrust Video」）、アプリがデザインシステムの CSS とアイコンを写しを作らずにリポジトリの `design-system/` から直接読み込むこと、書体を外部から読み込む `@import` の行の扱い、2 つのデザインシステムの CSS をアプリ全体に読み込むことと、アプリの画面の CSS の書き方、各画面のレイアウトが従う画面デザイン（「Progrust UIデザイン」）と実装した画面では実装を正とすること、書体のファイルの同梱のしかた、章カラーの使い方と章の番号との対応、ライト・ダークのテーマの切り替えを定める。
* [デザインシステムのファイルと変更の手順](design-system-files.md) - デザインシステム「Progrust」「Progrust Video」のファイルの置き場所（`design-system/progrust/`・`design-system/progrust-video/`）とリポジトリのファイルを正とすること、ディレクトリの中身（`tokens.json` から作る `tokens.css`、索引の `design-system.json` など）とリポジトリに置かないファイル、表示用のアーティファクトの URL と読み取り専用にすること、デザインシステムを変えるときの手順（`tokens.css` の作り直し、アイコンの追加、アーティファクトへの送信と中身の確認、画面デザインの中の写しの取り直し）、`python3 tools/design-system.py check` が確かめることを定める。
* [画面デザインのファイルと変更の手順](ui-design-files.md) - 画面デザイン「Progrust UIデザイン」のファイルの置き場所（`design-system/ui-design/`）とリポジトリのファイルを正とすること、ディレクトリの中身（索引の `canvas.json`、画面と状態ごとの `.dc.html`、配置の CSS の `styles/app.css`）とリポジトリに置かないファイル、ファイルの読み方、表示用のアーティファクトの URL とページで編集しないこと、画面デザインを変えるときの手順（送る前の確認、アーティファクトへの送信と中身の確認）、`python3 tools/design-system.py check` が確かめることを定める。
* [アプリのアイコン](app-icon.md) - アプリのアイコン（Dock と Finder に表示する絵）の絵柄と色、形と余白、元の絵のファイル（`src-tauri/app-icon.svg`）とアプリに入れるファイル（`src-tauri/icons/`）、アイコンを変えるときの手順を定める。
* [画面の通知（トースト）](notifications.md) - 画面右下のトーストで通知する出来事（問題生成の完了・失敗、ジョブの失敗）と、通知しない出来事を定める。
* [初回起動画面](first-launch.md) - 初回起動画面を表示する条件（`first_launch_completed`）と、Progrust の紹介、AI 機能についての説明、`cargo` と `claude` の環境チェック、クレートの初回準備の開始を定める。
* [画面仕様の受け入れ条件](acceptance.md) - 画面仕様を満たしたと判断する条件を定める。
* [画面仕様の未決事項](open-questions.md) - 画面仕様でまだ決まっていない事項（検索のモーダルを開いたときの動画の再生、演習画面の「戻る」の行き先、設定画面からログのフォルダを開く項目）を記す。
