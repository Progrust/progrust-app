---
type: Specification
title: "画面一覧と画面遷移"
description: "アプリの全画面（トップページ、レッスン一覧、動画画面、演習画面、生成問題一覧、設定画面など）の一覧と、画面どうしの遷移を定める。"
---

| 画面 | 内容 |
|---|---|
| 初回起動画面 | 初回起動時のみ表示する説明と環境チェック（[初回起動画面](first-launch.md)） |
| トップページ | 起動時に表示する。次にやるべきレッスンと分析の要約をダッシュボードとして表示する（[トップページ（ダッシュボード）](top-page.md)） |
| レッスン一覧 | 章ごとのレッスンの一覧（[レッスン一覧画面](lesson-list.md)） |
| 動画画面 | レッスンの動画を再生する（[動画画面](video-screen.md)） |
| 演習画面 | レッスンまたは生成問題の演習を表示する（[演習画面](exercise-screen.md)） |
| 生成問題一覧 | 過去に生成した演習問題の一覧（[問題生成の画面（生成問題一覧、生成設定画面）](generation-screens.md)「生成問題一覧」） |
| 生成設定画面 | 生成する問題の設定（[問題生成の画面（生成問題一覧、生成設定画面）](generation-screens.md)「生成設定画面」） |
| 設定画面 | アプリの設定と学習データの管理（[設定画面と settings.json](settings-screen.md)） |

```
初回起動画面 ─▶ トップページ ◀──────────── ヘッダーから全画面へ移動可能 ───────────┐
                  │  「続きから」                                                  │
                  ▼                                                                │
レッスン一覧 ─▶ 動画画面 ─▶ 演習画面 ─▶ 「次のレッスンへ」→ 動画画面               │
                  ▲           │       └▶ 「レッスン一覧へ」→ レッスン一覧          │
                  └「見直す」─┘                                                    │
生成問題一覧 ─▶ 演習画面 ─▶ 「生成問題一覧へ」                                     │
     │                                                                             │
     └▶ 生成設定画面 ─「生成」─▶ 生成問題一覧                                      │
設定画面 ◀─────────────────────────────────────────────────────────────────────────┘
```

- 動画のみのレッスンには演習画面がなく、動画画面から「次のレッスンへ」で次のレッスンに移る。レッスン一覧へは、動画画面の左上の「レッスン一覧」で移る（[レッスンの流れ](../lesson-flow/flow.md)）。
