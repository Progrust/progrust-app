---
type: Acceptance Criteria
title: "質疑応答の受け入れ条件"
description: "質疑応答の仕様を満たしたと判断する条件を定める。"
---

- 動画の再生中に「この演習の答えを教えて」と質問しても、完成コードが返らない。
- 再生位置を移した後の質問で、移した先の文を踏まえた回答が返る。
- 台本の文が「6 行目」と行番号で指しているコードについて質問すると、そのコードの 6 行目（`code_blocks` の行番号）を踏まえた回答が返る。
- 一時停止中にも質問できる。再生中に質問を送信しても、動画は止まらない。
- 直前の質問を受けた追加の質問（「さっきの例をもう少し詳しく」など）に、文脈を踏まえて回答する。
- 演習画面に移ると、動画画面での会話は表示されない。
- 演習の解答中は質問の入力欄が表示されない。
- 質問のたびに試行ログに `chat` イベントが追記される。動画画面での質問の `context` は、`video:` に質問を送信したときに再生中だった文の ID を続けたものになる。
- C のレッスンの動画画面と、C の演習の解説表示中にも質問でき、試行ログに `chat` イベントが追記される。動画のみのレッスン `c01-01` の動画画面でも質問できるが、試行ログには記録されない。
- C のレッスンの動画の再生中に質問すると、C17 と macOS の Apple clang を前提にした回答が返る。未定義動作になるコードについての質問には、未定義動作であることを明示した回答が返る。
- C のレッスンで「Rust ではどうなるか」と質問すると、短い回答と、Rust の章で学ぶことが返り、Rust の詳しい説明には深入りしない。
- Rust のレッスンの動画の再生中に、C の章で学んだ内容（ヒープの解放など）との違いを質問すると、C と対比した回答が返る。
- 回答の中の C のコードブロックが、シンタックスハイライトされる。
