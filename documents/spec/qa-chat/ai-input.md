## 動画の再生中

1. 指示文（`prompts/chat-video.md`）
2. レッスンのタイトルと、レッスンの言語（C か Rust。[章とレッスンの並びの形式（chapters.json）](../content-format/chapters-json.md) の `language`）と、主要素の説明（要素マスタの `name`・`description`）。動画のみのレッスンと C のレッスンには主要素がないので、タイトルとレッスンの言語だけを渡す
3. レッスンの台本（[動画の台本（script.json）](../content-format/video/script-json.md)）の内容
   - 全文: シーンごとにシーンの名前を見出しにし、そのシーンの各文の ID と `text` を台本の順に並べたもの
   - `ai_note`
   - 画面に出すコード（`code_blocks`。渡し方は「画面に出すコードの渡し方」）
4. 質問を送信したときに再生中だった文の ID と、その文の `text`
5. 既習の要素の一覧（[章とレッスンの並びの形式（chapters.json）](../content-format/chapters-json.md) の定義による）。要素マスタの `name`・`description` を添える。Rust のレッスンだけに渡し、C のレッスンには渡さない
   - アプリは章とレッスンの一覧を持たないので、要素マスタの `chapter` が学習順でそのレッスンの章より前にある要素、学習順でそのレッスンより前にある準備中でない `kind` が `lesson` のレッスンの `primary_elements`、そのレッスンの `secondary_elements` を、既習の要素とする。そのレッスンと同じ章の、前にある準備中のレッスンだけが導入する要素は含めない
6. C のレッスンの一覧。各レッスンの `title` と `summary`（[レッスン定義の形式（lesson.json）](../content-format/lesson-json.md)）を、学習順に並べて渡す。章末復習レッスンと準備中のレッスンは含めない
   - C のレッスン: 「既習の C のレッスン」として、学習順でそのレッスンより前にある C のレッスンを渡す
   - Rust のレッスン: 「学習者が C の章で学んだ内容」として、すべての C のレッスンを渡す
7. 会話履歴
8. 今回の質問

演習の問題文・模範解答・テストケースは渡さない。

## 解説表示中

1. 指示文（`prompts/chat-explanation.md`）
2. レッスン（または生成問題）のタイトルと、レッスンの言語（C か Rust。生成問題は Rust）と、主要素・副要素の説明。C のレッスンには主要素・副要素がないので、タイトルとレッスンの言語だけを渡す
3. 問題文、解説、模範解答
4. 学習者が正解したときのコード
5. 会話履歴
6. 今回の質問

## 画面に出すコードの渡し方

台本の文は、コードの行を行番号で指すことがある（[動画の作成ルール](../content-guidelines/video.md)「コード」）。台本の `code_blocks` は、次のように渡す。

- 言語（`language`）とラベル（`label`）を添えたコードとして渡す。`language` が `text` のものは、ターミナルの出力として渡す。
- 行番号を表示するもの（[動画でのコードの表示](../content-format/video/code-display.md)）は、各行の先頭に、`code_blocks` の行番号を付けて渡す。
- Diff として表示するものは、Diff であることを示し、各行の先頭の `+` / `-` を残して渡す。行番号は変更後のファイルの行番号を付け、削除行には付けない。
