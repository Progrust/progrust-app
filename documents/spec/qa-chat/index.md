# 質疑応答

* [質疑応答の目的とスコープ](scope.md) - 質疑応答の仕様が扱う範囲（C のレッスンと Rust のレッスンの両方で使えること）と、`claude -p` の呼び出し方の共通ルールの参照先を定める。
* [質疑応答を利用できる場面](availability.md) - 質問できる場面（動画の再生中、演習の解説表示中。C のレッスンでも同じ）と、それぞれで試行ログに記録するコンテキストを定める。
* [質疑応答の会話履歴](history.md) - 質疑応答の会話履歴を保持する範囲と、AI への入力に含める往復数と、回答を途中で止めた往復・エラーになった往復の扱いを定める。
* [質疑応答で AI に渡す入力](ai-input.md) - 動画の再生中と解説表示中のそれぞれで AI に渡す入力の内容と順序（レッスンの言語、Rust のレッスンに渡す既習の要素の一覧と C の章で学んだ内容、C のレッスンに渡す既習の C のレッスンを含む）、画面に出すコード（`code_blocks`）の渡し方を定める。
* [質疑応答の回答の方針](answer-policy.md) - 指示文で AI に指示する回答の方針を、共通（Rust のレッスンの edition 2024、C のレッスンの C17 と Apple clang の前提を含む）、レッスンの言語ごとの方針（C のレッスンでの未定義動作の明示と Rust についての質問への答え方、Rust のレッスンでの C との対比）、動画の再生中、解説表示中に分けて定める。
* [質疑応答の画面](screen.md) - チャットパネルの表示場所と動画画面を開いたときの開閉の状態、回答のストリーミング表示と停止、入力欄の制限、エラー時の表示と「再試行」を定める。
* [質疑応答の試行ログへの記録](attempt-log.md) - 質問を送信したときに試行ログへ `chat` イベントを追記する条件（追記するとき、試行セッションが存在する場面だけで記録すること（C のレッスンでも記録すること）、エラーの後の「再試行」は記録しないこと）を定める。
* [質疑応答の受け入れ条件](acceptance.md) - 質疑応答の仕様を満たしたと判断する条件を定める。
