# 演習問題生成

* [演習問題生成の目的とスコープ](scope.md) - 演習問題生成が扱う範囲と、生成した問題をレッスンの演習と同じ形式で保存し同じ仕組みで実行・判定・記録することを定める。
* [演習問題生成の流れ](flow.md) - 生成設定画面で「生成」を押してから、generate ジョブによる生成と検証を経て、`ready` または `failed` になるまでの流れを定める。
* [演習問題の生成設定](settings.md) - 生成設定画面の項目（苦手分野を中心にする、要素、難易度、AI へのメッセージ）と初期値、要素の初期値の決め方、難易度 1〜5 の目安を定める。
* [演習問題生成で AI に渡す入力](ai-input.md) - 生成時に AI に渡す入力の内容と順序、指示文（`prompts/generate.md`）で AI に指示する事項を定める。
* [演習問題生成の出力と検証](output-and-validation.md) - AI に出力させる JSON の形式、出力の検証項目、検証に失敗したときの修正依頼（最大 2 回）と `failed` の扱い、検証のビルドが初回準備のやり直しが要る失敗になったときの扱いを定める。
* [生成問題の保存](storage.md) - `generated/{generation_id}/` に保存するファイルの構成と、`meta.json` のフィールドおよび `status` の値を定める。
* [生成問題一覧と生成問題の演習](list-and-exercise.md) - 生成問題一覧の表示項目と操作（開く、同じ設定で生成、削除、再生成）、生成完了の通知、生成問題の演習の流れと試行ログへの記録を定める。
* [演習問題生成の受け入れ条件](acceptance.md) - 演習問題生成の仕様を満たしたと判断する条件を定める。
* [演習問題生成の未決事項](open-questions.md) - 演習問題生成の仕様でまだ決まっていない事項（失敗した生成ジョブの「再実行」と生成問題一覧の「再生成」の関係、「学習履歴をすべてリセット」のときの生成中の問題の扱い、生成中の問題の削除、分析ファイルを解析できないときの生成設定画面の初期値）を記す。
