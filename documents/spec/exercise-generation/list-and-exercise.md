type: Specification
title: "生成問題一覧と生成問題の演習"
description: "生成問題一覧の表示項目と操作（開く、同じ設定で生成、削除、再生成）、生成完了の通知、生成問題の演習の流れと試行ログへの記録を定める。"
---

- 生成問題一覧は新しい順に表示する。各問題にタイトル・概要・要素・難易度・状態（生成中 / 未着手 / 完了 / 失敗）・作成日時を表示する。
- 操作:
  - 「開く」: 演習画面を開く（`ready` のみ）。
  - 「同じ設定で生成」: `settings` を初期値として生成設定画面を開く。
  - 「削除」: 確認ダイアログの後、`generated/{generation_id}/` と下書きを削除する。学習記録・試行ログは削除しない。
  - 失敗した問題は、エラーの内容と「再生成」ボタン（同じ設定で新しく生成）を表示する。
- 生成が完了したら、どの画面にいても通知（トースト）を表示し、「開く」で演習画面に移れるようにする。
- 生成問題の演習は、動画がないこと以外は Rust のレッスンと同じ流れとする（[レッスンの流れ](../lesson-flow/flow.md)）。解説表示の後は「生成問題一覧へ」を表示する。
- 生成問題の試行も、Rust のレッスンと同じく記録・分析する（試行ログの `kind: generated`、`difficulty` に難易度を記録する）。
