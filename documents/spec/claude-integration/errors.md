---
type: Specification
title: "AI 呼び出しのエラーの分類と表示"
description: "未検出、未ログイン、利用上限、タイムアウト、出力不正、その他のエラーの判定条件と、表示・動作、`last_error` への保存を定める。"
---

| 分類 | 判定 | 表示・動作 |
|---|---|---|
| 未検出 | `claude` が見つからない | [claude が使えない場合の動作](unavailable.md) |
| 未ログイン | 終了コードと出力から認証エラーと判定できる場合 | 「ターミナルで `claude` を起動してログインしてください」 |
| 利用上限 | 出力から利用上限・レート制限と判定できる場合 | 「Claude の利用上限に達しました。時間をおいて再試行してください」。ジョブは通常のリトライに従う |
| タイムアウト | [claude -p の呼び出しの共通ルール](invocation.md)「制限時間」 の制限時間を超えた | 「応答がありませんでした」 |
| 出力不正 | 各機能の出力検証に失敗した | 質疑応答では発生しない。ジョブは失敗としてリトライする |
| その他 | 上記以外で終了コードが 0 以外 | 「AI の呼び出しに失敗しました」と、詳細（標準エラー出力の先頭）を折りたたんで表示 |

- ジョブの `last_error` には分類と詳細を保存する。
- エラーの詳細はログ（[アプリのログ](../non-functional/logging.md)）にも記録する。
