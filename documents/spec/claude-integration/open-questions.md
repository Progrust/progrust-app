type: Open Questions
title: "Claude Code 連携の未決事項"
description: "Claude Code 連携の仕様でまだ決まっていない事項（ジョブのリトライの回数と間隔、待ち時間の持ち方、手動の再実行での `attempts` の扱い、`failed` のジョブの保持期間）を記す。"
---

- ジョブのリトライ（[ジョブキュー（jobs.json）](job-queue.md)）の回数と間隔。「最大 3 回まで再実行（間隔 30 秒 → 2 分 → 10 分）。3 回失敗したら `failed`」とあり、3 回の失敗で終わるなら 3 つ目の間隔（10 分）を使う場面が無い。
- リトライの待ち時間の間に、ほかの `pending` のジョブを実行するか。次に実行する時刻を `jobs.json` に持つか（持たないと、アプリを再起動したときに待ち時間が消える）。
- 設定画面からの手動の再実行（`retry_job`）で、`attempts` を 0 に戻すか。
- `failed` のジョブをいつまで `jobs.json` に残すか（`done` のジョブは 7 日後に削除する）。
