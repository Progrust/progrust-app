---
type: Specification
title: "claude -p の呼び出しの共通ルール"
description: "`--model` の指定、ツール・ユーザー設定を使わない起動、一時ディレクトリ、標準入力での指示文の渡し方、出力形式、用途ごとの制限時間を定める。"
---

- 設定画面で選択したモデルを `--model` で指定する（[AI モデルの選択](model-selection.md)）。
- ツールを使わせない設定で起動する。
- 学習者の Claude Code のユーザー設定（フック・MCP サーバー・`CLAUDE.md` など）を読み込まない設定で起動する。
- 作業ディレクトリは呼び出しごとに作る空の一時ディレクトリとし、終了後に削除する。
- 指示文は標準入力で渡す。
- `--continue` / `--resume` は使わない。会話の続きが必要な場合（質疑応答）も、アプリが履歴を毎回入力に含める。
- 出力形式:
  - ジョブ: `--output-format json` を指定し、結果のテキストを取り出す。
  - 質疑応答: ストリーミングの出力形式を指定し、回答を少しずつ表示する。
- 具体的なコマンドラインフラグは、実装時に使用する Claude Code のバージョンに合わせて確認する。

## 制限時間

| 用途 | 1 回の呼び出しの制限時間 |
|---|---|
| 質疑応答 | 120 秒 |
| 記録・分析 | 300 秒 |
| 問題生成 | 600 秒 |

制限時間を超えたらプロセスを終了し、エラー（[AI 呼び出しのエラーの分類と表示](errors.md)）とする。
