# Claude Code 連携

* [Claude Code 連携の目的とスコープ](scope.md) - Claude Code 連携の共通仕様が扱う範囲と、機能ごとの呼び出し方（直接呼び出しかジョブか）および仕様書の対応を定める。
* [Claude Code 連携の設計方針](design-policy.md) - AI にツールを使わせないこと、数値の計算をさせないこと、AI 機能が使えなくても学習を続けられることを定める。
* [claude が使えない場合の動作](unavailable.md) - `claude` が見つからない間の質疑応答・問題生成・ジョブの動作と、設定画面の「接続テスト」ボタンの動作を定める。
* [claude -p の呼び出しの共通ルール](invocation.md) - `--model` の指定、ツール・ユーザー設定を使わない起動のフラグ、`claude` に渡す環境変数、使う認証、既定のシステムプロンプトの置き換え、一時ディレクトリ、標準入力での指示文の渡し方、出力形式、用途ごとの制限時間を定める。
* [指示文（プロンプト）の置き場所と書き方](prompts.md) - 指示文を `prompts/` に Markdown で置くこと、`{{name}}` 形式の埋め込み、指示文ファイルと用途の対応を定める。
* [ジョブキュー（jobs.json）](job-queue.md) - `jobs.json` の項目、ジョブの種類・状態・実行順・依存・リトライ・起動時の扱い・保持期間、UI への通知を定める。
* [AI モデルの選択](model-selection.md) - 設定画面で用途ごとに選ぶモデルの設定、既定値、選択肢、設定の保存先を定める。
* [AI 呼び出しのエラーの分類と表示](errors.md) - エラーかどうかの判定（`is_error`）、未検出、未ログイン、利用上限、タイムアウト、出力不正、その他のエラーの判定条件（`assistant` の行の `error` の値）と、表示・動作、`last_error` への保存を定める。
* [Claude Code 連携の受け入れ条件](acceptance.md) - Claude Code 連携の仕様を満たしたと判断する条件を定める。
* [Claude Code 連携の未決事項](open-questions.md) - Claude Code 連携の仕様でまだ決まっていない事項（ジョブのリトライの回数と間隔、待ち時間の持ち方、手動の再実行での `attempts` の扱い、`failed` のジョブの保持期間、制限時間を超えたときや中断のときの `claude` のプロセスの止め方）を記す。
