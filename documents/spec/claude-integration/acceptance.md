---
type: Acceptance Criteria
title: "Claude Code 連携の受け入れ条件"
description: "Claude Code 連携の仕様を満たしたと判断する条件を定める。"
---

- 学習者の `~/.claude/CLAUDE.md` やフックの設定が、アプリからの AI 呼び出しに影響しない。
- AI の呼び出し中に、AI がファイルを作成・変更・削除することがない。
- `claude` をアンインストールした状態で演習のある Rust のレッスンを完了すると、記録ジョブが `pending` のまま残り、`claude` を導入して再検出すると実行される。
- C の演習の実行・提出で起動する `clang` と学習者のプログラム（メモリリークの検査のライブラリを差し込む起動を含む）では、環境変数が `claude` に渡す 6 つに絞られない。
- 記録ジョブの実行中でも、質疑応答の回答が返ってくる。
- 問題生成のジョブは、先に登録された記録・分析のジョブより先に実行される（実行中のジョブの完了は待つ）。
- 設定画面で選んだモデルが、用途ごとに `--model` に渡される。
