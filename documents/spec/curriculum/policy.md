## C の章と Rust の章

- カリキュラムは、C の章と Rust の章からなる。最初に C の章（c01〜c03）を置き、その後に Rust の章（ch01〜ch23）を置く。
- C の章は、C を使えるようになるためではなく、Rust を深く理解するために置く。メモリを手で管理する難しさと、C がその誤りを防がないことを、演習で体験させる。
- C の章で扱う範囲は、メモリの動きを演習で試すのに困らない C の基本（型、制御構文、関数、配列、文字列、構造体）と、ポインタ、スタックとヒープ、メモリの誤り、誤りを避けるための取り決めとする。レッスンの数を減らすために、内容を削らない。
- C の章の最初のレッスン（c01-01）は動画のみのレッスンとし、最初に C 言語を学ぶ理由を、Rust の特徴も含めて説明する。
- Rust の章では、C の章で体験した内容に対応するレッスンで、C ではどうなったかと、Rust がそれをどう扱うかを対比する。対比するレッスンは、[章とレッスンの一覧](chapters/index.md) の「主に扱う内容」に、対応する C のレッスンの ID を添えて示す。

## Rust の章

- 想定する学習者（[想定する学習者](../content-guidelines/target-learner.md)）に合わせ、Rust 固有でない内容（`while`、イテレータの汎用的なアダプタなど）はまとめて扱い、Rust 固有の内容（所有権・借用・パターン・ライフタイムなど）は細かく分ける。
- The Rust Programming Language（以下 TRPL）を、扱う内容の網羅の目安とする。章立て・順序・題材は独自に組み立て、TRPL の文章・コード・題材のプログラム（数当てゲーム、minigrep、Web サーバーなど）は使わない。
- Rust を理解するうえで必要な周辺知識（[想定する学習者](../content-guidelines/target-learner.md)）は、TRPL が扱っていないものも扱う。
- 周辺知識のうち、メモリの仕組み（アドレス、スタックとヒープ、確保と解放、メモリの誤り）は、C の章で、演習のあるレッスンとして扱う。
- それ以外の周辺知識のうち、特定の Rust の要素の理由になるものは、その要素のレッスンの「主に扱う内容」に含める。複数のレッスンの前提になるものは、動画のみのレッスン（[教材作成におけるカリキュラムの決まり](../content-guidelines/curriculum.md)）にして、それを前提とするレッスンより前に置く。
