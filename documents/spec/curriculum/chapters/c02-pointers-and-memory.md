変数がメモリのどこに置かれるかを知り、ポインタでアドレスを扱う方法と、スタックとヒープの使い方を学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| c02-01 | アドレスとポインタ | メモリがバイトの並びで、変数がその上の場所を占めること、`&` でアドレスを得る、ポインタ型の変数、`*` で指す先を読み書きする、`%p`、`NULL` と、`NULL` のポインタで読み書きしたときの異常終了 |
| c02-02 | ポインタと関数 | ポインタを渡して呼び出し元の変数を書き換える（値の入れ替え）、`scanf` に `&` を付ける理由、ポインタで複数の結果を返す、`const` を付けたポインタ（指す先を書き換えない約束） |
| c02-03 | ポインタと配列 | 配列の名前が先頭の要素のアドレスになること、ポインタの加算と `p[i]`、関数に渡すと要素数が失われること、ポインタ同士の引き算、文字列を `char *` で扱う |
| c02-04 | スタックとスタックフレーム | 関数の呼び出しごとにスタックフレームが作られ、戻ると消えること、ローカル変数と引数の置き場所、再帰とスタックの深さ、戻った関数のローカル変数を指すポインタ（ダングリングポインタ）、呼び出し元が用意した場所に書き込ませる書き方 |
| c02-05 | ヒープと malloc・free | 実行時に大きさが決まるデータ、`malloc`（`<stdlib.h>`）と `sizeof`、確保に失敗したときの `NULL`、`free`、ヒープの領域は `free` するまで残ること（関数から返せる）、確保した直後の中身が決まっていないことと `calloc` |
| c02-06 | 構造体とポインタ | 構造体へのポインタと `->`、構造体をヒープに確保する、ポインタで渡してコピーを避ける・書き換える、ポインタのメンバーを持つ構造体 |
| c02-07 | 伸びる配列を作る | `realloc`、ポインタ・長さ・容量の 3 つを持つ構造体で要素数の変わる配列を作る、容量が足りなくなったら広げる、`realloc` が領域を別の場所へ移すことがあること |
| c02-08 | 文字列とヒープ | 文字列を複製する（`strlen` に 1 を足した大きさの `malloc` と `strcpy`）、`strcpy`・`strcat`・`strcmp`、書き込み先の大きさを自分で確かめること、文字列リテラルを書き換えられないこと |
| c02-09 | 連結リスト | 自分と同じ型へのポインタを持つ構造体、ノードの追加と走査、ノードの削除、すべてのノードを解放する順序 |
| c02-review | 章末復習 | |
