スレッドによる並行処理と、データ競合を防ぐ仕組みを学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| ch20-01 | スレッドを生成する | `thread::spawn`、`join`、`thread::sleep` と `Duration` |
| ch20-02 | スレッドと move | スレッドに値を渡す、`'static` が必要な理由 |
| ch20-03 | スコープ付きスレッド | `thread::scope`、借用したままスレッドを使う |
| ch20-04 | チャネル | `mpsc`、送信側の複製、受信の終わり |
| ch20-05 | Mutex | ロックとガード、ガードの破棄でロックが外れる |
| ch20-06 | Arc | スレッド間での共有、`Arc<Mutex<T>>` |
| ch20-07 | Send と Sync | スレッド間で渡せる型・共有できる型、`Rc` が使えない理由 |
| ch20-08 | アトミック型 | `AtomicUsize` など、ロックなしでの共有カウンタ、メモリオーダリングの概要 |
| ch20-09 | グローバルな共有状態 | `static` と `Mutex`、`OnceLock`・`LazyLock` による一度だけの初期化 |
