所有権を移さずに値を使う参照と、借用の規則を学ぶ

| ID | タイトル | 主に扱う内容 | 主要素 |
| --- | --- | --- | --- |
| ch05-01 | 不変の参照 | `&`、関数に貸す、参照外し `*`、参照の実体が値のあるアドレスであること（C のポインタと同じ。c02-01）、C のポインタとの違い（`NULL` にならない、指す先が有効であることをコンパイラが確かめる） | `borrow.immutable` |
| ch05-02 | 可変の参照 | `&mut`、可変参照を通した変更（C ではポインタを渡して書き換えた。c02-02） | `borrow.mutable` |
| ch05-03 | 借用の規則 | 可変参照は 1 つだけ・不変参照との共存不可、参照が使われる範囲（NLL）、この規則が防ぐ誤り（ほかのポインタを通した変更で、手元のポインタが無効になる。c03-06） | `borrow.rules` |
| ch05-04 | ダングリング参照 | 破棄された値への参照をコンパイラが防ぐ、参照は値より長く生きられない、関数から戻るとローカル変数がスタックフレームごと消えること（c02-04 を既習とする）、C では実行するまで気づけなかった誤り（c02-04・c03-03）がコンパイルエラーになること | `borrow.dangling` |
| ch05-05 | 文字列スライス | `&str`、範囲によるスライス、スライスがアドレスと長さの組であること（C のポインタは長さを持たなかった。c02-03）、文字列リテラルがスライスであること、引数を `&str` にする（`String` からは `&s[..]`・`as_str()` で渡す。`&String` をそのまま渡せる理由は ch17-03） | `slice.str` |
| ch05-06 | 配列のスライス | `&[T]`、配列の一部を貸す、文字列スライスと同じくアドレスと長さの組であること | `slice.array` |
| ch05-review | 章末復習 | | |
