所有権を移さずに値を使う参照と、借用の規則を学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| ch05-01 | 不変の参照 | `&`、関数に貸す、参照外し `*` |
| ch05-02 | 可変の参照 | `&mut`、可変参照を通した変更 |
| ch05-03 | 借用の規則 | 可変参照は 1 つだけ・不変参照との共存不可、参照が使われる範囲（NLL） |
| ch05-04 | ダングリング参照 | 破棄された値への参照をコンパイラが防ぐ、参照は値より長く生きられない |
| ch05-05 | 文字列スライス | `&str`、範囲によるスライス、文字列リテラルがスライスであること、引数を `&str` にする（`String` からは `&s[..]`・`as_str()` で渡す。`&String` をそのまま渡せる理由は ch17-03） |
| ch05-06 | 配列のスライス | `&[T]`、配列の一部を貸す |
| ch05-review | 章末復習 | |
