Rust のメモリ管理の中心となる所有権の仕組みを学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| ch04-01 | メモリの仕組み | スタックとヒープ、関数の呼び出しごとに作られて戻ると消えるスタックフレーム、ガベージコレクションがないこと、メモリを手で解放する言語で起きる問題（二重解放・解放後の使用）（動画のみのレッスン） |
| ch04-02 | スコープと値の破棄 | 変数のスコープ、スコープの終わりで値が破棄されてメモリが解放される |
| ch04-03 | String 型 | ヒープに置かれる文字列、`String` がスタックに持つポインタ・長さ・容量、`String::from`、`push_str`、`format!`、文字列リテラルとの違い |
| ch04-04 | 所有権のムーブ | 変数が値そのものを持つこと（Python・JavaScript の代入は同じオブジェクトの共有）、代入で所有権が移る、ムーブでコピーされるのはスタック上の部分だけであること、ムーブ済みの値を使ったエラー |
| ch04-05 | clone と Copy | 明示的な深いコピー、整数などがムーブされずにコピーされる理由 |
| ch04-06 | 関数と所有権 | 引数・戻り値での所有権の移動 |
| ch04-review | 章末復習 | |
