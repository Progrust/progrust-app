C のプログラムを書いて動かし、型・制御構文・関数・配列・文字列・構造体の基本を学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| c01-01 | なぜ C 言語から学ぶのか | Rust の特徴（ガベージコレクションなしでメモリを安全に扱うこと、コンパイラが誤りを実行の前に止めること）、ガベージコレクションのある言語が代わりにしていること、C がメモリを手で管理する言語であること、C の章で体験することと Rust の章でそれを振り返ること、C の演習の進め方（実行はメモリの検査なし、提出でメモリの検査）（動画のみのレッスン） |
| c01-02 | はじめての C | `#include <stdio.h>`、`main` 関数と戻り値、`printf` と `\n`、文とセミコロン、コメント、コンパイルしてから実行すること、コンパイルエラーと警告と実行時のエラーの違い |
| c01-03 | 変数と整数型 | 変数の宣言と型、`int`・`long`・`char`・`unsigned`、型の大きさと `sizeof`、表せる値の範囲、初期化していない変数の値が決まっていないこと、`const` |
| c01-04 | 演算と printf の書式 | 整数の除算と剰余、`double`、暗黙の型変換とキャスト、`%d`・`%ld`・`%zu`・`%c`・`%f`、書式と引数の型が合わないときに起きること、符号付き整数のあふれ |
| c01-05 | 標準入力を読む | `scanf` で整数を読む、変数に `&` を付けて渡すこと（理由は c02-02）、戻り値で読めた個数を確かめる、入力の終わり |
| c01-06 | 条件分岐と繰り返し | `if`・`else`、`while`・`for`・`do while`、`break`・`continue`、`switch`、0 が偽でそれ以外が真であることと `bool`（`<stdbool.h>`）、`=` と `==` の取り違え |
| c01-07 | 関数 | 関数の定義と呼び出し、プロトタイプ宣言、引数が値のコピーで渡ること、`void`、ローカル変数のスコープ |
| c01-08 | 配列 | 固定長の配列の宣言と初期化、添字、配列が要素数を持たないことと `sizeof` での計算、関数に渡すときは要素数も渡すこと（理由は c02-03）、範囲外の添字を C が検査しないこと（詳しくは c03-02） |
| c01-09 | 文字列 | 文字列が `char` の配列であること、終端の `'\0'`、文字列リテラル、`%s`、`strlen`（`<string.h>`）、配列の大きさと文字数の違い、幅を指定した `scanf("%15s", ...)` で単語を読む、1 文字ずつたどる |
| c01-10 | 構造体 | `struct` の定義と初期化、メンバーへのアクセス、`typedef`、代入と関数への受け渡しでメンバーがまるごとコピーされること、構造体の配列 |
| c01-review | 章末復習 | |
