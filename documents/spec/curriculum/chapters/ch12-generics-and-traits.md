型をパラメータにしたコードと、型に共通の振る舞いを定めるトレイトを学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| ch12-01 | ジェネリックな関数 | 型パラメータ `<T>`、使える操作が制約で決まること、使う型ごとにコードが作られること（単相化） |
| ch12-02 | ジェネリックな構造体と列挙型 | `struct Point<T>`、`impl<T>`、特定の型だけの `impl` |
| ch12-03 | トレイトの定義と実装 | `trait`、`impl Trait for Type`、デフォルト実装と上書き、孤児ルールの概要 |
| ch12-04 | トレイト境界 | `impl Trait` 引数、`T: Trait`、`+`、`where` |
| ch12-05 | 関連型 | トレイトの中の `type`、型パラメータとの違い |
| ch12-review | 章末復習 | |
