Rust のスカラー型と複合型、型変換の規則を学ぶ

| ID | タイトル | 主に扱う内容 | 主要素 |
| --- | --- | --- | --- |
| ch02-01 | 整数型 | 符号と大きさ（`i8`〜`i128`・`u8`〜`u128`・`isize`・`usize`）、リテラルの書き方、`MAX`・`MIN`、オーバーフロー時の panic（C の符号付き整数のあふれは未定義動作だった。c01-04・c03-01）、`wrapping_add`・`saturating_add` | `scalar.integer` |
| ch02-02 | 浮動小数点数と数値の演算 | `f64`・`f32`、整数の除算と剰余、整数と小数を混ぜて計算できないこと | `scalar.float_arithmetic` |
| ch02-03 | 型の変換 | `as` によるキャスト、暗黙の変換がないこと（C の暗黙の型変換との違い。c01-04）、切り捨て・桁あふれ | `scalar.cast` |
| ch02-04 | 論理型と文字型 | `bool`、`char` が Unicode のスカラー値（4 バイト）であること | `scalar.bool_char` |
| ch02-05 | タプル | 生成、`.0` によるアクセス、分解代入、ユニット型 `()` | `tuple.basic` |
| ch02-06 | 配列 | `[T; N]`、初期化の書き方、配列が要素数を持つこと（C の配列は持たなかった。c01-08）、添字アクセスと範囲外の panic（C は範囲外の添字を検査しなかった。c03-02） | `array.basic` |
| ch02-review | 章末復習 | | |
