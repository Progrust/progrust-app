テストを書いて、コードが期待どおりに動くことを確かめる方法を学ぶ

| ID | タイトル | 主に扱う内容 |
| --- | --- | --- |
| ch11-01 | テスト関数を書く | `#[test]`、`assert_eq!` などでの検査、`cargo test` の結果の読み方 |
| ch11-02 | テストモジュール | `#[cfg(test)]`、`mod tests` と `use super::*`、非公開の関数のテスト |
| ch11-03 | panic を期待するテスト | `#[should_panic]`、`expected` によるメッセージの確認 |
| ch11-04 | Result を返すテスト | テスト関数で `?` を使う |
| ch11-05 | 統合テスト | `tests/` ディレクトリ、ライブラリクレートを外から使うテスト |
| ch11-06 | ドキュメントコメントとドキュメントテスト | `///`・`//!`、ドキュメントの中のコード例がテストとして動く |
| ch11-review | 章末復習 | |
