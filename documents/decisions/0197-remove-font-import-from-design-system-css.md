## 背景

「Progrust」「Progrust Video」の `components/bundle.css` の先頭には、書体を Google Fonts から読み込む `@import` の行があった。[ADR 0153](0153-load-design-system-css-directly-from-repository.md) は、この行をデザインシステムのファイルから取り除かず、アプリがビルドのときに取り除いて読み込むと決めた。理由は、アーティファクトのページの見本がこの行で書体を読み込んでいることだった。[ADR 0175](0175-strip-font-import-with-vite-plugin.md) は、取り除く方法を、Vite のプラグインと、教材チェックツールの描画の CSS のローダーにした。

[ADR 0196](0196-stop-display-artifacts-for-design-files.md) で、表示用のアーティファクトをやめ、ページを消した。この行を残す理由は無くなった。Issue #149 は、行と、それを取り除く仕組みが残っていることを挙げた。2026-11-23、ユーザーは Issue #149 の対応を頼んだ。

この判断は、アプリの操作感に関わらない技術的な判断で、`CLAUDE.md` はそのような判断を Claude に任せている。以下の決定と理由は、Claude の判断である。

## 決定

- 2 つのデザインシステムの `components/bundle.css` から、書体を外部から読み込む `@import` の行を消す。デザインシステムの CSS には、外部から読み込む指定を書かない（[画面の見た目とテーマ](../spec/screens/appearance.md)「デザインシステムの CSS とアイコン」）。
  - 理由: 行を残す理由（アーティファクトのページの見本）が無くなった。アプリは外部のサイトから読み込まず（[ADR 0111](0111-bundle-monaco-and-set-csp.md)）、書体は同梱したファイルから読む（[ADR 0116](0116-bundle-upstream-variable-fonts-unmodified.md)）。使わない行を残して取り除き続けるより、行が無いほうが、読み込む CSS とファイルが同じになり、取り除く仕組みも要らない。
  - ADR 0153 の「決定」の「書体を外部から読み込む `@import` の行（`components/bundle.css` の先頭）は、デザインシステムのファイルからは取り除かず、アプリがビルドのときに取り除いて読み込む」を、この判断で変えた。
- 行を取り除く仕組み（Vite のプラグインと、教材チェックツールの描画の CSS のローダーの取り除き）をやめる。ADR 0175 を置き換える。
  - 理由: 取り除く行が無い。
- `python3 tools/design-system.py check` で、デザインシステムの CSS が外部から `@import` で読み込んでいないことを確かめる（[デザインシステムのファイルと変更の手順](../spec/screens/design-system-files.md)「検査」）。
  - 理由: 取り除く仕組みが無くなったので、行がまた入ると、アプリの開発時の起動と教材チェックツールの描画が外部の書体を読み込む（本番ビルドでは CSP が拒否する）。`design-system/` は lint の対象から外しているので（ADR 0153）、デザインシステムの検査で見つける。フロントエンドのビルドの出力に `@import` が残らないことを確かめるテストと、描画のチェックの試験用のレッスンが外部の `@import` を見つけたら失敗する仕組みは、そのまま残す。

## 検討した他の案

- 案: 行は消し、取り除く仕組みも、念のため残す
  - 採用しなかった理由: 取り除くものが無い仕組みを保守し続けることになる。行がまた入ったことは、検査で見つけられる。
- 案: 行を残し、取り除く仕組みも残す（いまのまま）
  - 採用しなかった理由: 行を残す理由が無くなった（「背景」）。

## 影響

- アプリと教材チェックツールが読み込む `bundle.css` が、リポジトリのファイルそのままになる。
- デザインシステムの CSS に外部から読み込む行を足すと、デザインシステムの検査（CI と実装のループの機械のチェックでも実行する）が指摘する。
- 画面デザインの `.dc.html` には、書体を Google Fonts から読み込む `<link>` が残っている。`.dc.html` はアプリが読み込まず、読むためのファイルなので、この判断では変えない。
