---

- 日付: 2026-10-31
- 関連仕様: [要素マスタの形式（elements.json）](../spec/content-format/elements-json.md)、[学習記録・分析の設計方針](../spec/learning-record-and-analysis/design-principles.md)「Rust 要素 ID の共通化」
- 置き換え: なし

## 背景

レッスン定義・学習記録・分析ファイル・問題生成の設定は、いずれも Rust の要素を参照する。参照のしかたがデータごとに違うと集計ができず、要素 ID を変えると過去の学習記録が参照する ID が存在しなくなる。

## 決定

すべてのデータが要素マスタの要素 ID で要素を参照する。要素 ID は一度公開したら変更せず、廃止する場合も削除せずに `deprecated` を付ける（`content-format.md`「要素マスタ（elements.json）」）。

## 検討した他の案

- 案: 要素の表示名で参照する
  - 採用しなかった理由: 表示名の修正で過去のデータとの対応が切れる
- 案: 廃止した要素 ID を削除し、過去の記録を移行する
  - 採用しなかった理由: 学習記録・分析ファイルは学習者が手で編集することも想定しており、確実に移行できない

## 影響

- 要素の分け方を見直したくなっても、既存の ID を変えられない。新しい ID を追加し、古い ID に `deprecated` を付けることになる。
