## 背景

コードエディタの部品（Issue #166）は Monaco Editor を使うので、Monaco が出す文言（右クリックのメニューの「Cut」「Copy」「Paste」「Command Palette」、検索・置換の欄、読み取り専用のエディタで文字を打ったときの「Cannot edit in read-only editor」など）が英語で表示されていた。アプリの画面は日本語だが、エディタの中の文言を日本語にするかどうかは、仕様に決まっていなかった（Issue #206）。

## 決定

- エディタの中に出る Monaco の文言を、日本語にする（[アプリの技術構成](../spec/architecture/tech-stack.md)）。
  - Claude が「日本語にする」を推奨の案として示し、ユーザーが選んだ（Issue #206 の仕分け）。示した案の説明は、「アプリの他の画面と言葉がそろう。実装は小さい」である。
- 翻訳は、monaco-editor に同梱された日本語の翻訳（`monaco-editor/nls/lang/ja`）を使い、Monaco の入口（`src/editor/monaco.ts`）の最初の import で読み込む。以下は Claude の技術的な判断である。
  - 理由: 同梱の翻訳は、同じ版の monaco-editor の文言の一覧と対になっているので、版を合わせる手間が無い。翻訳のファイルは、文言の一覧をグローバルな値に入れるだけで、Monaco の各モジュールは、読み込まれたときと文言を出すときにその値を引く。他の Monaco のモジュールより先に読み込まないと、先に読み込まれたモジュールの文言が英語のまま残る。

## 検討した他の案

- 案: 英語のままにし、仕様に「英語のままとする」と書く
  - 採用しなかった理由: ユーザーが選ばなかった
- 案: 使う文言だけを自分で訳して、Monaco に渡す
  - 採用しなかった理由: Monaco の文言は番号で引かれ、番号は版ごとに変わる。同梱の翻訳なら、版を上げても対が崩れない

## 影響

- monaco-editor の版を上げたときは、同梱の翻訳もその版のものになる。翻訳に無い文言は英語で表示される。
- 翻訳を読み込む import を Monaco の入口の先頭から動かすと、一部の文言が英語に戻る。入口のテスト（`src/editor/monaco.test.ts`）で、先頭にあることを確かめる。
