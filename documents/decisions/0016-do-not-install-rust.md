- 日付: 2026-10-31
- 関連仕様: [外部ツール（cargo・claude）への依存](../spec/architecture/external-tools.md)「見つからない場合」
- 置き換え: なし

## 背景

演習のビルドには Rust ツールチェーンが必要である。もともとの要件で、演習には学習者の環境の Rust コンパイラを使うことにしていた。

## 決定

Rust ツールチェーンが見つからない場合は、rustup の導入手順を案内するだけとし、アプリからは導入しない（`architecture.md`「見つからない場合」）。

## 検討した他の案

- 案: アプリから rustup を実行して自動で導入する
  - 採用しなかった理由: 初心者には親切だが、OS ごとの対応と失敗時の処理が必要になり、学習者の環境を変更することになる
- 案: Rust ツールチェーンをアプリに同梱する
  - 採用しなかった理由: 環境の差はなくなるが、配布サイズが数百 MB 増え、学習者の環境の Rust を使うという方針とも異なる

## 影響

- 実装が単純で、学習者の環境を勝手に変更しない。
- Rust を導入するまで演習を実行できない。
