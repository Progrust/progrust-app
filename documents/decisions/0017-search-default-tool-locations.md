## 背景

macOS では、Finder や Dock から起動したアプリにシェルの `PATH` が引き継がれない。rustup や Claude Code のインストーラーはシェルの設定ファイルで `PATH` を追加するため、`PATH` だけを探すと、インストール済みでも見つからないことがある。

## 決定

`cargo` と `claude` は、設定で指定したパスと `PATH` に加えて、各ツールの既定のインストール先も探索する（`architecture.md`「検出」）。

## 検討した他の案

- 案: ログインシェルを起動して `PATH` を取得する
  - 採用しなかった理由: シェルの種類や設定ファイルの内容によって動作が変わり、起動も遅くなる
- 案: 学習者にパスを手動で設定してもらう
  - 採用しなかった理由: 多くの学習者で設定が必要になる。手動設定は自動検出できない場合の手段として残す

## 影響

- 既定の場所以外にインストールした場合は、設定画面でパスを指定する必要がある。
- ツールの既定のインストール先が変わった場合は、探索先を更新する必要がある。
