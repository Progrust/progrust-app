## 背景

[ADR 0077](0077-curriculum-uses-trpl-as-coverage-guide.md) の「決定」は、「個々の章立て・レッスンの分け方・順序の理由は、この ADR にまとめ、個別には記録しない」と書いている。理由は、23 章・165 レッスンの 1 つ 1 つに理由を記録するのは、手間に見合わないことだった。

その後、個々のレッスンの変更の理由を書いた ADR が増えた。どれも、ADR 0077 のこの文には触れていなかった（Issue #50）。

- [ADR 0104](0104-teach-flush-after-print.md): flush を ch09-05 で教える理由
- [ADR 0114](0114-allow-integration-and-doc-tests.md): ch11-05 と ch11-06 のレッスンを残す理由
- [ADR 0118](0118-teach-background-knowledge-hidden-by-gc-languages.md): レッスンを新設し、後ろのレッスンの ID をずらした理由

Claude は、今後もレッスンの変更の理由を記録し続けることを推奨した。ユーザーは、この推奨を選んだ（選択肢「記録し続ける」）。以下の理由は Claude が書いた。

## 決定

- ADR 0077 の「個々の章立て・レッスンの分け方・順序の理由は、この ADR にまとめ、個別には記録しない」を、ADR 0077 で組み立てたときのカリキュラムだけに当てはまる、に変える。
- その後に、個々のレッスンを足す・移す・残す・分けるなどの変更をしたときは、[ADR の運用ルール](../conventions/decision-records.md)「書く対象」に当てはまれば、その理由を ADR に記録する。
  - 理由: ADR 0077 が記録しないとした理由は、165 レッスンの理由を一度に記録する手間だった。後からの変更は 1 つずつ行い、他の案を検討して選ぶことが多い。記録しないと、後から同じ変更や、元に戻す変更が提案されたときに、理由をたどれない。ADR 0104・0114・0118 は、既にこのとおりに書かれている。

## 検討した他の案

- 案: ADR 0077 のとおり、後からの変更の理由も記録しない
  - 採用しなかった理由: 後からの変更は、技術検証や Issue などの、カリキュラムの全体とは別の理由で行う。その理由は、ADR 0077 の「方針」と TRPL の網羅からは読み取れない

## 影響

- ADR 0077 の「影響」の「個々のレッスンの配置の理由は記録に残らない」は、ADR 0077 で組み立てたときの配置に限られる。
- ADR 0077 で組み立てたときのレッスンの配置の理由は、これまでどおり記録しない。
