## 背景

スライドの見た目と書き方についての ADR（0048〜0051・0053〜0059）は、0076 で動画に引き継がれ、採用のまま残っている。0076 は、これらの本文を書き換えず、「スライド」を「動画」と読み替えると決めた。0083 は、ADR の `description` を移行前のタイトルにすると決めた。その結果、これらの ADR の `description` と索引の行は「スライドの…」のままで、動画の言葉では引けなかった。

ドキュメントの検索のしやすさを確かめる調べもの（0086 の「背景」）で、動画の色が章カラーに従う理由を探させると、索引に動画の色についての行が無く、0048 と 0076 の 2 つを読み合わせて初めて分かった。スライドから動画への切り替え（0060）を知らないエージェントには、これらの行は廃止された教材の話に見える。

Claude は、`description` に動画へ引き継いだことが分かる語を足すことを提案し、0076 が本文を書き換えないと決めているので `description` を変えてよいかの判断を求めた。ユーザーは「改善案の1〜3すべて実施してください。」と承認した。

## 決定

- 後の ADR が判断を別の対象に引き継いだときは、引き継がれた ADR の `description` の末尾に「（ADR NNNN で〈引き継いだ対象〉に引き継いだ）」を足し、索引の行も直す。
- `description` のそれ以外の部分は変えない。本文（「背景」「決定」「検討した他の案」「影響」）も変えない。0076 と 0083 の判断は変えていない。足したのは注記だけで、もとの決定内容の文は残っている。
- 0048〜0051・0053〜0059 の 11 件の `description` に「（ADR 0076 で動画に引き継いだ）」を足した。
- 引き継がれた ADR の関連仕様には、引き継いだ先で判断の内容を定めている concept を載せる（関連仕様に載せる仕様の決まりは 0086）。
- 注記の文言は Claude が決めた。

## 検討した他の案

- 案: `description` を動画の言葉で書き直す（「スライドの…」を「動画の…」にする）
  - 採用しなかった理由: 本文はスライドの言葉のままなので、`description` と本文が食い違う。当時の判断が何についてのものだったかも、`description` から読み取れなくなる。
- 案: 何も足さず、0076 を読んで読み替える
  - 採用しなかった理由: 索引の行だけでは、どの ADR が動画でも有効かが分からない。0076 を先に読むことを知っている必要がある。
- 案: 11 件を置き換え済みにして、動画についての ADR を新しく書く
  - 採用しなかった理由: 判断そのものは変わっていない。0076 が、採用のまま残して引き継ぎを 1 つの ADR に記録すると決めている。

## 影響

- 索引と `description` を「動画」で検索すると、引き継がれた 11 件が見つかり、読み替えを定めた 0076 にもたどれる。
- 今後、判断を別の対象に引き継ぐ ADR を書くときは、引き継がれる ADR の `description` と索引の行にも注記を足す必要がある。
- 注記の形と、足し忘れは、検査では確かめられない。
