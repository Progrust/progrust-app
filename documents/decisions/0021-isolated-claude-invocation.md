- 置き換え: なし

## 背景

`claude -p` は、作業ディレクトリの `CLAUDE.md` や、学習者の Claude Code のユーザー設定（フック・MCP サーバーなど）を読み込む。これらが読み込まれると、アプリが意図しない指示や処理が AI の呼び出しに混ざる。
また、呼び出しごとに入力が長くなる（試行ログ・分析ファイルなど）。

## 決定

呼び出しは次の条件で行う（`claude-integration.md`「呼び出しの共通ルール」）。

- 作業ディレクトリは呼び出しごとの空の一時ディレクトリにする。
- 学習者のユーザー設定を読み込まない設定で起動する。
- 指示文は標準入力で渡す。
- `--continue` / `--resume` を使わず、必要な情報は毎回の入力に含める。

## 検討した他の案

- 案: 学習者のホームディレクトリやアプリのデータディレクトリで呼び出す
  - 採用しなかった理由: `CLAUDE.md` などの意図しない設定を読み込む可能性がある
- 案: 指示文をコマンドライン引数で渡す
  - 採用しなかった理由: Windows ではコマンドラインの長さに上限があり、長い入力を渡せない
- 案: `--resume` で前回のセッションを続ける
  - 採用しなかった理由: 呼び出しの結果が過去のセッションの内容に左右され、学習者の Claude Code のセッション履歴にもアプリの呼び出しが残る

## 影響

- 同じ入力からは、学習者の環境の設定に関係なく同じ条件で AI が呼び出される。
- 会話を続ける質疑応答でも、アプリが会話履歴を入力に含める必要がある（0025）。
