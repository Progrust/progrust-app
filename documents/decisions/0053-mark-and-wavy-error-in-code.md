## 背景

これまでの仕様では、コードブロックの注目させたい行を `data-highlight-lines` で強調していた。スライドのデザインシステムを作るときは、エラーになる行を赤く塗る表示も提案した。サンプルでは、どちらも行全体に帯を引いたので、その行のどこに注目すればよいのか、どこがエラーなのかが分かりにくかった。

## 決定

- `data-highlight-lines`（行全体の強調）を廃止する。
- 注目させたい字句は、文中と同じ `span.mark`（マーカー）で強調する。
- エラーの箇所は `span.error` で示し、VS Code のエラー表示のように赤い波線を引く。2 文字ほどの字句でも波線だと分かる細かさにする。
- 見た目はスライドのデザインシステムに定める。

## 検討した他の案

- 案: 行全体の強調と、エラーの行の帯を残す
  - 採用しなかった理由: 行のどこに注目すればよいか、どこがエラーなのかが分かりにくい

## 影響

- マーカーの上の字句は、読めるように墨の太字にする。強調した字句だけコードの色分けが消えるが、確認して違和感はなかった。
- 作者は、行番号ではなく字句を `span` で囲む。コードブロックの中の `span` は 1 行に収める。
