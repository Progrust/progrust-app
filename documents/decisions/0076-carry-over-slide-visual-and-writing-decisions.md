## 背景

スライドの見た目と書き方について、0048〜0051・0053〜0059 で判断していた。教材を動画に切り替えた（0060）ので、これらの判断が動画でも当てはまるかを決める必要があった。
試作では、スライドのデザインシステムの CSS（トークンと部品）をそのまま使えた（0075）。教材ガイドラインについては、スライドの文章・コード・エラー・図の決まりを、動画の画面の文字に引き継ぐ提案が承認された。
これらの ADR を採用のまま残し、引き継ぎをこの ADR に記録するという ADR の扱いも、提案して承認を受けた。

## 決定

次の ADR の判断は、動画でも引き継ぐ。どれも採用のままとし、本文は書き換えない。本文の「スライド」は「動画」、「スライドのデザインシステム」は動画のデザインシステム「Progrust Video」（0075）と読み替える。本文のうち HTML の記法で書かれた部分は、動画では次のとおりに読み替える。

- 0048（主役・補助の色を章カラーに合わせる）
  - 生きる部分: 主役（`c-primary`）と補助（`c-accent`）の色を章カラーに合わせる。意味の色は合わせない。
  - 当てはまらなくなった部分: 「開いている章」は、アプリが再生するときに指定した章と読み替える。「スライドの HTML には章を書かない。アプリが表示するときに章を指定する」は、動画のコードに章を書かず、アプリが再生するときに章を指定する、と読み替える（`content-format.md`「構成」「色の指定」）。
- 0049（補助の色を章カラーの淡い段にする）
  - 生きる部分: 決定のすべて。
  - 当てはまらなくなった部分: なし。
- 0050（意味と色が結びついた要素を固定の色にする）
  - 生きる部分: 決定のすべて（callout の 5 種類、`c-ok`・`c-ng` を章によらない固定の色にする。画面の 0041 は変えない）。
  - 当てはまらなくなった部分: なし。
- 0051（章に属さずに表示するときの色を第4章の章カラーにする）
  - 生きる部分: 決定のすべて。
  - 当てはまらなくなった部分: なし。
  - いまの仕様で動画を表示するのは、動画画面とレッスン検索のモーダルで、どちらもレッスンの動画を、そのレッスンが属する章を指定して再生する（`screens.md`「動画画面」「レッスン検索」）。章に属さずに動画を表示する場面は、仕様にはない。0051 の「影響」のとおり、章外で表示されるのは例外（0051 の「背景」の、章の分からないプレビューなど）に限られる。
- 0053（コードの強調とエラーの箇所を字句単位で示す）
  - 生きる部分: 行全体の強調をやめ、注目させたい字句はマーカー、エラーの箇所は赤い波線で、字句単位で示す。
  - 当てはまらなくなった部分: 字句を `span.mark`・`span.error` で囲む書き方（「影響」の、`span` を 1 行に収めることを含む）は、共通部品 `CodeBlock` の `marks`・`errors` の指定（行番号と、その行の中の文字列）に変わる（`content-format.md`「コードの表示」）。
  - `content-guidelines.md`「コード」では、行全体に色を付けて強調しないことと、読み上げている行に目を向けさせるときはほかの行を淡くしてよいことを定めている。読み上げている行以外を淡くする表現は、試作で使ったものである。
- 0054（Diff を行の先頭の記号で書き、固定の色で示す）
  - 生きる部分: 各行の先頭に `+`・`-`・半角空白を書く形、追加・削除の固定の色、削除行に取り消し線を付けないこと、変更後のファイルの行番号だけを表示して削除行には付けないこと。
  - 当てはまらなくなった部分: `data-diff` 属性での指定は、台本の `code_blocks` の `diff` に変わる（`content-format.md`「台本（script.json）」「コードの表示」）。本文の `content-format.md`「コードブロック」は「コードの表示」と読み替える。
- 0055（マーカーを固定の黄にする）
  - 生きる部分: マーカーを、章によらない固定の黄にする。
  - 当てはまらなくなった部分: `span.mark` という書き方は、コードの中では `CodeBlock` の `marks` の指定に、画面の文章ではデザインシステムのクラス `mark` に変わる（`content-format.md`「シーン」「コードの表示」「色の指定」）。
- 0056（コードに行番号を表示し、行番号で指してよい）
  - 生きる部分: ターミナルの出力以外のコードに行番号を表示すること、行番号の見た目（0056 の案 A。範囲の枠は行番号の欄の内側に置く）、行番号でコードを指してよいこと、行番号をファイルの行番号とし、途中から載せるときは開始行を指定すること、ターミナルの出力ではないテキストをターミナルの出力と分けて書くこと。
  - 当てはまらなくなった部分: `data-start-line` 属性での指定は、台本の `code_blocks` の `start_line` に変わる。`language-text`・`language-plaintext` のクラスは、`code_blocks` の `language` の値 `text`・`plaintext` に変わる（`content-format.md`「台本（script.json）」「コードの表示」）。
  - 「作者が属性に書く行番号も、文で指す行番号も、表示される番号で書く」は、次のとおりになった。動画では行を差し込む動きを付けられ、その途中では、表示される行番号が `code_blocks` の行番号と違うことがある。`CodeBlock` の指定に書く行番号は、差し込みの途中でも `code_blocks` の行番号で書く（`content-format.md`「コードの表示」）。文で行番号を指すのは、両方が同じになるところだけにする（`content-guidelines.md`「コード」）。
- 0057（生きている範囲をコードに重ねた枠で示し、図の中にコードを書かない）
  - 生きる部分: コードは図の中に書かず、図の中は短いラベルだけにする。変数が生きている範囲は、図にせずコードの行を囲む枠で示す。範囲の枠と Diff は、同じコードブロックで使わない。
  - 当てはまらなくなった部分: `data-scopes` 属性での指定は、`CodeBlock` の `scopes` の指定に変わる。台本の `code_blocks` には持たない（`content-format.md`「コードの表示」）。「影響」の `content-format.md`「コードブロック」は「コードの表示」と、`two-column` を使うことは左右に並べることと読み替える（`content-guidelines.md`「図」）。
- 0058（エラーをエラーコードだけで説明しない）
  - 生きる部分: 決定のすべて（画像の `alt` を含む）。エラーを指すときは何が起きたのかを言葉で書き、エラーコードは言葉の説明に添えるときだけ使う。コンパイラの出力の中のエラーコードはそのままでよい。動画では、画面の文字に加えて、台本（ナレーション）にも当てはめる（`content-guidelines.md`「エラー」）。
  - 当てはまらなくなった部分: なし。
- 0059（見出し・箇条書き・図の語句に常体と体言止めを許す）
  - 生きる部分: 画面の見出し・箇条書き・表・図の語句は、言い切りの常体か体言止めでよい。画面の本文と callout は「です・ます」調にする。
  - 当てはまらなくなった部分: `h1`・`h2`・`li`・`p` という HTML の要素名での言い方は、画面の見出し・小見出し・箇条書き・本文という言い方に変わる（`content-guidelines.md`「画面の文章」）。
  - 0059 が対象にするのは画面の文字である。ナレーション（台本）は「です・ます」調にする（`content-guidelines.md`「台本」）。

## 検討した他の案

- なし（提案した ADR の扱いが承認された）

## 影響

- 0048〜0051・0053〜0059 は採用のまま残る。HTML の記法で書かれた本文は、この ADR の読み替えとあわせて読む必要がある。
- コードの表示と色の決まりは、動画の形で `content-format.md`「コードの表示」「色の指定」に定める。
- 引き継いだ判断の見た目の値は、動画のデザインシステム（0075）に定める。
