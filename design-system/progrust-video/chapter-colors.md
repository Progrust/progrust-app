## 見分けにくい組（色以外で区別する）

- `c-ok`（緑）と `c-ng`（赤）は明るさがほぼ同じ（コントラスト 1.1:1）。赤と緑を見分けにくい色覚のために、文字の `c-ok` / `c-ng` と callout.ok / ng には CSS が ✓ / × の形を付ける。図では作者が ✓ / × を描く。
- 第2章・第12章では、主役（章カラー）と `c-ok`（成功の緑）が似た色になる。第4章では主役と `c-ng` が近い色相になる。✓ / × と文言で区別する。
- ダークでは章カラーの線と既定の線がどちらも明るく、明るさの差が小さい。主役は塗りか太さ（線 3）でも示す。
- 第8章（空色）は第7章（青緑）・第1章（青）と色相が近い（どちらとも 20° 前後）。第9章（紺）とはライトで明るさが違う。隣の第7章とは、並べて見れば区別できる程度の差がある。
- Diff の追加の色（青竹）は第2章（緑）・第7章（青緑）と色相が 20° 余り離れている。Diff はコードブロックの行の帯と「+」の記号として出るので、形でも区別できる。
