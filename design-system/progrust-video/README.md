Progrust Video は、Progrust のレッスンの動画（仕様書 `content-format/video/index.md`）の**中身の見た目**を定める。動画は白い地に墨色の文字で組み、開いている章の色（章カラー）を「主役」の色にする。章が進むと動画の主役の色も変わり、画面のアクセント（アプリ側「Progrust」）と同じ色でつながる。

この README は、動画を書く人とエージェントのための使い方のルールである。値はすべて `tokens.json` にあり、ここではトークンの名前で書く。部品ごとの書き方は各部品の README、章ごとの実際の色とコントラストは「章カラーごとの実際の色」（`chapter-colors.md`）にある。

## 位置づけ

- **対象**: 動画の枠の中に描画するもの（ステージ、配置、文章、コード、出力、表、callout、図、画像と、寄せ・動き）。動画の台紙（枠・角丸・影）、プレーヤーの操作、字幕、検索のモーダルはアプリ側「Progrust」の対象（仕様の `screens/appearance.md`「デザインシステム」）。
- **アプリ側との関係**: 書体、基本の色（`bg`・`ink` など）、章カラー（`chapter-1`〜`chapter-12`）、意味の色（`danger`・`warning`）、コードの色（`code-*`）は、アプリ側の同名トークンの**写し**である（各トークンの説明に明記）。値を変えるときはアプリ側を変えて、ここを合わせる。このシステムで新しく決めるのは `video-*` のトークンと、`components/bundle.css` の部品の規則だけ。
- **動画の作り**: 動画は動画ファイルではなく、アプリの中で Remotion の Player が描画する。シーンは React（TSX）で書き、使える要素と部品は制限されない（仕様の `content-format/video/structure.md`・`content-format/video/scenes.md`）。そのため、このシステムは「使える要素の一覧」ではなく、動画のコードが使うクラス・トークンと、教材用の共通部品（`CodeBlock`・`Camera`・`LessonTitle` など。仕様の `content-format/video/scenes.md`「共通部品」）が出力する HTML の形を定める。
- **実装**: アプリはアプリ側の `tokens.css` をそのまま使い、このシステムの `video-*` トークンと `bundle.css` の 1〜11 節を動画のテーマ CSS として動画に適用する（`vd-` で始まるクラスは見本の表示用で、アプリでは使わない）。
- **名前**: このシステムは、スライドのデザインシステム「Progrust Slides」を動画用に改めたものである（ADR 0075）。色・書体・コードの見た目の判断は引き継いでいる（ADR 0076）。

## 動画の原則

- **書き方のルールは仕様書に従う**。動画の構成と長さ、台本、画面の見出しと文章の書き方、コードの行の指し方、エラーの説明のしかた、図とコードの分け方、合図の合わせ方は、Progrust の仕様書 `content-guidelines/video.md` を唯一の定義とする。動画のファイル、シーンの書き方、共通部品の指定のしかた、色の指定と禁止事項は仕様の `content-format/video/index.md` に従う。このシステムは、見た目に関わる決まり（寄せ・文字の大きさ・動き・量・配置・色・書体・寸法）と、共通部品が出力する HTML の形だけを定める。寄せ方、文字の最小サイズ、動きの種類と速さ、1 画面に載せる量は、この節が唯一の定義である（仕様の `content-guidelines/video.md`「動きと画面の量」）。
- **1 つの画面の上で変えていく**。シーンの中では、同じコードと同じ図を置いたまま、ナレーションの進みに合わせて変える（行を差し込む、マーカーを引く、所有者の印が動く、読み上げている行以外を淡くする）。同じものは、シーンのあいだ同じ位置に置く。
- **内容のある範囲へ寄せる**。寸法・書体・色はトークンのまま組み、場面ごとに映す範囲だけを変えて、文字と図を大きく見せる。スライドの寸法のままだと、動画では文字が小さいためである（ADR 0068）。
- **色は少なく**。主役と補助は章カラー（`c-primary` / `c-accent`）の 1 色相だけ。そのほかの色は、意味が決まった色（成功の緑 `c-ok`、誤りの赤 `c-ng`、callout の 5 色）と墨・灰だけ。`c-primary` は、同時に 1〜2 か所。
- **意味は色だけで伝えない**。正しい・誤りは ✓ / × の形と文言を添える（文字と callout では CSS が自動で付ける。図では描く）。
- **字幕は動画の中に置かない**。字幕はアプリの機能で、動画の枠の外（下）に表示する（仕様の `screens/video-screen.md`）。字幕の帯を動画の中に置くと、文字と図が小さくなるためである（ADR 0067）。動画の下の端に、字幕のための空きを取らない。

### ステージ

- 基準サイズは 1280×720（`video-width` × `video-height`）、16:9、30fps（`video-fps`）。値はすべてこの基準サイズでの px で、アプリが表示領域に合わせて拡大・縮小する（仕様の `content-format/video/structure.md`）。
- シーンは、根に `.video-stage`（1280×720 のステージ）を 1 つ描く。このシステムの部品の規則は、すべて `.video-stage` の中だけに効く。寄せるときは、共通部品 `Camera` の中にステージを置く。
- ステージの余白・縦の間隔・列の幅は「寸法とグリッド」のとおり。ステージの外（寄せて映る範囲がステージからはみ出したところ）は、ステージの地と同じ `video-bg`。
- `data-layout` で、配置の基本形を選べる（省くと、上から積む `content`）。

| `data-layout` | 配置 | 部品 |
| --- | --- | --- |
| `title` | 表紙（最初のシーン）。レッスン名とサブタイトル、右に章カラーの飾り | LayoutTitle |
| （なし）/ `content` | 見出しの下に、上から積む | LayoutContent |
| `two-column` | 見出しの下に、左右 2 列 | LayoutTwoColumn |
| `code` | 見出し + コード 1 つ（幅いっぱい） | LayoutCode |
| `diagram` | 見出し + 図 1 つ（中央） | LayoutDiagram |
| `summary` | まとめ（最後のシーン）。見出し + ✓ の付いた項目 | LayoutSummary |
| `statement` | 要点の 1 文を大きく | LayoutStatement |

- **変えていく画面は、位置を固定して組む**。ブロックが現れたり消えたりしても、ほかのブロックが動かないようにする。上から積む配置のままブロックを足すと、下のブロックが押されて動く。コードと図を左右に並べて変えていく画面は、`data-layout` を付けないステージに、位置と幅を決めて置く（`position: absolute`。見本は「Camera」）。位置の基準は次のとおり。

| 位置 | 値（基準の px） |
| --- | --- |
| 左端 | 72（`video-space-72`） |
| 見出しの上端 | 64（`video-space-64`） |
| 内容の上端（見出しが 1 行のとき） | 149（上の余白 64 + 見出し 57 + 間 28） |
| ブロックの間 | 24（`video-space-24`） |
| 左右に並べるブロックの間 | 32〜40 |

### 寄せ方

寄せは、共通部品 `Camera`（仕様の `content-format/video/scenes.md`「共通部品」）で行う。ステージ（1280×720）のうち、左上が (x, y) で、幅が 1280 ÷ 倍率・高さが 720 ÷ 倍率の範囲を、動画の枠いっぱいに映す。ステージの中身は変えない。

- **倍率**: 表紙は寄せない（1 倍、`video-zoom-none`）。そのほかの画面は、内容のある範囲へ 1.12〜1.35 倍（`video-zoom-min`〜`video-zoom-max`）で寄せる。1.35 倍を超えて寄せない。

| 画面 | 内容のある範囲の幅 | 倍率 | 映る範囲 |
| --- | --- | --- | --- |
| 表紙、全体を見せる短い間 | 1136（全幅） | 1 | 1280×720 |
| 左右 2 列（他の言語との比較など） | 1040 | 1.12 | 1143×643 |
| コード + 図（左右） | 1004 | 1.16 | 1103×621 |
| コード + 出力（上下。幅いっぱい） | 983 | 1.2 | 1067×600 |
| まとめ | 820 | 1.35 | 948×533 |

- **倍率の決め方**: 内容のある範囲（見出し・柱を含む）の左右・上下に、基準の px で 40（`video-zoom-margin`）以上の余白が残る、最大の倍率を目安にする。幅 w の内容なら、1280 ÷ (w + 80) が上限になる。上の表の画面と違う内容のときも、この決め方で 1.12〜1.35 の間で決める。
- **寄せたあとの余白**: 左右の余白はそろえる（x = 内容の左端 −（1280 ÷ 倍率 − 内容の幅）÷ 2）。上は、ステージの上端に合わせる（y = 0。見出しの上に 64 の余白が残る）。内容の下の空きが 100 を超えるときは、y を負にして空きを上にも分ける（映る範囲がステージの外に出てよい。上の空きを下の空きより大きくしない）。見出しを消して、その下の内容へ寄せるときは、内容の上にも 40 以上の余白を残す（y は、内容の上端 − 40 まで）。
- **寄せるために配置を詰める**: 寄せると映る幅が狭くなるので、内容を左に寄せて詰める。左右 2 列は列を 500・間を 40 にする（`two-column` の既定は列 544・間 48）。コードと図を並べるときは、コード 480・間 32・図 492 を目安にする。図は横幅を詰める（スタックとヒープの領域の間を 64 にする）。
- **1 倍に引くのは短い間だけ**: 1 倍では文字が小さい。表紙のほかに 1 倍を使うのは、画面を組み替えるあいだ全体を見せるとき（図をしまってコードを広げ、出力を出す）だけにし、読ませるところでもう一度寄せる。
- **シーンが変わるとき**: 寄せは動かさない。シーンごとの寄せで始め、シーンの出入りのフェード（下の表）で切り替える。
- **シーンの中で寄せを変えるとき**: x・y・倍率を同時に、24〜28 フレーム（`video-frames-camera`）・`video-ease-in-out` で動かす。寄せを変えるのは、読ませる範囲が変わるときだけにする（1 分ほどのシーンで 2 回まで）。
- **映る範囲の外に出るもの**: 寄せで見出しが映らなくなるときは、寄せ始めに見出しを消す（10 フレーム）。柱は、映る範囲の外に出てよい。
- 寄せても、線の太さ・角丸・文字の大きさのトークンは変えない（映る大きさが倍率の分だけ大きくなる）。

### 文字の最小サイズ

- 画面に表示される文字の大きさは、**基準の文字サイズ × 寄せの倍率 × 表示倍率**で決まる。
- **基準の文字サイズ**は 18px（`video-min-text`）未満を使わない。図の中の文字、画像の中の文字も同じ。
- **寄せたあと**（基準の文字サイズ × 寄せの倍率）で、読み上げに合わせて読ませる文字（コード、出力、本文、callout、箇条書き、表、図のラベルと補足）は 20px（`video-min-text-zoomed`）以上にする。18px の文字（出力、図の補足、表の見出し）は、1.12 倍以上に寄せた画面で読ませる。行番号・柱・コードのラベル・figcaption は、18px のままでよい。
- **表示倍率**は、アプリが動画を表示領域に収めるときの倍率である（動画画面の配置は仕様の `screens/video-screen.md`）。

| ウィンドウ | チャットパネル | 表示倍率 | 決まり方 |
| --- | --- | --- | --- |
| 初期サイズ（1280×800） | 開く | 約 0.68 | 幅（チャットパネルの幅を引いた残り） |
| 最小（1024×700） | 開く | 約 0.48 | 幅 |
| 初期サイズ（1280×800） | 閉じる | 0.83 以下 | 高さ（ヘッダーとプレーヤーの操作の高さを引いた残り。「未決事項」） |

- 寄せたあとで 20px の文字は、初期サイズでチャットパネルを開いたとき約 13.6px、最小のウィンドウで約 9.6px で表示される。寄せていない 18px の文字は、それぞれ約 12.2px、約 8.6px になる。読ませる文字を小さくしないために、基準の文字サイズを下げるのではなく、載せる量を減らして寄せる。

### 動きの種類と速さ

動きは、フレームから計算した進み具合（0〜1）で作る（仕様の `content-format/video/scenes.md`）。CSS のアニメーションとトランジションは使わない。長さは 30fps でのフレーム数で、イージングは 2 種類だけ使う。

- **すっと止まる動き**（`video-ease-out`）: 現れる・消える・描く・淡くする・差し込む・入力するの既定。
- **ゆっくり動き出して、ゆっくり止まる動き**（`video-ease-in-out`）: 画面の中で位置や大きさが変わる動き（移る・寄せる・幅を変える・線を描く）。

| 動き | 使うとき | 長さ（フレーム） | イージング | 見た目 |
| --- | --- | --- | --- | --- |
| シーンの出入り | シーンが始まる・終わる | 10（`video-frames-scene-fade`） | すっと止まる | ステージ全体の不透明度だけを変える。最後のシーンは、終わりで消さない（最後の絵のまま止まる） |
| 現れる | ブロック・見出し・図の部品を新しく出す | 16（`video-frames-enter`。14〜18） | すっと止まる | 不透明度 0 → 1。下から 16px（`video-rise`）上がりながら現れる。見出しは 14px。図の中の部品は 10〜16 フレームで、不透明度だけか、10px 以下 |
| 消える | 役目を終えたものをしまう | 8（`video-frames-exit`。6〜10）。図の中で一時的に見せたものは 12〜16 | すっと止まる | その場で不透明度 1 → 0。見出しは上へ 10px、しまう図は横へ 24px 動かしてよい |
| 入れ替える | 同じ位置の見出し・callout を、次のものに替える | 消える 6〜8、現れる 16 | すっと止まる | 前のものが消えてから、同じ位置に次のものが現れる（見出しは、前の見出しが消え始めてから 6 フレーム後に現れ始める） |
| 移る | 図の中の印や矢印が、別の位置へ移る | 30（`video-frames-move`） | 動き出して止まる | 位置を補間する。印と一緒に動くもの（添え書き、矢印の根元）は同時に動かす |
| 寄せる | シーンの中で、映す範囲を変える | 24〜28（`video-frames-camera`） | 動き出して止まる | x・y・倍率を同時に補間する（「寄せ方」） |
| 幅を変える | ブロックを広げる・狭める | 20（`video-frames-resize`） | 動き出して止まる | 幅を補間する |
| 描く（マーカー） | 字句・語句にマーカーを引く | 12（`video-frames-draw`。文中の語句は 14） | すっと止まる | 帯が左から右へ伸びる（`--mark-p`） |
| 描く（波線） | エラーの箇所に波線を引く | 12（`video-frames-draw`） | すっと止まる | 波線が左から右へ現れる（`--error-p`） |
| 描く（線・矢印） | 図の矢印を引く | 18（`video-frames-line-draw`） | 動き出して止まる | 根元から先へ線が伸びる。矢じりは、線を描き始めて 14 フレーム後から 6 フレームで現れる |
| 範囲の枠が現れる | 生きている範囲の枠を出す | 16（`video-frames-enter`） | すっと止まる | 不透明度 0 → 1（`--scope-p`） |
| 淡くする | 読み上げている行以外を目立たなくする | 8（`video-frames-dim`）。戻すのも 8 | すっと止まる | 行の不透明度を `video-dim-opacity`（0.32）まで下げる（`--line-dim`） |
| 差し込む | コードに行を足す | 8（`video-frames-open`）で行の間を開け、続けて入力する | すっと止まる | 行の高さが 0 から 1 行分（32px）まで開き、下の行が下がる（`--line-open`） |
| 入力する | コードの行を書いていく | 1 行 8〜22（1 フレームに 1〜1.5 字が目安） | すっと止まる | 左から 1 字ずつ現れる。入力の途中は、末尾にカーソル（`span.caret`）を出す |
| 1 行ずつ出す | 出力の行を順に出す | 2 フレームに 1 行 | 一定の速さ | 行が上から順に現れる |

使い方のルール:

- **動きは、ナレーションがそのことを言う位置に合わせる**（合図。仕様の `content-guidelines/video.md`「動きと画面の量」）。言葉と関係のない動きを足さない。
- **動きは、意味のある変化にだけ使う**。新しく出す（現れる）、しまう（消える）、関係が変わる（移る）、注目する箇所を示す（描く・淡くする・寄せる）、コードが変わる（差し込む・入力する）のどれかである。飾りの動きは、表紙の章カラーの飾りだけ（LayoutTitle）。
- **その場で変える**。同じものは同じ位置に置いたまま、変わる部分だけを動かす。ブロックを画面の外から滑り込ませない。
- **続けて現れる要素は、ずらす**。同時に出さず、4〜8 フレームずつずらして、上から・左から順に出す。
- **繰り返す動きを使わない**。点滅・脈打つ動き・回り続ける動きは使わない。カーソルは点滅させない。誤った状態を示す短い揺れ（左右に 3px、30 フレームほど）は、1 つのシーンに 1 度まで。
- **淡くする行**: 淡くした行の文字は、地に対して 1.6〜2.6:1 になり、読ませる文字の基準（4.5:1）に届かない。そのため次を守る。
  - 淡くするのは、いま読ませない行だけにする。読み上げで指している行は淡くしない。少なくとも 1 行は、通常の濃さで残す。
  - 淡くする行は、淡くする前に通常の濃さで見せておく。淡くした状態で初めて出さない。
  - 行に色を付けない。行全体に色を付けて強調しないこと、読み上げている行以外を淡くしてよいことは仕様の `content-guidelines/video.md`「コード」 に従う。
  - 読む行が移ったら、淡くする行を入れ替える。説明が終わったら戻すか、シーンの終わりまでそのままにする。
  - コードと出力を上下に並べたときは、出力の読んでいる行と、その行が指すコードの行だけを残して、両方のブロックで同時に淡くする。

### 1 画面に載せる量

同時に映っている量の目安である。シーンの中で変えていくので、シーン全体で出す量ではなく、ある瞬間に映っている量で数える。

- **見出し**: 1 行。字数は、内容の幅 ÷ 44 まで（下の表）。見出しは、ナレーションの進みに合わせて切り替えてよい（仕様の `content-guidelines/video.md`「画面の文章」）。切り替えても位置は変えない。
- **ブロック**（コード・出力・図・callout・表・箇条書き・本文）: 見出しのほかに、同時に 3 つまで。左右 2 列で比べるときは、各列 2 つ（コード + callout）まで。
- **callout**: 同時に 1 つ（左右 2 列で比べるときは各列に 1 つ）。1〜2 文。説明が進んだら、同じ位置で次の callout に入れ替える。
- **本文**（`p`）: 同時に 1 つ、2 行まで。箇条書きは 5 項目まで、各 1 行。項目は、読み上げに合わせて 1 つずつ出す。
- **コード**: 行数と 1 行の字数は、寄せの倍率で決まる（下の表）。図と左右に並べるときは、幅 480（1 行 32 字）で 8 行まで。
- **出力**: 10 行まで。コードと出力を上下に並べるときは、合わせて 14 行まで（コード 5 行 + 出力 9 行で、高さ 511）。1.2 倍では、見出しを消して寄せたときに収まる。
- **図**: 1 つ。コードと左右に並べるときは、幅 500・高さ 280 までを目安にし、下に callout を 1 つ置ける。図だけを置くときは、内容の幅と、見出しの下の高さに収める。
- **まとめ**: 項目 3〜5、各 1 行。3〜4 項目なら 1.35 倍、5 項目なら 1.2 倍まで。
- **表紙**: レッスン名は 2 行まで（1 行 12 字）、サブタイトルは 1 行（27 字まで）。
- **表**: 4 列・5 行（見出しを除く）まで。

寄せの倍率ごとの量（見出しが 1 行で、映る範囲の上端をステージの上端に合わせたとき）:

| 倍率 | 映る範囲 | 内容の幅 | 見出しの下の高さ | 見出しを消したときの高さ | 見出し | コードだけ | コード + callout か本文（2 行） | コードの 1 行 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 1280×720 | 1136（`video-content-width`） | 523（`video-content-height`） | — | 25 字 | 15 行 | 11 行 | 86 字 |
| 1.12 | 1143×643 | 1063 | 454 | 563 | 24 字 | 12 行 | 8 行 | 80 字 |
| 1.16 | 1103×621 | 1023 | 432 | 541 | 23 字 | 12 行 | 8 行 | 77 字 |
| 1.2 | 1067×600 | 987 | 411 | 520 | 22 字 | 11 行 | 7 行 | 74 字 |
| 1.35 | 948×533 | 868 | 344 | 453 | 19 字 | 9 行 | 5 行 | 64 字 |

- 内容の幅は、映る幅 − 80（左右の余白 40 ずつ）。見出しの下の高さは、映る高さ − 149（内容の上端）− 40（下の余白）。見出しを消したときの高さは、映る高さ − 80（上下の余白 40 ずつ）。行数は、見出しの下の高さで数えている。1 倍の行は、ステージの余白（左右 72、下 48）での値。
- コードブロックの高さは 32 × 行数 + 40。1 行に入る字数は「行番号」の式による（幅いっぱいのコードブロックでの値。Diff・範囲の枠があると減る）。
- 量が収まらないときは、文字を小さくせず、シーンを分けるか、いま説明していないブロックをしまう。

### 使える表現の例

1 つの画面の上でコードと図を変えていく表現の例。どれも上の表の動きの組み合わせである。

- **読み上げている行以外を淡くする**: エラーメッセージを読むあいだ、出力のうち読んでいる行と、その行が指すコードの行だけを残す。
- **所有者の印が動く**: 所有者を表す章カラーの塗り（`fill-primary`）が、元の変数の箱から移った先の箱へ移り、矢印の根元も一緒に移る。元の箱は破線の「使えない」箱になり、矢印の跡が破線で残る（DiagramPatterns）。
- **行を差し込む**: コードの行の間を開けて、新しい行を入力する。行番号の扱いは仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」、文での指し方は仕様の `content-guidelines/video.md`「コード」 に従う。
- **マーカー・波線を、言葉に合わせて描く**: 字句の名前を読み上げる位置で、その字句にマーカーや波線を描く。
- **見出しと callout を入れ替える**: 画面の構成はそのままで、いま伝えていることに合わせて、見出しと callout だけを替える。
- **「もしも」を一時的に見せて、戻す**: 起こらないこと（所有者が 2 つある状態）を図に重ねて見せ、誤りの赤（`stroke-ng`）と × で示してから、元に戻す。起こらないもの（コピーされたデータ）は、破線（`video-stroke-dash`）で一時的に見せて消す。
- **全体に引いてから、読ませる範囲へ寄る**: 図をしまい、1 倍に引いてコードを広げて出力を出し、出力を読むところでコードと出力へ寄る。
- **項目を 1 つずつ出す**: まとめの項目を、読み上げに合わせて上から順に出す。

## 寸法とグリッド

- ステージは 1280×720（`video-width` × `video-height`）。値はすべてこの基準サイズでの px。

## 色

### 章カラーとの連動

- アプリは、動画を描画する範囲（動画画面の動画、レッスン検索のモーダルの動画）に `data-chapter="N"` を付ける（アプリ側 README「章カラー」と同じ）。`bundle.css` 1 節の規則で `accent` 系が第 N 章の色になり、`video-primary` などがそれに従う。
- **動画のコードには章もテーマも書かない**（仕様の `content-format/video/structure.md`）。同じ動画は、どの章で再生してもその章の色になる。章の並べ替えや 13 章目以降の循環（第 N 章は `chapter-((N − 1) mod 12 + 1)`）にもそのまま従う。
- 12 色すべてで同じ画面が成り立つことを「ChapterColors」で確かめられる。
- **章外は第4章の色（マゼンタ）**: 動画が章の外で表示されるときは、主役・補助の色（`video-primary`・`video-primary-ink`・`video-on-primary`・`video-accent-fill`・`video-accent-ink`）が第4章の値（`chapter-4` 系のトークンを参照）になる。
  - **アプリの画面との違い**: アプリの画面の章外は墨色（アプリ側 README、ADR 0042）で、これは変えない。動画では主役が墨色だと本文の墨と区別できず、mark・枠・図の主役などの強調が見えにくくなるので、章外でも色を持たせる。第4章のマゼンタは、デザイン案で最初に作った章カラーで、白い地でも暗い地でも本文の墨とはっきり分かれる。
  - **章外の渡し方**: アプリは、章の中の動画を描画する範囲に `data-chapter="1"`〜`"12"`（章カラーの番号。13 章目以降は循環させた番号）を付ける。章外の動画では `data-chapter` を付けない。CSS は値が `1`〜`12` のときだけ章の中として扱うので、`data-chapter="none"` や範囲外の値を付けても章外（第4章の色）になる。ただしアプリは章外を「属性を付けない」で表す。
  - 教材の動画は必ず章に属するので、章外で表示されるのは例外（章の分からないプレビューなど）である。
  - `accent-line` に当たる中間の色は、動画では使わない。

### 色クラスの意味と実際の色

動画のコードでは色を直接書かず、このシステムのトークン（CSS 変数）と、次のクラスだけを使う（仕様の `content-format/video/colors.md`。色の直接指定は仕様の `content-format/video/prohibited-code.md` の lint でエラーになる）。文字には `c-*`、SVG には `fill-*` / `stroke-*` を付ける。

| クラス | 意味 | 文字（`c-*`、SVG の `text` に `fill-*`） | 塗り（`fill-*`） | 線（`stroke-*`） |
| --- | --- | --- | --- | --- |
| `primary` | 主役（注目させたいもの） | `video-primary-ink`（= `accent-ink`）・太さ 700 | `video-primary`（= `accent`）。中の文字は `fill-on` | `video-primary` |
| `accent` | 補助的な強調 | `video-accent-ink`（= `accent-ink`）・太さ 500 | `video-accent-fill`（= `accent-soft`）。中の文字は `fill-accent` | `video-accent-ink` |
| `ok` | 正しい・成功（章によらない緑） | `video-ok-ink`・太さ 700・先頭に ✓ | `video-ok`。中の文字は `fill-on` | `video-ok` |
| `ng` | 誤り・エラー | `video-ng-ink`（= `danger-ink`）・太さ 700・先頭に × | `video-ng`（= `danger`） | `video-ng` |
| `muted` | 背景的な情報・無効になったもの | `video-muted`（= `muted`）・太さ 400 | `video-muted-fill`（= `field`） | `video-muted-stroke`（= `disabled-ink`） |

### 判断と理由

- **`c-primary` は章カラー**。動画の主役を、画面のアクセント（主ボタン・進み具合）と同じ章の色にする。章の中にいる合図が動画の中まで続く（ADR 0039）。
- **`c-accent` は同じ章カラーの淡い段**（塗りは `accent-soft`、文字と線は `accent-ink`）。
  - 12 色の章カラーが色相環をほぼ一周しているので、どの章ともぶつからない固定の 2 色目は選べない。
  - ほかの章の色を借りると「いまどの章か」の合図が崩れる（ADR 0042 と同じ考え）。
  - 墨色を 2 色目にすると、墨の線・文字と区別がつかない。
  - 同じ色相の濃い塗りと淡い塗りなら、色覚にかかわらず明るさの差で見分けられる。
  - 淡い色（`accent-soft`・`accent-line`）は線や文字にするとライトの bg に対して 1.1〜1.6:1 しかなく読めないので、線と文字は濃い段の `accent-ink` にする。そのため**線の色は primary と accent でほぼ同じ**になる。主役と補助は、塗り（濃い／淡い）と線の太さ（3／2）で区別する。
- **意味の色は章によらず固定**。成功＝緑、誤り＝赤、注意＝橙、情報＝青のように、意味と色が一般に結びついているものは、章カラーではなくその色で表す。章カラーは「主役」と「補助」だけに使う。
  - **`c-ok` は成功の緑**（`video-ok`・`video-ok-ink`・`video-ok-soft`）。章カラーとは別の色なので、`c-ok` と `c-primary` は 1 つの画面の中で並べて使える。
  - **アプリの画面との違い**: アプリの画面は「成功専用の緑を持たず、正解・完了を章カラーで表す」（アプリ側 README、ADR 0041）。画面の正解は 1 回の出来事で、チェックの形と文言だけで伝わり、章カラーで祝う演出を優先している。動画は「正しい書き方と誤った書き方」を並べて比べる教材で、学習者が一般に知っている緑＝正しい・赤＝誤りの対応のほうが読み取りやすい。そのため動画の中だけ緑を持つ。
  - 成功の緑（色相 144°）は、緑の章カラー（第12章 142°・第2章 164°）と色相が近い。ライトでは成功の緑のほうが暗く、ダークでは暗く鮮やかにして明るさと鮮やかさで離した（色差はライト 0.067〜0.076、ダーク 0.050〜0.080）。Diff の追加（186°）、mark の黄、誤りの赤とは十分に離れている。第2章・第12章では主役と成功が似た色になるので、✓ の形と文言を必ず添える。
- **`c-ng` はアプリの `danger`**。誤りは章によらず同じ赤にする。`c-ok`（緑）と `c-ng`（赤）は明るさがほぼ同じ（1.1:1）で、赤と緑の区別がつきにくい色覚では見分けにくい。そのため ✓ / × の形と文言が必須である。文字では CSS が先頭に Lucide の `check` / `x` を自動で付ける。
- **`c-muted` は灰**。無効になったもの（ムーブしたあとの変数）は、図では破線（`video-stroke-dash`）も併用する。
- **マーカー（`mark`）は蛍光ペンの黄（アプリの `mark`）で、章によらず同じ色**。マーカーという比喩は章を問わず通じる。章の淡い面（`c-accent`）と区別でき、アプリの検索結果で一致部分を示す色とも同じになる。帯は文字の下 42% だけに引き、文字の色を変えない。
- **callout は 5 種類とも章によらない固定の色**: `info` は情報の青（`video-info-fill`・アイコン `video-info-icon` = `link`）、`tip` はヒントの紫（`video-tip-fill`・`video-tip-icon`）、`warn` は注意の橙（`warning-soft`・`warning`）、`ng` は誤りの赤（`danger-soft`・`danger-ink`）、`ok` は成功の緑（`video-ok-soft`・`video-ok`）。紫は、ほかの 4 色（青・橙・赤・緑）のどれとも色相が離れていて、ヒント・重要の意味でよく使われる色として選んだ。地どうしはダークでも色相で見分けられる（ok と ng の地はダークで色差 0.087）。
- **注意（`warning`）は callout.warn とコンパイラの出力にだけ使う**。色クラスには含めない（仕様の `content-format/video/colors.md` にない）。

### コードの色

- コードの字句の色はアプリ側の `code-*`（Monaco Editor のテーマの元）と同じにする。例外はコメントで、`video-code-comment`（= `muted`）にする。アプリの `code-comment` は `panel` の上で 4.42:1 で、動画のコードの地（`video-code-bg` = `panel`）に置くと 4.5:1 に届かないため。
- 字句のクラス（共通部品 `CodeBlock` がシンタックスハイライトで付ける）:

| クラス | 字句 | 色 |
| --- | --- | --- |
| `tk-k` | キーワード（`fn` `let` `mut` `impl` `match` `self`） | `code-keyword` |
| `tk-s` | 文字列・文字 | `code-string` |
| `tk-m` | マクロ（`println!`） | `code-macro`・太さ 600 |
| `tk-a` | 属性（`#[derive(Debug)]`） | `code-macro` |
| `tk-t` | 型（`String` `i32` `Vec`） | `code-type` |
| `tk-n` | 数値・`true` / `false` | `code-type` |
| `tk-l` | ライフタイム（`'a`） | `code-type`・斜体 |
| `tk-f` | 関数・メソッドの名前 | `code-function` |
| `tk-c` | コメント | `video-code-comment` |

  `tk-a`・`tk-n`・`tk-l` はアプリ側にない区分で、既存の色に割り当てた。Monaco のテーマと字句の分け方をそろえるかどうかは「未決事項」。

### コードの中の強調・エラー・Diff

コードでは行全体に色を付けて強調しない（仕様の `content-guidelines/video.md`「コード」）。どの字句に注目すればよいかが分からなくなるため。代わりに次の 3 つを使う。指定のしかたは仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 に従う。

- **強調はマーカー**（`CodeBlock` の `marks`。CodeMark）。文中と同じ黄の帯（`video-mark`）を、字句の下 42% に引く。帯の上の字句は、字句の色をやめて墨（`video-code-text`）の太さ 600 にする。黄の帯の上では `code-type`（ライト 4.35:1）や `code-macro`（ダーク 4.42:1）などが 4.5:1 に届かないため。墨なら 13.7:1（ダーク 7.59:1）ある。帯の色・高さは文中の mark と同じで、章によらない。
- **エラーの箇所は波線**（`CodeBlock` の `errors`。CodeError）。字句の下に赤（`video-ng`）の波線を引く。波は波長 6px・振幅 2.5px・線 2px で、1 文字（12px）でも山が 2 つ見える。字句の色は変えない。波線は `video-code-bg` の上で 5.46:1（ダーク 7.58:1）、mark の帯の上で 4.91:1（ダーク 4.12:1）、Diff の帯の上でも 3:1 以上。波線という形そのものが色以外の手がかりになる。
- **Diff**（`code_blocks` の `diff`。CodeDiff）。行の先頭に `+`（追加）・`-`（削除）・半角空白（変わらない行）を書く。追加行は青竹の帯（`video-diff-add-soft`）・左端の 4px の線（`video-diff-add`）・先頭の「+」（`video-diff-add-ink`）。削除行は灰の帯（`video-diff-del-soft`）・左端の灰の線・先頭の「−」で、文字はすべて灰（`video-muted`）にする。取り消し線は引かない。Diff のコードブロックは、全行の左に記号の欄（28px）を空ける。
- **Diff の色を新しく作った理由**: アプリ側に「追加」を表す色がない。よく使われる緑と赤は、緑が第2章・第12章の章カラーと、赤が誤り（`c-ng`・波線）とぶつかる。そこで、追加は章カラーの緑（色相 164°）と青緑（209°）の間の空き（186°、青竹）に新しい色を置いた。削除は、色相を持たない灰にした（「消えたもの」として `c-muted` と同じ考え）。黄（mark）・赤（誤り）・12 色の章カラーのどれとも色相が重ならない。さらに「+」「−」の記号と帯の形で、色に頼らず区別できる。
- 3 つは重ねてよい。例: 追加行の中の字句にマーカーを引く、マーカーの上に波線を引く。
- **生きている範囲・スコープは枠**（`CodeBlock` の `scopes`。CodeScope）。行の範囲を枠で囲み、枠の右上にラベル（`r`・`x`）を出す。外側の枠は破線 2px の `video-accent-ink`、内側の枠は実線 3px の `video-primary`。制約（入れ子・重なり・範囲の数）は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」。
- **読み上げている行以外を淡くする**のは、強調の色付けではない。行に色を付けず、読ませない行の不透明度を下げる（「動きの種類と速さ」、CodeMotion）。
- **出力**（`language` が `text`）は地を `video-bg` にして 2px の `video-rule` で囲み、コードブロック（灰の地）と見分ける。行番号は付けない。

### 行番号

- `language` が `text` 以外のコードブロック（Rust、Rust 以外の言語、`plaintext`）には、左に行番号の欄が付く（仕様の `content-format/video/code-display.md`「行番号と Diff」）。
- 欄の幅は `video-code-gutter`（52px）で、右端の 2px が区切り線（`video-code-rule`）。番号は 18px の等幅（`video-code-number`）を右寄せにし、色は `video-line-number`（= `muted`、コードの地の上で 5.75:1、ダーク 6.56:1）。本文は `video-code-text-x`（68px）から始まる。
- どのコードブロックにどの `language` を使うかは仕様の `content-format/video/code-display.md`「言語（`language`）」 に従う。`text` は「ターミナルの出力」（コンパイラ・cargo の出力、プログラムの実行結果、標準入力とのやりとり）に限る。行番号を付けない。ターミナル以外のテキスト（入力ファイル、設定ファイルの中身など）は `plaintext`（色付けなし・行番号あり）か、その言語の名前（`toml` など）で書き、`label` にファイル名を書く。
- **番号はファイルの行番号**（仕様の `content-format/video/code-display.md`「行番号と Diff」）。`code_blocks` に `start_line` を書くと、載せた 1 行目がその番号になる（省くと 1）。Diff では、変更後のファイルで最初の行（削除行を除く）の番号を書く。
- **数え方は 1 種類だけ**: 共通部品に指定する行番号（`marks`・`errors`・`scopes`・`lines`）も、ナレーションと画面の文で指す行番号も、すべて**表示される番号**（ファイルの行番号）で書く（指定は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」、文は仕様の `content-guidelines/video.md`「コード」）。Diff の追加・削除は、行の先頭の記号（`+` / `-` / 空白）で書くので、どの行が追加・削除かを数える必要がない。
  - 理由: 「載せた 1 行目を 1 とする数え方」を指定だけに使うと、表示の番号と 2 種類の数え方ができ、途中の行から載せたときに必ず取り違える。Diff を行番号で指定すると、削除行には表示の番号がないので、さらに別の数え方（削除行を含めた位置）が要る。行の先頭に記号を書く形は git の差分（unified diff）と同じで、学習者も作者も見慣れている。
- **3 桁まで**: 番号の欄（52px、番号の右に 14px）には、18px の等幅で 3 桁（約 33px）まで入る。表示する最後の番号を 999 以下にすることは仕様の `content-format/video/code-display.md`「行番号と Diff」（教材チェックツールでエラー）。
- **行を差し込む動きの途中**は、まだ差し込んでいない行を数えずに番号が表示される（仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」）。差し込みが終わると、`code_blocks` の行番号と同じになる。
- 数え方の例（`src/main.rs` の 12 行目からの Diff。台本の `code_blocks` の 1 件）:

```json
{
  "id": "fix",
  "label": "src/main.rs",
  "language": "rust",
  "start_line": 12,
  "diff": true,
  "code": "     let s1 = String::from(\"hi\");\n-    let s2 = s1;\n+    let s2 = s1.clone();\n     println!(\"{s1} {s2}\");"
}
```

| 書いた行 | 表示される番号 | 文での指し方 |
| --- | --- | --- |
| `␣    let s1 = …` | 12 | 「12 行目」 |
| `-    let s2 = s1;` | （なし） | 「`let s2 = s1;` を消す」 |
| `+    let s2 = s1.clone();` | 13 | 「13 行目のように `clone()` を足す」 |
| `␣    println!(…)` | 14 | 「14 行目」 |

  （`␣` は半角空白。記号の 1 字は共通部品が取り除き、その後ろがコードになる。）
- 範囲の例（118 行目から載せたコードの生きている範囲）: `start_line` が 118 のコードブロックで、`r` の範囲を 119〜124、`x` の範囲を 121〜123 と指定する。範囲も表示される番号で書く。
- 1 行に入る字数（20px の等幅で 1 字 12px。出力は 18px で 1 字 10.8px）:

| コードブロック | 本文の左端 | 字数の式（W はコードブロックの幅） | 全幅（W = 1136） | W = 544 | W = 480 |
| --- | --- | --- | --- | --- | --- |
| 通常 | 68px | (W − 96) ÷ 12 | 86 字 | 37 字 | 32 字 |
| Diff あり | 92px | (W − 120) ÷ 12 | 84 字 | 35 字 | 30 字 |
| 範囲の枠あり | 102px | (W − 148) ÷ 12。全幅では 80 字まで | 80 字（ラベルがかかる行は 60 字） | 33 字 | 27 字 |
| 出力（`text`、18px） | 28px | (W − 56) ÷ 10.8 | 100 字 | — | — |

- 寄せたときは、映る範囲に収まる幅で数える（「1 画面に載せる量」）。
- Diff の帯と左端の 4px の線は、行番号の欄の右（区切り線から 2px 空けた位置）から始める。番号の欄はどの行も地の色のままにして、区切り線と番号が帯に埋もれないようにする。
- 範囲の枠は、行番号の欄の内側（コード側）に置く（外側の枠の左端 60px、内側 76px、本文 102px）。枠は欄をまたがない。範囲の枠と Diff は同じコードブロックで使わない（仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」）。

## ライトとダーク

- テーマは、アプリが動画を描画する範囲の祖先の `data-theme`（`light` / `dark`）で切り替える。動画のコードには何も書かない（仕様の `content-format/video/structure.md`）。`data-theme` は `data-chapter` の祖先に置く。
- テーマを切り替えると、再生中の動画の色も、再生を止めずに切り替わる（仕様の `screens/appearance.md`「テーマ」）。色をトークンと色クラスだけで指定していれば、そのまま切り替わる。
- ダークの値はアプリ側と同じく案である。ダークでは章カラーの塗りが明るくなり、上の文字は濃くなる（`fill-on` が自動で切り替わる）。塗りの上の文字は必ず `fill-on` にし、白や黒を前提にしない。
- 画像（`img`）はテーマで色が変わらない。白い地に黒い線の画像はダークで浮くので、図は画像にせず SVG（`figure.diagram`）で描く。
- 配置の基本形のダークの見え方は「DarkTheme」にある。

## アクセシビリティ

- 文字は、置く地の上で 4.5:1 以上（ライト・ダークとも）。主な組:
  - 本文 `video-text` は `video-bg`・`video-code-bg`・`mark` の帯の上で 5.9:1 以上。
  - 章カラーの文字（`c-primary`・`c-accent`）は `video-bg`・`video-code-bg`・`accent-soft` の上で 5.9:1 以上（全 12 章）。成功の文字 `c-ok` は 7.0:1 以上（ダーク 8.6:1 以上）。
  - callout の文字は 5 種類の地のどれの上でも 12:1 以上、アイコンは地の上で 5.6:1 以上。
  - 塗り `fill-primary` の上の `fill-on` は 4.68:1 以上（全 12 章）。
  - コードの字句は、コードの地と Diff の追加行の帯の上で 4.6:1 以上。mark の帯の上の字句は墨に固定（13.7:1、ダーク 7.59:1）。Diff の削除行の文字（灰）は帯の上で 5.1:1 以上。
- **この基準は、動き終わった状態と、淡くしていない行に当てはめる**。現れる・消える途中の要素と、淡くした行（1.6〜2.6:1）は、基準の対象から外す。淡くした行の扱いは「動きの種類と速さ」に従う（読ませない行だけを淡くし、淡くする前に通常の濃さで見せる）。
- 線や図形で意味を持つものは、地に対して 3:1 以上: 章カラーの線 4.68:1 以上、`stroke-muted` 3.1:1、既定の線 9.3:1。`stroke-muted` は `video-bg` か `fill-surface` の上に置き、`fill-muted` の領域の上に直接置かない（2.8:1）。
- 色だけで意味を伝えない。正しい・誤りは ✓ / × と文言、無効は破線と文言（「使えない」）を添える。
- 図の `svg` には `role="img"` と `aria-label`（図の要点を 1 文で）を付ける（仕様の `content-format/video/scenes.md`）。図の中の文字は `text` で書き、画像にしない。
- `img` には `alt` を付ける（仕様の `content-format/video/scenes.md`）。画像の中の文字も、表示した大きさで 18px 以上にする。
- 画面に表示される文字の大きさは「文字の最小サイズ」に従う。
- 音を出せない環境や聞こえにくい人のための字幕は、アプリの機能である（仕様の `screens/video-screen.md`）。

## 共通部品が出力する HTML の形

動画のテーマ CSS（`bundle.css`）は、アプリと共通部品（仕様の `content-format/video/scenes.md`「共通部品」）が次の形の HTML を出力する前提で書いている。作者は、この形を自分で書かない（共通部品に指定する。指定のしかたは仕様の `content-format/video/scenes.md`「共通部品」・`content-format/video/code-display.md`「`CodeBlock` の指定」 を唯一の定義とする）。`CodeBlock` にない動きのためにレッスン専用の部品を作るときは、この形に合わせる。

動きの途中の状態は、要素の `style` に書いた CSS 変数（進み具合 0〜1）で受け取る。CSS のアニメーションとトランジションは使わない。変数がないときは、動き終わった状態（`--line-dim` だけは 0）になる。

| CSS 変数 | 付ける要素 | 意味 |
| --- | --- | --- |
| `--camera-x`・`--camera-y`・`--camera-scale` | `.video-camera` | 映す範囲の左上の位置（基準の px。単位なしの数）と倍率 |
| `--mark-p` | `.mark` | マーカーの帯を左から引いた割合 |
| `--error-p` | `span.error` | 波線を左から描いた割合 |
| `--scope-p` | `span.scope` | 範囲の枠の現れ具合（不透明度） |
| `--from`・`--to` | `span.scope` | 範囲の最初と最後の行（載せた何行目か） |
| `--line-open` | `span.line` | 差し込む行の開き具合（高さと不透明度） |
| `--line-dim` | `span.line` | 行を淡くする度合い（1 で `video-dim-opacity`） |
| `--bar-p` | `.title-deco-bar` | 表紙の飾りの棒の伸び具合 |
| `--fade-right` | `.fade-right`（コードブロックを包む要素） | 行の右端をぼかして消す度合い |

1. **章とテーマ**: アプリは、動画を描画する範囲に `data-chapter="N"`、その祖先に `data-theme` を付ける。動画のコードは付けない。
2. **ステージと寄せ**: シーンは、根に `.video-stage` を描く。`Camera` は、ステージを `.video-camera` で包み、映す範囲を CSS 変数で渡す。`.video-camera` は動画の枠（1280×720）の左上に重なり、枠からはみ出した部分は映らない。アプリは、動画の枠の地を `video-bg` にする（映す範囲がステージの外に出たとき、外がステージの地と同じ色になる）。

```html
<div data-theme="light">                                   <!-- アプリ -->
  <div data-chapter="4">                                   <!-- アプリ（章外では data-chapter を付けない） -->
    <div class="video-camera" style="--camera-x:22; --camera-y:0; --camera-scale:1.16">  <!-- Camera -->
      <div class="video-stage" data-lesson-label="4-3 所有権のムーブ">…</div>             <!-- シーン -->
    </div>
  </div>
</div>
```

3. **コード**（`language` が `text` 以外）: `pre > code.language-{language}`。`label` があれば `pre` に `data-label` を付ける。字句に分けて `tk-*` の `span` で囲み（`rust` だけ）、1 行ずつ `span.line` に入れる（行と行の間に改行文字を入れない）。Diff のときは `code` に `data-diff` を付け、各行の先頭の 1 字（`+` / `-` / 空白）を取り除いてから字句に分け、`+` の行の `span.line` に `is-add`、`-` の行に `is-del` を付ける。
4. **行番号**: 新しい要素は差し込まない。`span.line` に、表示する番号を `data-ln` 属性で付ける（`<span class="line" data-ln="118">`）。番号は `start_line`（省くと 1）から数え、削除行（`is-del`）には付けず、数えもしない。行を差し込む動きの途中の番号は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 に従う。CSS が `.line::after` に `attr(data-ln)` で描く（`::before` は Diff の記号が使う）。番号を表示しない行には、空の `data-ln` を付ける。`data-ln` がないときは CSS のカウンタで 1 から数える（見本用の予備）。
5. **マーカーと波線**（`marks`・`errors`）: 対象の字句を `span.mark`・`span.error` で囲み、その中の字句も `tk-*` で囲む。両方を重ねるときは `span.mark > span.error` の順にする。描く途中は `style="--mark-p:0.5"`・`style="--error-p:0.5"` を付ける。進み具合が 0 の字句は囲まない（マーカーの帯の上の字句は墨の太字になるため）。
6. **生きている範囲**（`scopes`）: `code` に `data-scopes` 属性（値は使わない）を付け、範囲ごとに `<span class="scope" data-label="r" data-depth="0" style="--from:2;--to:7"></span>` を `code` の先頭に差し込む（`data-depth` は入れ子の深さ、外側が 0）。`--from` / `--to` には、表示の番号を「載せた何行目か」に直して渡す（表示の番号 − `start_line` + 1）。CSS が行の高さ（32px）から枠の縦の位置を決める（上端は `20 + 32 × (from − 1)`px）。行を差し込む途中は、開いている分を足した小数を渡す。現れる途中は `--scope-p` を付ける。
7. **行の動き**（`lines`）:
   - 差し込み（`open`）: 途中の行（0 以上 1 未満）の `span.line` に `is-opening` を付け、`style="--line-open:0.4"` を渡す。CSS が高さを 0 から 1 行分まで開け、不透明度を上げる。開き終わったら `is-opening` を外す。
   - 入力（`typed`）: その行の文字を、先頭から進み具合の分だけ出力する。入力の途中（0 より大きく 1 未満）は、末尾に `<span class="caret"></span>` を置く。
   - 淡くする（`dim`）: `span.line` に `style="--line-dim:1"` を渡す。
8. **出力**（`language` が `text`）: `pre > code.language-text`。1 行ずつ `span.line` に入れる。rustc の出力は行を解析して `out-*` の `span` で囲む（CompilerOutput）。行の動き（7）は同じ。長い行がブロックに入りきらないときは、コードブロックを包む要素にクラス `fade-right` を付けると、行の右端（右から 96px〜28px）をぼかして消せる（`--fade-right` が 0 で消さない、1 で消す。既定は 1。CompilerOutput）。
9. **柱**: `.video-stage` に `data-lesson-label`（例「4-2 所有権のムーブ」）を付けると、左上に柱が出る。表紙（`title`）では `data-chapter-label`（例「第4章 所有権」）を付けると、レッスン名の上に章名が出る。値は `useLesson()` から得る（動画のコードに書き写さない。仕様の `content-format/video/scenes.md`「共通部品」）。
10. **表紙**: `LessonTitle` は、表紙のステージの `h1` としてレッスン名を出力する。章カラーの飾りは、CSS が `::after` で描く。飾りを動かすときは、ステージに `deco-as-elements` を付けて `::after` を消し、`div.title-deco-soft` と `div.title-deco`（中に `span.title-deco-bar` を 3 つ）を置く（LayoutTitle）。
11. **CSS の注意**: `accent` に依存する `video-*`（`video-primary` など）は `.video-stage` の上で宣言し直している。CSS のカスタムプロパティは宣言した要素で解決されるので、`:root` だけで宣言すると `[data-chapter]` の差し替えが届かない。
12. **書体**: 見本の `bundle.css` は Murecho と Red Hat Mono を Google Fonts から読み込んでいる。アプリでは書体を同梱する（アプリ側の未決事項と同じ）。動画のコードから外部の URL は参照できない（仕様の `content-format/video/prohibited-code.md`）。
