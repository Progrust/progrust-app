Rust の学習でよく使う図の定型（ムーブ、借用）で、同じ概念は同じ描き方でそろえる。生きている範囲は図ではなく CodeScope で示す（仕様の `content-guidelines/video.md`「図」）。

## 定型

### スタックとヒープ（ムーブ・クローン・Box）

- 左にスタック、右にヒープの領域（`fill-muted`、間 160）。コードと左右に並べるときは、間を 64 まで詰める（README「寄せ方」）。
- 変数は箱、ヒープのデータはセル。所有者の箱は主役（`fill-primary`）、ヒープのデータは補助（`fill-accent stroke-accent`）。
- 所有者からデータへの矢印は `stroke-primary`（線 3）。
- ムーブされた元の変数は無効の箱（`fill-surface stroke-muted` の破線）で、「使えない」と書く。元の矢印は `stroke-muted` の破線で残す。
- 見本: LayoutDiagram（ムーブ）、FigureCaption（String）、Camera（コードと並べたムーブ）。

### 借用（参照）

- 参照は補助の箱（`fill-accent stroke-accent`）で、`&s` のような短いラベルを添える。
- 参照から所有者への矢印は `stroke-accent`（線 3）。「借りている」と書き添える。
- 所有者とヒープの関係はムーブと同じ描き方。
- 可変参照（`&mut`）は同じ形で、文字を `&mut s` にする。色を変えない。

### 生きている範囲（ライフタイム・スコープ）

- 図にしない（仕様の `content-guidelines/video.md`「図」）。コードブロックの行に枠を重ねる `CodeBlock` の `scopes`（CodeScope）で示す。コードを図の中に書かずにすみ、範囲と行の対応がずれない。

## 動かし方

長さとイージングは README「動きの種類と速さ」に従う。

- 図は、ナレーションの進みに合わせて部品を 1 つずつ出す（領域 → 変数の箱 → ヒープのセル → 矢印 → 所有者の印）。
- **ムーブ**: 所有者の印（`fill-primary` の塗りと「所有者」の添え書き）と矢印の根元が、元の変数の箱から移った先の箱へ、30 フレームで移る。移ったあと、元の箱は破線の無効の箱になり、矢印の跡が破線で残る。「使えない」は、そのことを読み上げる位置で出す。
- **起こらないこと**（コピーされない、所有者が 2 つになる）を見せるときは、一時的に出して消す。コピーされたデータは破線のセル、誤った状態は `stroke-ng` の枠と ×・文言で示す。出すのも消すのも 12〜16 フレーム。
- 矢印は、根元から先へ 18 フレームで描く。

## 使い分けの原則

- 図の中に書いてよい文字と、図とコードの分け方は仕様の `content-guidelines/video.md`「図」 に従う。この定型で使うラベルは、変数名・型名・値・`&s`・`'a` と、短い注記（「使えない」「借りている」）。
- 1 つの図で使う色は、主役（章カラー）・補助（章の淡い面）・灰・赤（誤りのとき）まで。
- 同じレッスンの中で、同じ変数は同じ位置・同じ色で描く。シーンのあいだも、シーンをまたいでも、位置を動かさない。
