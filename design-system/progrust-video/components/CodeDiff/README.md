コードブロックの Diff 表示（台本の `code_blocks` の `diff`）で、追加した行と削除した行を、章によらない固定の色と「+」「−」の記号で示す。行の先頭に記号を書く、git の差分（unified diff）と同じ書き方。

## 書き方

台本の `code_blocks` の 1 件:

```json
{
  "id": "fix",
  "label": "src/main.rs の変更",
  "language": "rust",
  "diff": true,
  "code": " fn main() {\n     let s1 = String::from(\"hi\");\n-    let s2 = s1;\n+    let s2 = s1.clone();\n     println!(\"{s1} {s2}\");\n }"
}
```

- **書き方と制約は仕様書に従う**。`diff` の書き方（各行の先頭の 1 字に書く `+` / `-` / 半角空白、空の行の扱い）、表示される行番号と `start_line` との併用、範囲の枠（CodeScope）と同じコードブロックで使わないことは、仕様の `content-format/video/code-display.md` を唯一の定義とする。記号のあとに、インデントを含めたコードをそのまま書く。
- 置き換える行は、削除行と追加行を変更後の位置に並べて両方書く。並べる順は仕様の `content-guidelines/video.md`「コード」 に従う。
- どの行が追加・削除かを、行番号で指定する必要はない。
- ファイルの途中から載せるときは `start_line` を併せて書く（CodeExcerpt）。
- 文での Diff の行の指し方は仕様の `content-guidelines/video.md`「コード」 に従う。上の例では「3 行目のように `clone()` を足す」「`let s2 = s1;` を消す」のように言う。
- 追加行: 青竹の帯（`video-diff-add-soft`）、左端の 4px の線（`video-diff-add`）、先頭に「+」（`video-diff-add-ink`）。字句の色はそのまま。
- 削除行: 灰の帯（`video-diff-del-soft`）、左端の灰の線、先頭に「−」。文字はすべて灰（`video-muted`）になる。取り消し線は引かない。
- 並びは「行番号 → 記号 → コード」。帯と左端の 4px の線は、行番号の欄の右（区切り線から 2px 空けた位置）から始まり、番号の欄は地の色のまま。記号は 64px、本文は 92px から。1 行に入る字数は README「行番号」（全幅で 84 字。記号の 1 字は数えない）。表示の「+」「−」は CSS が描く。
- 変わった字句を示したいときは、追加行の中の字句にマーカーを引く（`marks`。CodeMark）。上の例では 3 行目の `clone()`。
- 使う場面: 誤ったコードの直し方、関数の書き換え、手順の前後。変更は 1 つの画面に 1 か所（数行）までにする。
- 色を新しく作った理由は README「コードの中の強調・エラー・Diff」にある（赤は誤り、緑は章カラーとぶつかるため、追加は青竹、削除は灰）。

## 出力される HTML の形

共通部品は `code` に `data-diff` 属性を付け、各行の先頭の 1 字を取り除き、`+` の行の `span.line` に `is-add`、`-` の行に `is-del` を付ける。番号を持つ行には `data-ln`（変更後の行番号）を付け、削除行には付けない。
