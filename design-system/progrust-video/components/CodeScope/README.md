変数が生きている範囲やスコープを、コードブロックの行に重ねた枠で示す（`CodeBlock` の `scopes`）。範囲ごとに枠で囲み、右上にラベルを出す。入れ子の範囲（`r` が 2〜7 行目、`x` が 4〜6 行目）が、枠の内外でそのまま分かる。

## 書き方

- **指定のしかたと制約は仕様書に従う**。`scopes` の書き方（ラベルと開始行・終了行、行番号の数え方、進み具合）と制約（範囲の数・入れ子の深さ・重なり・`code_blocks` の行番号の外の範囲・Diff との併用）は、仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 を唯一の定義とする。例: `start_line` が 118 のコードブロックなら、`r` を 119〜124、`x` を 121〜123 と指定する（CodeExcerpt）。
- ラベルは変数名かライフタイム名（`r`、`x`、`'a`）。
- 外側の枠は破線 2px の `video-accent-ink`、内側の枠は実線 3px の `video-primary`。同じ深さの範囲を 2 つ並べてもよい。
- 枠は行番号の欄の内側（コード側）に置く。外側の枠の左端は 60px（`video-code-scope-x`）、内側は 76px（`video-code-scope-inner-x`）、本文は 102px（`video-code-scope-text-x`）から始まる。枠は番号の欄をまたがない。
- 1 行に入る字数は README「行番号」（全幅で 80 字、幅 544 で 33 字）。枠の右上のラベルは、範囲の最初の行と前の行の右端にかかるので、その 2 行は短くする（全幅で 60 字程度まで）。
- 枠は、その範囲を読み上げる位置で現れる（`--scope-p`。16 フレーム。README「動きの種類と速さ」）。外側の枠と内側の枠は、説明する順に出す。
- エラーの関係を示すときは、エラーの箇所に波線（例: 借用している値が先に破棄されるエラー（E0597）の `&x`）、エラーが表に出る箇所にマーカー（例: `println!` の行の `r`）を引き、ナレーションと callout.ng で枠の長さの違いを説明する。行の指し方と、枠のラベルで指すときに範囲を台本の `ai_note` に書くことは仕様の `content-guidelines/video.md`「コード」、エラーの説明のしかたは仕様の `content-guidelines/video.md`「エラー」 に従う。見本は、同じエラーを前に出力とともに説明したあとの画面なので、出力を省いている（初めて説明するところでは、CompilerOutput も示す）。
- 使う場面: ライフタイム、スコープの終わりでの破棄（drop）、借用が続く範囲。生きている範囲を図にせずこの書き方で示すことは仕様の `content-guidelines/video.md`「図」 による。

## 出力される HTML の形

共通部品は `code` に `data-scopes` 属性（値は使わない）を付け、範囲ごとに `<span class="scope" data-label="r" data-depth="0" style="--from:2;--to:7"></span>` を `code` の先頭に差し込む（`data-depth` は入れ子の深さで、外側が 0）。`--from`・`--to` は「載せた何行目か」（表示の番号 − `start_line` + 1）。CSS が `--from`・`--to` と行の高さ（32px）から枠の縦の位置を決める（上端は `20 + 32 × (from − 1)`px、外側の枠の左端は 60px）。n 行目の中心はコードブロックの上端から `32n + 4`px で、行番号があっても変わらない。現れる途中は `--scope-p`（不透明度）を付ける。行を差し込む動きの途中は、`--from`・`--to` に、開いている分を足した小数を渡す。
