参照は、指す値より長く生きられない

fn main() {    let r;    {        let x = 5;        r = &x;    }    println!("{r}");}
x の枠は 6 行目で終わるのに、r の枠は 7 行目まで続きます。7 行目で、破棄された x を r が指すので、借用している値が先に破棄されるエラー（E0597）になります。
