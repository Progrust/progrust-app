ポイント欄（クラス `points`）で、章の淡い面に `h2`（小さな見出し）と `ul` を置き、要点を 3 つ程度にまとめる。デザイン案の「ポイント」欄を部品にしたもの。

## 書き方

```tsx
<div className="points">
  <h2>ポイント</h2>
  <ul>
    <li><code>&s</code> は参照（借用）</li>
    <li>所有権は移らない</li>
    <li>借りた側は書き換えられない</li>
  </ul>
</div>
```

- 左右に並べた右の列に置き、左のコードの要点をまとめる使い方が基本。
- 項目は 3 つまで、各 20 字まで。文体は仕様の `content-guidelines/video.md`「画面の文章」 に従う。
- `h2` は「ポイント」など 2〜6 字。20px・章カラーの文字。
- 1 つの画面に 1 つ。まとめ（`summary`）の代わりに使わない。
- 項目は、読み上げに合わせて 1 つずつ出してよい。
- 地は `video-accent-fill`（章外では第4章の淡い面）、角丸 `video-radius-panel`、内側の余白 24 / 28、印は章カラーの 10px の丸。
- 理由: callout は 1〜2 文の注意書きで、箇条書きの要点をまとめる部品がほかにない。
