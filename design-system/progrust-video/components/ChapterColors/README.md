12 色の章カラーと章外（第4章の色）で、同じ画面を並べた見本。どの章で再生しても同じ動画が成り立つことを確かめるためのもの。

## 見方

- 各サムネイルは同じ HTML で、外側の `data-chapter` だけが違う。上がライト、下がダーク。
- 変わるもの: `c-primary`・`c-accent`、`fill-*` / `stroke-*` の `primary`・`accent`、リストの印、表の見出しの線、まとめの ✓、ポイント欄。
- 変わらないもの: 本文・見出しの墨色、`c-ok`（緑）、`c-ng`（赤）、`c-muted`（灰）、callout の 5 色、マーカー（黄、コードの中も）、エラーの波線（赤）、Diff の色、コードの字句の色。
- 章外（`data-chapter` なし、または `"none"` など 1〜12 以外の値）では、章カラーの部分が第4章の色になる。アプリの画面の章外（墨色）とは違う。
- `data-chapter` はアプリが付ける。動画のコードには章を書かない（README「章カラーとの連動」）。
- 実際の値とコントラストは「章カラーごとの実際の色」（`chapter-colors.md`）。

## 気をつける章

- 第2章（緑）・第12章（若葉）: 主役（章カラー）と `c-ok`（成功の緑）が似た色になる。✓ の形と文言で区別する。
- 第4章（マゼンタ）: 主役と `c-ng`（赤）が近い色相になる。× の形と文言で区別する。
- 第8章（空色）: 第7章（青緑）・第1章（青）と色相が近い（どちらとも 20° 前後）。
