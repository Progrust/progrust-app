コードの中の強調（`CodeBlock` の `marks`。出力は `span.mark`）で、文中のマーカーと同じ黄の帯（`video-mark`）を字句の下 42% に引き、帯の上の字句を墨の太字にする。

## 書き方

- 指定のしかた（行番号と、その行の中の文字列。同じ文字列が複数あるときの指し方、進み具合）は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 を唯一の定義とする。
- 注目させたい字句・式だけを指定する（変数名、引数、`&s`、`.clone()`、型名など）。マーカーで強調し、行全体に色を付けて強調しないことは仕様の `content-guidelines/video.md`「コード」 に従う。
- 1 つのコードブロックで、同時に 1〜3 か所。ナレーションか画面の文（callout など）で、マーカーを引いた字句に触れる。マーカーで指すときに、指している字句を台本の `ai_note` に書くことは仕様の `content-guidelines/video.md`「コード」 に従う。
- マーカーは、その字句を読み上げる位置で、左から右へ 12 フレームで引く（`--mark-p`）。役目を終えたマーカーは、10 フレームで消してよい（README「動きの種類と速さ」）。
- 帯の上の字句は、字句の色をやめて墨（`video-code-text`）・太さ 600 にする（CSS が行う）。黄の帯の上では `code-type` などの字句の色が 4.5:1 に届かないため。墨は帯の上で 13.7:1（ダーク 7.59:1）。
- 帯の色と高さは文中のマーカーと同じで、章によらない。
- 波線（CodeError）と重ねてよい。Diff の追加行の中でも使える（CodeDiff）。
- 出力（`language` が `text`）の中では使わない（仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」）。

## 出力される HTML の形

共通部品は、対象の字句を `<span class="mark">…</span>` で囲む（中の字句は `tk-*` で囲むが、色は墨になる）。引く途中は `style="--mark-p:0.5"` を付ける（0 で帯なし、1 で端まで）。進み具合が 0 の字句は囲まない。波線と重ねるときは `<span class="mark"><span class="error">…</span></span>` の順にする。
