要点を 1 文で大きく見せる配置（`data-layout="statement"`）で、見出し（56px）と本文を左寄せ・縦中央に置く。

## 書き方

```tsx
<div className="video-stage" data-layout="statement">
  <h1>値の持ち主は、いつも 1 人だけです</h1>
  <p>所有者がスコープを抜けると、値はその場で破棄されます。</p>
</div>
```

- 使う場面: 「このあと何度も使う原則」を一度だけ印象づけるとき。1 レッスンに 1 回まで。
- 見出しは 3 行まで（1 行 17 字）。見出しの上の章カラーの短い棒はテーマ CSS が描く。
- `p` は 1 行の補足。省いてよい。
- 寄せるなら 1.16 倍まで（見出しの最大の幅 1000 が、内容の幅に収まる）。
- 理由: 1 つのことを最も強く表せる。`content` に見出しだけを置くと、上詰めのため下半分が空く。
