文中の強調（クラス `mark`）で、蛍光ペンのように文字の下 42% に黄色の帯（`video-mark`）を引く。章によらず同じ色。コードの中でも同じ見た目で使える（CodeMark）。

## 使い方

```tsx
<p>ムーブではなく複製したいときは、<code>clone()</code> を<span className="mark">自分で呼んで明示します</span>。</p>
```

- 1 つの画面に、同時に 1 か所（コードの中のマーカーを除く）。その画面で一番覚えてほしい一句に引く。
- 1 行に収まる長さ（20 字程度）にする。
- `strong` や色クラスと重ねない。
- マーカーは、その語句を読み上げる位置で、左から右へ 12〜14 フレームで引く。引く途中は、要素の `style` で CSS 変数 `--mark-p`（0〜1）を渡す（README「動きの種類と速さ」「共通部品が出力する HTML の形」）。
- 文中では文字の色を変えない（帯の上の本文の文字は 10.7:1、ダーク 5.97:1）。
- コードの中では、帯の上の字句が墨の太字になる（CodeMark）。
- 理由: マーカーの比喩は章を問わず通じる。章の淡い面（`c-accent`）と区別でき、アプリの検索結果の一致部分と同じ色になる。
