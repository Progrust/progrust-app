動画の最後のシーンに置くまとめの配置（`data-layout="summary"`。仕様の `content-guidelines/video.md`「構成と長さ」）で、見出しと `ul` を置く。各項目の頭に章カラーの ✓（Lucide の `circle-check`）が付く。

## 書き方

```tsx
<div className="video-stage" data-layout="summary">
  <h1>このレッスンのまとめ</h1>
  <ul>
    <li>代入すると、String の所有権は新しい変数に移る（ムーブ）</li>
    <li>ムーブでコピーされるのは、スタック上の部分だけ</li>
    <li>ムーブした元の変数を使うと、ムーブ済みの値を使ったエラーになる</li>
  </ul>
</div>
```

- 項目は 3〜5 つ、各 1 行。`video-summary-item`（26px・太さ 700）で表示する。1 行は、1 倍で 41 字、1.2 倍で 35 字、1.35 倍で 31 字まで。
- 寄せ: 3〜4 項目なら 1.35 倍、5 項目なら 1.2 倍まで（README「1 画面に載せる量」）。寄せるときは、`ul` の幅を内容の幅に合わせて狭める（`style` の `maxWidth`）。
- **書き方は仕様書に従う**。最後のシーンをまとめにすること、項目には分かったことを書き感想にしないことは仕様の `content-guidelines/video.md`「構成と長さ」、見出しを「このレッスンのまとめ」のような見出しにしてよいこと、項目の文体と句点は仕様の `content-guidelines/video.md`「画面の文章」 を唯一の定義とする。例: 「〜を学びました」ではなく、上の例のように書く。
- 項目は、読み上げに合わせて上から 1 つずつ出す（18 フレーム、下から 16px）。
- 最後のシーンなので、終わりで消さない（最後まで再生すると、まとめを映したまま止まる。仕様の `screens/video-screen.md`）。
- 項目の下に、本文を 1 行添えてよい（例: 次の演習で確かめること）。
- ✓ は「分かったこと」を表す章カラーの印。まとめの項目は正誤ではないので、成功の緑（`c-ok`）にはしない。項目に色クラスを付けない。項目の中の一句にマーカーを引くのはよい（Mark）。
- 入れ子のリスト、`ol`、コードブロックを置かない（文中の `code` は使ってよい）。
