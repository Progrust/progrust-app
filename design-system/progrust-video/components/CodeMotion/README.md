コードブロックの動き（`CodeBlock` の `lines` と、`marks`・`errors`・`scopes` の進み具合）で、行を差し込む・入力する・淡くする途中と、マーカー・波線を描く途中の見た目を定める。

## 使い方

- 指定のしかた（行ごとの差し込み・入力・淡くする度合い、進み具合、行番号の数え方）は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 を唯一の定義とする。動きの長さとイージングは README「動きの種類と速さ」に従う。
- **入力する**: 行の文字が左から 1 字ずつ現れる。入力の途中は、末尾にカーソル（幅 2px・高さ 1.15em・`video-code-text`）が出る。カーソルは点滅しない。入力が終わると消える。1 行 8〜22 フレーム。
- **行を差し込む**: 行の間を 8 フレームで開け（高さ 0 → 32px）、続けてその行を入力する。下の行は、開いた分だけ下がる。差し込む前後の行番号の表示は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」、差し込みの途中での行の指し方は仕様の `content-guidelines/video.md`「コード」 に従う。
- **淡くする**: 読み上げていない行の不透明度を `video-dim-opacity`（0.32）まで下げる。行に色は付けない。8 フレームで淡くし、8 フレームで戻す。淡くした行の文字は 4.5:1 に届かない（1.6〜2.6:1）ので、README「動きの種類と速さ」の「淡くする行」を守る。
- **マーカー・波線を描く**: 左から右へ 12 フレームで描く（CodeMark・CodeError）。
- **範囲の枠**: 16 フレームで現れる（CodeScope）。
- 動きは、ナレーションがその行・字句を言う位置に合わせる（合図。仕様の `content-guidelines/video.md`「動きと画面の量」）。
- 出力（`language` が `text`）の行も、同じように淡くできる。コードと出力を上下に並べたときは、出力の読んでいる行と、その行が指すコードの行だけを残して、両方のブロックで同時に淡くする。
- 行全体に色を付けて強調しないこと、読み上げている行に目を向けさせるときにほかの行を淡くしてよいことは仕様の `content-guidelines/video.md`「コード」 に従う。

## 見本

動きの途中の 1 フレームを、止めた状態で示している（見本は動かない）。

- 左上「行の間を開ける途中」: 2 行目の下に、3 行目になる行の間を半分まで開けたところ（開き具合 0.5）。開いている途中の行には番号を出さず、下の行の番号もまだ変えていない。差し込みの途中の番号の数え方は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 に従う。
- 左下「入力の途中（カーソル）」: 差し込んだ 3 行目に `let s2 =` まで入力したところ。末尾にカーソルが出る。
- 右上「ほかの行を淡くする」: 4 行目を読み上げているあいだ、ほかの行を淡くしたところ。
- 右下「マーカーと波線を描く途中」: マーカーと波線を、半分まで描いたところ。

## 出力される HTML の形

- 差し込みの途中の行: `<span class="line is-opening" data-ln="" style="--line-open:0.5">…</span>`。CSS が高さを 0 から 1 行分まで開け、不透明度を上げる。開き終わったら `is-opening` を外す。番号を表示しない行には、空の `data-ln` を付ける。
- 入力の途中の行: 入力した分の文字のあとに `<span class="caret"></span>` を置く。
- 淡くした行: `<span class="line" data-ln="1" style="--line-dim:1">…</span>`（0 で通常、1 で `video-dim-opacity`）。
- マーカー・波線を描く途中: `<span class="mark" style="--mark-p:0.5">`・`<span class="error" style="--error-p:0.5">`。
- 値は、共通部品が現在のフレームから計算して渡す。CSS のアニメーションとトランジションは使わない（仕様の `content-format/video/scenes.md`）。
