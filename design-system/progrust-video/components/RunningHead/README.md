ステージの左上に出る柱（「4-4 所有権のムーブ」）と、表紙の章名（「第4章 所有権」）。`.video-stage` に付けた属性の値を、テーマ CSS が描く。

## 属性

| 属性 | 値の例 | 出る場所 |
| --- | --- | --- |
| `data-lesson-label` | `4-4 所有権のムーブ` | 表紙以外のステージの左上（上 24、左 72、18px・章カラーの文字・12px の章カラーの四角） |
| `data-chapter-label` | `第4章 所有権` | 表紙（`title`）のレッスン名の上（22px） |

- 値（章の番号・章名・レッスンの番号・レッスン名）は、共通部品 `useLesson()` から得る。動画のコードに書き写さない（仕様の `content-format/video/scenes.md`「共通部品」）。
- 属性がなければ何も出ない。
- 柱の高さは上の余白（64）の中に収まり、内容の高さを減らさない。
- 柱は 18px のままでよい（README「文字の最小サイズ」）。寄せたときに、映る範囲の外に出てもよい（README「寄せ方」）。
- 柱は動かさない。シーンの出入りのフェードで、ステージと一緒に現れて消える。
- 理由: デザイン案には左上にレッスン番号と名前があった。レッスン検索のモーダルなど動画だけを見る場面で、どのレッスンの動画かが分かる。動画のコードに書くと書き忘れや食い違いが出るので、`lesson.json` から得た値を使う。
