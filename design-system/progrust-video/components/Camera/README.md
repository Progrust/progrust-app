寄せ（共通部品 `Camera`。出力は `.video-camera`）で、ステージ（1280×720）のうち内容のある範囲を、動画の枠いっぱいに映す。寸法・書体・色は変えず、映す範囲だけを変えて、文字と図を大きく見せる。

## 使い方

- **寄せ方は README に従う**。倍率の範囲、倍率の決め方、寄せたあとの余白、配置の詰め方、寄せを切り替えるときの動きは、README「寄せ方」を唯一の定義とする。`Camera` の指定のしかたは仕様の `content-format/video/scenes.md`「共通部品」 に従う。
- 映す範囲は、左上の位置 (x, y) と倍率で決まる。幅は 1280 ÷ 倍率、高さは 720 ÷ 倍率。
- 表紙は寄せない（1 倍）。そのほかの画面は 1.12〜1.35 倍（`video-zoom-min`〜`video-zoom-max`）。
- 寄せても、ステージの中身（文字の大きさ・線の太さ・角丸のトークン）は変えない。

## 見本

コードと図を左右に並べて変えていく画面（所有権のムーブ）。位置を決めて組んでいる（README「ステージ」）。

| ブロック | 位置と大きさ（基準の px） |
| --- | --- |
| 見出し | 左 72・上 64 |
| コード | 左 72・上 149・幅 480（1 行 32 字） |
| 図 | 左 584（コードの右に間 32）・上 149・幅 492・高さ 280 |
| callout | 左 584・上 453（図の下に間 24）・最大の幅 492 |

- 内容のある範囲は x = 72〜1076、y = 24〜558。(22, 0) から 1.16 倍で映す。映る範囲は 1103×621 で、左右に 50 ずつ、下に 63 の余白が残る。
- 上の見本が、動画の枠に映る絵。コードの文字（20px）は 23.2px、図の補足（18px）は 20.9px の大きさで映る。
- 下の見本は、寄せる前のステージ全体（1 倍）と、映す範囲（枠の線。見本用の印）。

## 出力される HTML の形

```html
<div class="video-camera" style="--camera-x:22; --camera-y:0; --camera-scale:1.16">
  <div class="video-stage" data-lesson-label="4-3 所有権のムーブ">…</div>
</div>
```

- `.video-camera` は、動画の枠（1280×720）の左上に重なる 1280×720 の要素で、CSS が `--camera-scale` で拡大し、`--camera-x`・`--camera-y`（基準の px。単位なしの数）の分だけずらす。枠からはみ出した部分は映らない。
- 寄せを変える動きは、3 つの値を現在のフレームから補間して渡す。CSS のトランジションは使わない（仕様の `content-format/video/scenes.md`）。
- 変数を省くと 1 倍（寄せない）になる。
