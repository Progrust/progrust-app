エラーの箇所に、赤い波線を引く

let s1 = String::from("hi");let s2 = s1;println!("{s1}");     // 2 文字let r = &x;              // 1 文字let r2 = &mut s;        // 可変参照が 2 つ（E0499）let r3 = &mut s;        // mark と重ねる
波線は、1 文字の字句でも山が 2 つ見える細かさにしています。
