コードの中のエラーの箇所（`CodeBlock` の `errors`。出力は `span.error`）で、VS Code のように字句の下に赤（`video-ng`）の波線を引く。字句の色は変えない。

## 書き方

- 指定のしかた（行番号と、その行の中の文字列。同じ文字列が複数あるときの指し方、進み具合）は仕様の `content-format/video/code-display.md`「`CodeBlock` の指定」 を唯一の定義とする。
- rustc がエラーで指す箇所（出力の `^^` の範囲。`println!("{s1}")` なら `{s1}` ではなく `s1`）を指定する。行全体ではなく、字句や式だけにする。
- 1 つのコードブロックで 1〜2 か所。
- 色だけで伝えないため、波線のほかに、ナレーションと、行末のコメントか callout.ng・出力（CompilerOutput）で何のエラーかを示す。エラーの説明のしかたと、出力を示すところは仕様の `content-guidelines/video.md`「エラー」 に従う（例: コメントは `// 可変参照が 2 つ（E0499）` のように書き、`// E0499` だけにしない）。
- マーカーと重ねてよい（原因の字句にマーカー、エラーの字句に波線、または同じ字句に両方）。
- 波線は、そのエラーを読み上げる位置で、左から右へ 12 フレームで描く（`--error-p`。README「動きの種類と速さ」）。
- 波線: 波長 6px・振幅 2.5px・太さ 2px のタイルを横に並べる（CSS の `::after` とマスク）。1 文字（12px）でも山が 2 つ、2 文字で 4 つ見える。字句の下端から 4px 下に 5px の高さで描く。コードの地の上で 5.46:1（ダーク 7.58:1）、mark の帯の上で 4.91:1（ダーク 4.12:1）、Diff の帯の上でも 3:1 以上。

## 出力される HTML の形

共通部品は、対象の字句を `<span class="error">…</span>` で囲む（中の字句は `tk-*` のまま）。描く途中は `style="--error-p:0.5"` を付ける（0 で波線なし、1 で端まで）。マーカーと重ねるときは `<span class="mark"><span class="error">…</span></span>` の順にする。
