参照は、指す値より長く生きられない

fn main() {    let r;    {        let x = 5;        r = &x;    }    println!("{r}");}
x の枠は 123 行目で終わるのに、r の枠は 124 行目まで続きます。124 行目で、破棄された x を r が指すので、借用している値が先に破棄されるエラー（E0597）になります。

clone() を足すと、s1 も使い続けられる

    let s1 = String::from("hi");    let s2 = s1;    let s2 = s1.clone();    println!("{s1} {s2}");
13 行目のように s1.clone() を代入すると、ムーブ済みの値を使ったエラー（E0382）が出なくなります。
