配置の基本形の見本をダークテーマで並べたもので、各部品の preview を読み込んで `data-theme="dark"` の中に置き直している。

## 見方

- ダークの値はアプリ側と同じく案である。
- テーマはアプリが `data-theme` で指定する。動画のコードにはテーマを書かない（README「ライトとダーク」）。
- 章カラーの塗りは明るくなり、上の文字（`fill-on`）は濃い墨になる。
- callout の地・ポイント欄の地は、章の暗い面（`accent-soft` のダークの値）になる。Diff の追加行の帯は暗い青竹、削除行の帯は暗い灰になる。
- 黄の `mark` は暗い黄土色の帯になる（本文の文字に対して 5.97:1）。
