文中の `code`（インラインコード）で、灰の地（`video-inline-code-bg`）・等幅・周りの 0.88 倍の大きさで表示する。

## 使い方

- **囲む範囲は仕様書に従う**。文中でインラインコードにするもの・しないもの、見出しでインラインコードを使わないこと、表で型や式を並べる列の囲み方、和文と英数字の間の空白は、仕様の `content-guidelines/video.md`「画面の文章」 を唯一の定義とする。
  - 例: `&s`・`&mut T`・`clone()`・`String::from`・`"hello"`・`let` は囲む。s1・String・i32・serde、エラーコード（E0382）、Rust 以外の語（Python、Java）は囲まず、地の文に半角スペースで区切って書く（「s1 は使えない」「String を代入する」）。見出しは「&str は借りる型、String は持つ型」のようにインラインコードなしで書く。表では `&str` と `String` を両方囲む。
- 20 字までにする。途中で折り返さない（`white-space: nowrap`）ので、長いものはコードブロックにする。
- 本文・リスト・表・callout のどこでも使える。callout とポイント欄の中では地が `video-bg` になる。
- TSX では、`{`・`}`・`<`・`>` を含むコード片を文字列として書く（`<code>{"Vec<i32>"}</code>`）。
- 理由: 識別子まで箱で囲むと、短い文に箱が並んで読みにくくなる。和文の中の英数字は半角スペースで区切れば十分に読み分けられるので、箱は「そのまま入力するコード」と分かってほしい片に限る。見出しで使わないのも、地の色の箱が並ぶと読みにくいため。
