箇条書き（`ul`・`ol`・`li`）の見た目と使い方。`ul` の印は章カラーの点、`ol` の番号は章カラーの太字になる。

## 使い方

- 項目は 5 つまで。各項目は 1 行（41 字まで。1.35 倍に寄せた画面では 34 字まで）。
- 入れ子は 2 段まで。2 段目は 22px で、印は灰色の「–」。
- 順序に意味があるとき（手順、ルールの番号）は `ol`、ないときは `ul`。
- 項目の文体、1 つのリストの中での文末のそろえ方、句点を付けないことは仕様の `content-guidelines/video.md`「画面の文章」 に従う。
- 項目の間隔は `video-space-12`、2 段目の上は `video-space-8`。
- 項目は、読み上げに合わせて 1 つずつ出す（README「動きの種類と速さ」の「現れる」）。

```tsx
<ul>
  <li>不変参照（<code>&T</code>）をいくつでも
    <ul><li>読むだけなら同時に何人でも</li></ul>
  </li>
  <li>可変参照（<code>&mut T</code>）を 1 つだけ</li>
</ul>
```

## してはいけないこと

- 3 段以上の入れ子にしない。
- 1 項目に 2 文以上を書かない。説明が要るなら、ナレーションか callout にする。
