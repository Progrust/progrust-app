戻り値で所有権を受け取り直す

考え方

add_suffix(name) を呼ぶと、name の所有権は引数に移ります（ムーブ）。呼んだあとの name は使えませんが、関数が新しい String を返すので、それを受け取れば main で続けて使えます。

let name = add_suffix(name);

同じ名前で受け取り直す書き方は、第1章のシャドーイングです。元の name はムーブ済みなので、取り違えるおそれがありません。

模範解答（src/suffix.rs）

pub fn add_suffix(name: String) -> String {
    let mut s = name.trim().to_string();
    s.push_str("_the_crab");
    s
}

気をつけたい点

trim_end() だけでは先頭の空白が残ります。テストの「前後に空白がある名前」は、この違いを確かめています。
