はじめに

Progrust で Rust を学ぶ

Rust の文法や考え方を、要素ごとに「動画で学ぶ → 演習で書いて確かめる」の順に進めます。ほかのプログラミング言語を使ったことがある人に向けた教材です。

動画で学ぶ

ナレーションつきの短い動画で、1 つの要素の考え方とコードの書き方を確かめます。

演習で解く

エディタでコードを書き、実行して動きを見てから、提出して正しいかを判定します。

AI が記録・分析する

演習ごとの解き方を AI が記録し、苦手な要素を中心にした問題を作ります。

AI の機能と、送信されるデータ

質問への回答・学習記録・分析・問題生成には Claude Code を使います。このとき、書いたコード・質問の内容・学習記録の内容が、Claude Code を通じて Anthropic に送信されます。

学習記録と分析ファイルはこのコンピューターに保存し、設定画面からいつでも開いたり、リセットしたりできます。AI の機能が使えなくても、レッスンは進められます。
