Progrust は、動画で学び演習で解く Rust の学習アプリ。画面は白い地に淡い灰色の面を重ね、角を大きく丸め、開いている章の色をその画面のアクセントにする（デザイン案 D2「章カラー」）。章が進むたびに画面の色が変わることで、学習者が先に進んでいる感覚を持てるようにする。

この README は画面を作る人とエージェントのための使い方のルールである。値はすべて `tokens.json` にあり、ここではトークンの名前で書く。動画の中身（動画の枠の中に描画するもの）の見た目（仕様の `content-format/video/colors.md` の色クラスなど）はこのデザインシステムの対象外で、動画のデザインシステム「Progrust Video」（https://claude.ai/artifact/QGt9Cb1cFYaA8TU7kY9bPq ）に従う。動画の枠の外に置くプレーヤーの操作と字幕は、画面の一部としてこのデザインシステムに従う（仕様の `screens/appearance.md`「デザインシステム」）。

## 文言

- UI の文言は日本語だけ。短く言い切る。感嘆符と絵文字は使わない。
- 学習者に呼びかけず、事実と次の行動を書く。例: 「3 件のテストがすべて通りました」「代入や関数への受け渡しで、値の持ち主がどう移るのかを確かめます。目安 15 分。」
- ボタンは動詞か行き先で書く: 「提出」「実行」「演習へ」「次のレッスンへ」「動画を見直す」「続きから」。確定ボタンを「OK」「はい」にしない。
- 和文と英数字の間、数字と単位の間に半角スペースを入れる: 「String を代入」「15 分」「24 / 167 レッスン完了」。分数の進み具合は「3 / 5」、タイルのような狭い場所では「6/6」。動画の再生位置は「0:42 / 1:44」（分:秒）、再生速度は「1.25 倍」。
- 章は「第4章」、レッスンは「4-4 所有権のムーブ」と書く。
- 警告は、何が起きているか → 学習への影響の順に書く: 「Claude Code が見つかりません。質問・学習の分析・問題生成は使えません。レッスンは続けられます。」

## 色

### 面

- 画面の地は `bg`（白）。地から一段分ける面は `panel`、`panel` の上に置く面は `raised`。面の境目は塗りの差で示し、枠線を付けない（Surface）。
- 枠線を付けるのは `bg` の上のカード（タイル、エディタ、動画の台紙、レッスンの一覧、要素の選択、生成問題の一覧、環境の確認）だけで、色は `line`。一覧の行の区切りとヘッダーの下線は `line-soft`。
- 検索窓・アイコンボタン・灰のボタンの塗りは `field`。
- 影は浮かぶ層（ポップオーバー、検索結果、トースト、ツールチップ、ダイアログとモーダル）の `shadow-pop` と、動画の台紙の `shadow-video` だけ。

### 文字

- 本文と見出しは `ink`、長い説明文は `ink-2`、ナビや二次的なラベルは `ink-3`、補足は `muted`。この 4 つは `bg`・`panel`・`raised` のどれの上でも 4.5:1 以上ある（ダークも同じ）。
- 文中のリンクとテキストボタンは `link`、マウスを重ねたら `link-hover`。
- `ink` の塗り（選択中のナビ、提出ボタン、学習者の吹き出し、ファイルのタブ）の上の文字は `on-ink`。

### 章カラー

- 章の中の画面（動画画面、演習画面、レッスン一覧の章の区切り、次のレッスンの欄）は、その範囲の要素に `data-chapter="N"` を付ける。`bundle.css` が中の `accent`・`accent-soft`・`accent-ink`・`accent-line`・`on-accent` を第N章の色に差し替える。部品は `chapter-N` を直接参照せず、必ず `accent-*` を使う。
- 使い分け:
  - `accent`: 塗り。主ボタン、章の番号、進み具合（シークバーの再生済みの範囲を含む）、正解の円、フォーカスリング。上の文字は `on-accent`。
  - `accent-soft`: 淡い面。次のレッスンの欄、学習中のタイル、章のチップ、推奨レッスンの行、正解のモーダルの見出し、正解後の帯。
  - `accent-ink`: 章の色で書く文字。「学習中」、章のチップの文字、レッスン番号、「正解」。
  - `accent-line`: 中間の色。学習中のタイルの枠、シークバーのまだ再生していない範囲。
- 章カラーは 12 色ある: 1 青、2 緑、3 橙、4 マゼンタ、5 紫、6 茶、7 青緑、8 空色、9 紺、10 オリーブ、11 梅紫、12 若葉（`chapter-1` 〜 `chapter-12`）。第1〜7章と第9章はデザイン案の色で、第2章・第3章は白い文字が読めるように暗くした値。第8章と第10〜12章は新しく選んだ色。章カラーに灰色を使わない。
- 第N章には `chapter-((N − 1) mod 12 + 1)` を使う。13 章目からは 1 色目に戻る。隣り合う章は必ず違う色になる。
- 塗り（`chapter-N`）はライトでは白い文字に対して、ダークでは `on-chapter` の濃い文字に対して 4.5:1 以上ある。
- 1 つの画面で章の色を使うのは、開いている章の範囲だけにする。ほかの章を指す印（相互参照のバッジ、気をつけたい要素のバッジ、検索結果のバッジ）は、その印にだけ `data-chapter` を付ける。
- ヘッダー・質問パネル・学習ペースのグラフ・トーストには章の色を持ち込まない。
- 動画のプレーヤーで章の色を使うのは、シークバーと主ボタン（「演習へ」、動画のみのレッスンの「次のレッスンへ」、「このレッスンを開く」）だけにする。再生／一時停止、位置を移すボタン、再生速度、音量、字幕の切り替えは `ink` と `field` で作る。

### 章外の画面

- トップページ（次のレッスンの欄を除く）、生成問題一覧、生成問題の演習画面、生成設定画面、設定画面、初回起動画面は `data-chapter` を付けない。`accent` は `ink`（墨色）のままになり、主ボタンも正解の円も墨色になる。
- 章末復習レッスンは、その章の `data-chapter` を付ける。

### 意味の色

- 成功（正解、完了）は章の色で表し、成功専用の緑は持たない。必ず `check` の形を添える。
- エラー・不正解・取り返しのつかない操作は `danger`（塗り）・`danger-soft`（面）・`danger-ink`（文字）。注意は `warning`（文字とアイコン）・`warning-soft`（面）。
- 判定結果のカード（JudgeResult）は、不正解なら面を `danger-soft`、ビルドの失敗なら `warning-soft` にして、結果をひと目で分かるようにする。カードの中の文字（`ink`〜`muted`、`danger-ink`、`accent-ink`）は、どちらの面の上でも 4.5:1 以上ある（ダークも同じ）。
- `danger` は第4章のマゼンタと、`warning` は第3章の橙と色相が近い。意味の色を使うときは必ずアイコン（`circle-alert`、`triangle-alert`、`x`）と文言を添え、色だけで意味を伝えない。
- 習熟レベル（MasteryBadge）は目盛りの数と文言で区別する。「よく間違える」は `danger-ink`、「たまに間違える」は `warning`、「安定」「得意」は墨色。
- 検索結果で一致した部分は `mark` の塗りに `ink` の文字。

### コード

- エディタ・コード片・コンソールの色は `code-keyword`・`code-string`・`code-macro`・`code-comment`・`code-type`・`code-function`・`code-line-number`。Monaco Editor のテーマもこのトークンから作る。
- コンソールの ANSI の色は `ansi-red`・`ansi-yellow`・`ansi-green`・`ansi-blue`・`ansi-magenta`・`ansi-cyan`。

### コントラスト

- 文字は、使う面の上で 4.5:1 以上（24px 以上の文字は 3:1 以上）。各トークンの説明に、どの面の上で使えるかを書いている。
- 次の組はデザイン案の値のままで、基準に届いていない。値を変えるかどうかは未決。
  - `control-line`（入力欄・白いボタンの輪郭）: `raised` に対して 1.3:1。操作部品の境界の目安 3:1 に届かない。
  - `code-comment`: ライトの `panel` の上で 4.42:1。コメントを含むコードは `raised` か `bg` の上に置く。
  - `code-line-number`: 2.4:1。読ませる文字ではない扱い。
- スライダーの地（シークバーは `bg` の上の `accent-line`、音量は `field` の上の `chart-bar`）は、置く面に対して 3:1 に届かない。値は、塗り（`accent`・`ink`）とつまみの位置で読ませる。

### ダークテーマ

- ダークの値は案である。面は `bg` → `panel` → `raised` の順に明るくなる。
- 章カラー・`danger` の塗りはダークでは明るくし、上の文字を濃くする（`on-chapter`、`on-danger`、`on-ink`）。白い文字を直接書かず、必ず `on-*` を使う。

## 書体

- 本文と見出しは Murecho（`--font-sans`）、コードは Red Hat Mono（`--font-mono`、和文は Murecho で表示）。
- 太さは 400・500・700・800 だけ。見出しは 800、ラベルとボタンは 700（主ボタンは 800）、ナビは 500。
- 書体のスタイル: `logo`、`numeral`、`display`（1 画面に 1 つ）、`title`、`title-sm`、`heading`、`subheading`、`body`、`body-sm`、`label`、`label-strong`、`button`、`button-lg`、`caption`、`micro`、`code`、`code-sm`。
- 和文の本文は行間を広く取る: `body` 1.85、`body-sm` 1.75。
- エディタの文字サイズは設定で 12〜24px（既定 14px）。

## 余白・角丸・高さ

- 余白は `space-*`（2〜32px）。画面の左右は `space-28`、セクションの間は `space-18`〜`space-20`、面の内側は `space-20`／`space-22`。
- 角丸は大きさで決める: 進み具合の棒 `radius-bar`、小さな四角 `radius-cell`、章の番号 `radius-badge`、面の中の欄 `radius-inset`、タイル `radius-tile`、エディタやコンソール `radius-panel`、トップページのセクションとダイアログ `radius-section`。
- ボタン・ナビ・検索窓・タブ・チップは `radius-pill` で両端を丸くする。
- 部品の高さは `control-*`: チップ 28、ツールバー 32、通常のボタン 36、入力欄と検索窓 38、主な操作 44、画面の最後の行動 46。ヘッダーは `header-height`（62px）。

## 状態

- フォーカス: 2px の実線の `accent` を 2px 離して付ける。章外の画面では墨色、章の中では章の色になる。
- 選択中: ナビは `ink` の塗り。タブとセグメントは `raised` の塗りと `shadow-tab`。ファイルのタブは `ink` の塗り。
- マウスを重ねたとき: 塗りの上に `state-hover` を重ねる（案。デザイン案にはホバーの状態がない）。
- 押し込んだ状態（字幕の切り替え、ミュート）: `aria-pressed="true"` を付け、`ink` の塗りと `on-ink` の文字にする。
- 無効: 塗りは `disabled`、文字は `disabled-ink`。
- 処理中: Lucide の `loader-circle` を回し（`.pg-spin`）、「実行中」「回答を作成しています」のように文字でも示す。
- 動きの決まり（時間・イージング）はまだない。

## アイコン

- アイコンは Lucide を使う（ISC ライセンス）。アプリには `lucide-react` などで同梱し、ネットワークから読み込まない。
- 線の色は `currentColor` で、文字の色に合わせる。線幅は 16px 以上で 2.2、14px 以下で 2.4（Lucide の既定の 2 より太くする）。
- 大きさは 14・15・16・18px。正解の円の中だけ 28px（線幅 3）。
- 文字の横に添えるアイコンは `aria-hidden="true"`。アイコンだけのボタンには `aria-label` を付ける。
- このシステムの Icons に、使っているアイコンの SVG を置いている。動画のプレーヤーで使う `pause`・`rotate-cw`・`volume-2`・`volume-x`・`captions` は、まだ Icons に置いていない（見本はインラインの SVG で描いている）。Icons の SVG は `currentColor` の線なので、`<img>` で表示すると黒になる。画面ではインラインの SVG か `lucide-react` で使う。

## 動画のプレーヤー

- 動画画面とレッスン検索のモーダルは、VideoPlayer（動画の台紙・Captions・VideoControls）で組む。操作の種類・キーの割り当て・字幕の表示の決まりは仕様の `screens/video-screen.md` と `screens/lesson-search.md` に従う。
- 動画の台紙（`.pg-video-frame`）は 16:9 で、`bg` の塗り・`line` の枠・角 `radius-panel`・`shadow-video`。枠の中には動画だけを描き、字幕と操作は枠の外（下）に置く。
- 再生位置と音量は Slider で示す。再生位置（シークバー）は章の色、音量は墨色。
- 設定画面の「動画」の区分（仕様の `screens/settings-screen.md`）は、SettingsRow に VideoControls の音量（`.pg-volume`）・SegmentedControl・Switch を置いて組む。

## ロゴ

- ロゴのマークはまだない。「Progrust」を `logo` の書体（Murecho 800、21px、字間 0.01em）で `ink` の色で書く。

## 実装のしかた

- テーマはルート要素の `data-theme`（`light` / `dark`）で切り替える。色はすべて CSS 変数で参照し、値を直接書かない。
- 章の色は、章の範囲の要素の `data-chapter`（1〜12）で切り替える。
- 部品のクラスは `components/bundle.css` にあり、接頭辞は `pg-`。部品ごとの使い方は各部品の README にある。見本の HTML はクラスと構造の見本で、React の部品はまだない。
- 画面ごとの部品の組み合わせ方は、画面デザインのキャンバス「Progrust UIデザイン」（https://claude.ai/artifact/SL7VXW5D7weHs8tLG9zHNx ）にある。
- `bundle.css` は見本のために Murecho と Red Hat Mono を Google Fonts から読み込んでいる。アプリではフォントを同梱する（仕様の `screens/appearance.md`「書体のファイル」）。

## 未決事項

- アプリの仕様に関わる未決事項（章と章カラーの対応をどこで定めるか、字幕を表示しないときも動画の下に字幕の場所を空けておくか）は、Progrust の仕様書（`screens/open-questions.md`）にある。このシステムでは、章の順番で章カラーが決まる前提で書いている。字幕の場所は、空けておく場合と詰める場合の両方を Captions の見本に示している。
- 基準に届いていない組（`control-line`、ライトの `panel` の上の `code-comment`、`code-line-number`、スライダーの地）の扱い。
- ダークテーマの値、ホバーの見た目、動きの決まり。
- 「新規の案」と書いた部品と、「画面デザインで追加した部品」「動画への切り替えで追加した部品」と書いた部品は、画面のレイアウトが固まるまで見直すことがある。
