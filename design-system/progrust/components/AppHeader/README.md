# AppHeader

全画面の上に置く高さ 62px のヘッダーで、ロゴ・メインメニュー・レッスン検索・ジョブ数を並べる。

- 呼び出し側が渡すもの: 現在の画面（`aria-current="page"` を付ける項目）、実行中・待機中のジョブ数。
- 選択中のメニューは章の中の画面でも `ink` の塗り（`on-ink` の文字）にする。章カラーはヘッダーに持ち込まない。
- ジョブ数のボタン（`.pg-jobs`）はジョブがないときは出さない。押すと JobPopover を開き、開いている間は `aria-expanded="true"` で墨色になる。
- 検索窓は `field` の塗りの丸い欄で、「レッスン検索」と書く。結果は SearchResults に出す。フォーカス時は欄全体に `accent` のフォーカスリングを付ける。
- ロゴのマークはまだない。「Progrust」を `logo` の書体で書く。
