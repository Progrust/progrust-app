# LessonList

レッスン一覧の、章の見出しとレッスンの行。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）

- 章ごとに `[data-chapter]` を付けた区切りにする。見出しは 40px の章番号・章名（`title`）・説明・完了数。
- 行に出すもの: レッスン番号（`accent-ink`）、タイトル、概要、目安の時間（`clock`）、状態（未着手 / 進行中 / 完了）。
- 状態の印: 未着手は `field` に `muted`、進行中は `accent-soft` に `accent-ink`、完了は `accent` の塗り。
- 推奨レッスンの行は `aria-current` で `accent-soft` の塗りにし、タイトルの横に「次はここ」（`.pg-next`）を付ける。章末復習レッスンには「復習」、動画のみのレッスンには「動画のみ」（どちらも `.pg-tag`）を付ける。
