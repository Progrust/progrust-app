# ChatPanel

質疑応答のパネル。動画画面では右に開閉できるパネル（幅 340px）、正解のモーダル（PassModal）の中では右の列（幅 360px）として置く。

- パネルは `panel`。学習者の吹き出しは `ink` の塗り（右寄せ、右下の角だけ 4px）、AI の回答は `raised`（左寄せ、左下の角だけ 4px）。どちらも `body-sm`。
- 入力欄は `.pg-inbox`（`raised` の面に `shadow-control` の輪郭）の中に、複数行の入力と、下の行に送信ボタン（`.pg-icon-btn--ink.pg-icon-btn--sm`）を置く。送信ボタンを入力欄の外に出さず、入力の幅を狭めない。送信ボタンの左に、ショートカット（`.pg-inbox-hint`）を添える。フォーカスリングは入力欄の面全体に付ける。
- 回答を作っている間は、回転するアイコンと「回答を作成しています」を AI 側に出し、入力欄の代わりに「停止」と理由（`.pg-composer-note`）を出す。止めた回答は残して「（停止しました）」（`.pg-stopped`）を添える。
- エラーは回答の場所に `.pg-bubble-error`（`danger-soft`）で出し、「再試行」を置く。
- 解説の質問は空の状態（`.pg-chat-empty`）から始め、何を聞けるかを書く。Claude Code が見つからないときは、入力欄の代わりに `.pg-chat-unavailable`（`warning-soft`）で導入手順へのリンクを出す。
- 章の色は使わない（質問は章の進行と関係しない操作のため）。
