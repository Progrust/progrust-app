# Tooltip

要素名などに添える、墨色の短い説明（要素マスタの description）。（画面デザインで追加した部品。D2 の面・角丸・文字の決まりで作った）

- `.pg-tip` は `ink` の塗りに `on-ink` の文字（`caption`）。1 行目に名前を太字で、最後に要素 ID を `code` で小さく書く。上向きの小さな三角を付け、`shadow-pop` で浮かせる。
- 対象の要素にマウスを重ねたときと、キーボードでフォーカスしたときに出す。`role="tooltip"` を付け、対象から `aria-describedby` で指す。
- 操作できる中身（リンク、ボタン）は入れない。
