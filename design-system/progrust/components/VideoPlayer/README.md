# VideoPlayer

動画画面とレッスン検索のモーダルに置く動画のプレーヤーで、動画の台紙・字幕・操作を縦に積む。（動画への切り替えで追加した部品。D2 の面・角丸・文字の決まりで作った）

- `.pg-video` の中に、上から動画の台紙（`.pg-video-frame`）、字幕（Captions）、操作（VideoControls）を置く。間は `space-12`。
- 動画の台紙は 16:9。`bg` の塗り・`line` の枠・角 `radius-panel`・`shadow-video`。枠の中には動画だけを描く。動画の中身の見た目は、動画のデザインシステム「Progrust Video」に従う（このデザインシステムの対象外）。
- 字幕と操作は枠の外（下）に置き、枠の中に重ねない（仕様の `screens/video-screen.md`）。
- 呼び出し側が渡すもの: レッスンの動画、開いたときの再生位置（仕様の `lesson-flow/progress.md`）、音量・再生速度・字幕の設定（仕様の `screens/settings-screen.md`）、右端の行動（動画画面は「演習へ」、動画のみのレッスンの動画画面は「次のレッスンへ」、モーダルは「このレッスンを開く」）。
- 動画は表示領域に収まる最大の大きさにする（仕様の `screens/video-screen.md`）。幅と高さの両方に収める計算は実装で行い、台紙の幅に字幕と操作の幅を合わせる。
- 章の色は、章の範囲の `[data-chapter]` から受け取る。使う場所は VideoControls の README に書いている。
- 開いたときは一時停止の状態で表示する（自動では再生しない）。
