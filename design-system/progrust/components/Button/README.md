# Button

角を高さの半分まで丸めた、文字のボタン。種類は役割で選ぶ。

| 種類 | クラス | 使う場面 |
|---|---|---|
| 主（章の色） | `.pg-btn--accent` | 画面の先に進む行動。1 画面に 1 つ（「演習へ」「次のレッスンへ」「続きから」）。章外の画面では墨色になる |
| 墨色 | `.pg-btn--ink` | 章の色を使わない確定の行動（「提出」「生成」「送信」） |
| 白 | `.pg-btn--outline` | `panel` の上の二次的な行動（「実行」「解説について質問する」） |
| 灰（既定） | `.pg-btn` | `bg` の上の二次的な行動（「動画を見直す」「レッスン一覧へ」「キャンセル」、動画のプレーヤーの「5 秒」「字幕」） |
| 文字 | `.pg-btn--text` | ツールバーの軽い操作（「初期コードに戻す」） |
| 危険 | `.pg-btn--danger` | 取り返しのつかない操作の確定（「リセット」）。確認ダイアログの中だけで使う |

- 高さ: `--sm` 32px、既定 36px、`--lg` 44px、`--xl` 46px。1 つの行の中では高さを揃える。
- 文言は動詞か行き先で短く言い切る（「提出」「演習へ」「次のレッスンへ」）。補足は `.pg-btn-sub` で後ろに添える（「次のレッスンへ　4-5 clone と Copy」）。
- 切り替えのボタン（「字幕」）は `aria-pressed` を付ける。`aria-pressed="true"` のときは `ink` の塗りと `on-ink` の文字になる。
- 無効のときは `disabled`。塗りは `disabled`、文字は `disabled-ink` になる。
- ホバーは `state-hover` を塗りの上に重ねる（案）。
