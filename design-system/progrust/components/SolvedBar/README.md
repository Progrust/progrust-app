# SolvedBar

正解のモーダル（PassModal）を閉じたあと、演習画面の下に残す帯。（画面デザインで追加した部品。D2 の面・角丸・文字の決まりで作った）

- `.pg-solved` は `accent-soft` の面で、両端を丸くする。左に `accent` の円の `check`、「正解しました」（`accent-ink`）、補足（`.pg-solved-sub`、エディタが読み取り専用になったこと）。
- 右（`.pg-solved-actions`）に「解説を開く」（白のボタン）、「レッスン一覧へ」、主ボタンの「次のレッスンへ」。生成問題では墨色になり、主ボタンは「生成問題一覧へ」。
