# JobPopover

ヘッダーのジョブ数を押すと開く、実行中・待機中のジョブの一覧。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）

- `.pg-pop`（`raised`・角 `radius-panel`・`shadow-pop`）。ボタンの右端に揃えて下に開く。
- 行に出すもの: 種類（学習記録の作成 / 分析の更新 / 問題の生成 / 分析の再構築）、対象（レッスン名など）、状態。
- 実行中は回転する `loader-circle`、待機中は `clock` と `muted`。失敗したジョブはここに残さず、設定画面の「失敗したジョブ」で扱う。
