# Console

演習画面の右下の、実行の出力の欄。見出し・実行・テスト・提出・停止のボタンと、出力・標準入力の欄を持つ。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）（ボタンは D2-Exercise のもの。出力と入力欄は新規）

- 欄は `panel`、出力は `raised` の中に `code-sm` で書く。コンパイラの ANSI の色は `ansi-*` のトークンに割り当てる（error は `ansi-red`、warning は `ansi-yellow`、行番号と矢印は `ansi-blue`、help は `ansi-cyan`）。
- 出力の文字の色は、出力の種類で分ける。ANSI の色が付いた部分は、どの種類でも ANSI の色にする。
  - 標準出力: `ink`（`.pg-console-out` の既定の色）。
  - 標準エラー出力（ビルドの出力を含む）: 一段淡い `ink-3`（`.pg-out-stderr`）。
  - アプリの知らせ（`run_output` の `system`。タイムアウトの旨など）、区切りの行、「古い出力を省略しました」の行: `muted`（`.pg-out-system`）。提出の経過の行（「ビルドしました」など）は `system` ではないので、画面デザインのとおり `ink` にする。
  - 学習者が入力した行: `link`（`.pg-out-input`）。
- タブは置かない。実行の出力と提出の経過を、区切りの行（`── 提出  14:32 ──` を `muted` で）を挟んで続けて書く。提出してもそれまでの出力は消さない。提出の結果は JudgeResult に出し、出力の最後にどこを見ればよいかを書く。
- 実行中は「停止」を有効にし（白のボタン）、見出しの行に「実行中」と回転するアイコンを出す。標準入力の欄（`.pg-stdin`）も実行中だけ有効にし、それ以外は「実行中だけ入力できます」と書く。
- 実行できないとき（Rust が見つからない、外部クレートの準備中、C の演習で clang が見つからない）は、実行・提出を無効にし、出力の上に Banner で理由を出す。clang が見つからないときの Banner は、導入のコマンドを示す形にする（Banner の README）。
- C の演習の clang の診断（`-fcolor-diagnostics` の ANSI の色）も、同じく ANSI の色を `ansi-*` に割り当てる。clang が付ける色をそのまま使い、rustc の区分に合わせて付け直さない。Apple clang 21.0.0 では、error が `ansi-red`、warning が `ansi-magenta`、note が `ansi-cyan`、誤りの位置の `^`・`~` と修正の案が `ansi-green` になり、位置（`main.c:5:1:`）と本文は太字になる。診断に引用されるコード片の行（`   11 | …`）の字句にも、clang が色を付ける（キーワードは `ansi-blue`、文字列と数値は `ansi-green`）。ANSI の黒と白は、色を付けない。
- C の演習の実行が、シグナルで終わったときの 1 行（「シグナル SIGSEGV で終了しました（不正なメモリアクセス）」など）は、アプリの知らせなので `muted`（`.pg-out-system`）にする。
- C の演習では「テスト」ボタンを置かない。ボタンの並びは、実行・提出・停止になる。
