# MasteryBadge

要素の習熟レベルの印（未学習 / よく間違える / たまに間違える / 安定 / 得意）。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）

- 4 本の目盛り（`.pg-meter`）と文言で示す。色は補助で、目盛りの数と文言だけで区別できる。
- よく間違える: `danger-soft` に `danger-ink`。たまに間違える: `warning-soft` に `warning`。安定: `field` に `ink-3`。得意: `ink` の塗り。未学習: 目盛りなしの `muted`。
- 成功の色は章の色で表す決まりなので、「得意」に緑を使わない。
- `provisional` のときは後ろに「データ不足」（`.pg-mastery-note`）を添える。
