# VideoModal

レッスン検索の結果を選ぶと、今の画面の上に開く動画のモーダル。（動画への切り替えで追加した部品。D2 の面・角丸・文字の決まりで作った）

- `overlay` の幕（`.pg-scrim`）の上に、`.pg-modal`（幅 880px、`bg`・角 `radius-section`・`shadow-pop`）を置く。上（`.pg-modal-head`）に章のチップ・レッスン名・閉じるボタン、その下（`.pg-modal-body`）に VideoPlayer。
- プレーヤーの操作は動画画面と同じ（VideoControls）。右端の行動は主ボタンの「このレッスンを開く」にし、「演習へ」は出さない。
- 動画の先頭で、一時停止の状態で開く（仕様の `screens/lesson-search.md`）。
- モーダルの面を、表示しているレッスンの章の `[data-chapter]` にする。
- 字幕は、動画画面と同じ設定に従って Captions を出す。
- 画面の高さに収まらないときは、動画を縮めて、操作と「このレッスンを開く」が見えるようにする。
- Esc と幕のクリックで閉じる。
