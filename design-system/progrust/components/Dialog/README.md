# Dialog

操作の前に確認するダイアログ（リセットなど）。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）

- `overlay` の幕の中央に、幅 440px・`raised`・角 `radius-section`・`shadow-pop` の面を置く。タイトルは `title-sm`、本文は `body` の `ink-2`。
- ボタンは右下に「キャンセル」（灰）と確定（取り返しがつかない操作は危険ボタン）。確定の文言は操作名にする（「OK」「はい」にしない）。
- 「学習履歴をすべてリセット」では TextField に「リセット」と入力するまで確定ボタンを無効にする。
- Esc と幕のクリックで閉じる。開いたら最初の入力欄（なければキャンセル）にフォーカスを移す。
