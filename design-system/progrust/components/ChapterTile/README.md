# ChapterTile

トップページの「章ごとの進み具合」に並べる、章のタイル。並べるのは 9 章ぶん（どの 9 章かは仕様の `screens/top-page.md`）で、見本は第4章を学習中のとき（第2〜10章）。

- 呼び出し側が渡すもの: 章の番号・名前・完了レッスン数・レッスン数、学習中かどうか。
- `bg` の塗りに `line` の枠。学習中の章は `aria-current` を付け、`accent-soft` の塗り・`accent-line` の枠・「学習中」の印にする。
- 進み具合の棒は ProgressBar。完了した章は棒が章の色で埋まる。
- 最後のタイルは `.pg-tile--more`（「レッスン一覧を開く」）。
