# ElementList

トップページの「気をつけたい要素」の一覧。要素ごとに章の番号・要素名・理由を並べる。

- 呼び出し側が渡すもの: 要素名、導入された章の番号、理由（よく間違える / たまに間違える / 復習推奨 / 定着度が低下）。
- 章の番号は要素ごとに `[data-chapter]` を付けたバッジ。
- 理由の文字: 「よく間違える」は `danger-ink`、「たまに間違える」は `warning`、「復習推奨」「定着度が低下」は `muted`。色だけでなく文言で区別する。
- モックアップでは「よく間違える」を第4章の濃いマゼンタ `#A61E55` で書いていたが、章の色と意味の色を分けるため `danger-ink` にした。
- 行を押すと、その要素を選んだ状態の生成設定画面を開く。
