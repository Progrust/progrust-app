# SearchResults

ヘッダーの検索窓の下に開く、レッスン検索の結果のドロップダウン。（新規の案。D2 のモックアップにない部品を、D2 の面・角丸・文字の決まりで作った）

- 結果はレッスン単位で、最大 20 件。検索の対象・照合・並び順は仕様の `screens/lesson-search.md` に従う。
- 呼び出し側が渡すもの: 結果（章の番号と名前、レッスン番号とレッスン名、一致した検索ワード）と、一致部分の範囲。
- 1 行目（`.pg-result-meta`）に章のバッジと章名、2 行目（`.pg-result-h`）にレッスン番号とレッスン名、3 行目（`.pg-result-tags`）に「検索ワード」の文字と、一致した検索ワードを `.pg-tag` で並べる。検索ワードに一致がないとき（レッスン名だけに一致したとき）は 3 行目を出さない。
- 一致部分は `<mark>`（`mark` の塗り、`ink` の文字）で示す。章のバッジは結果ごとに `[data-chapter]` を付けて、その章の色にする。
- キーボードで選んでいる行は `aria-selected="true"`（`panel` の塗り）。Enter で VideoModal を開く。
- 0 件のときは「一致するレッスンはありません」を `.pg-results-foot` に出す。
