# ElementPicker

問題生成で使う要素を選ぶ部品。章ごとに折りたたむ一覧と、選んだ要素のチップからなる。（画面デザインで追加した部品。D2 の面・角丸・文字の決まりで作った）

- 一覧は `.pg-acc`（`bg` の上のカードなので `line` の枠）。章ごとに `.pg-acc-group` を置き、見出し（`.pg-acc-head`、`aria-expanded`）には章のバッジ・章名・選んだ数（`.pg-acc-sel`、`ink` の塗り）・要素数を出す。章の色はバッジだけに使う（バッジにだけ `data-chapter`）。
- 要素の行（`.pg-el`）は Checkbox と、習熟レベル（MasteryBadge）。分析のデータが少ない要素は「データ不足」（`.pg-mastery-note`）を前に添える。
- 要素名（`.pg-el-name`、点線の下線）にマウスを重ねるかフォーカスすると、Tooltip で要素の説明を出す。
- 選んだ要素は上に `.pg-pick` のチップで並べ、× で外せる。何も選んでいないときは `.pg-pick--empty` に、選ばなかったときの動作を書く。上限に達したら `.pg-count` で知らせ、残りの Checkbox を無効にする。
