# EmptyState

中身がまだない一覧や欄に出す、何がここに出るかと次の行動の案内。（画面デザインで追加した部品。D2 の面・角丸・文字の決まりで作った）

- 画面いっぱいの空は `.pg-empty`（`panel` の面）。上に `raised` の円のアイコン（`ink-3`）、見出し（`heading`）、説明（`body-sm`・`ink-2`）、次の行動のボタン。
- 欄の中の空（トップページの分析など）は `.pg-panel-empty` で、文だけを中央に置く。
- 文言は事実と次の行動を書く: 「まだ生成した問題はありません」「演習に正解すると、ここに分析が表示されます」。
